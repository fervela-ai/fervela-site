AI 自學課程地圖

先選一條路線，照順序上幾門具體的課，用一個做得出來的東西驗收。後面附台灣與全球的完整目錄，要找更多時再往下翻。

明天就能開始的三門

  1. 01
    李宏毅 — 生成式人工智慧與機器學習導論 2025，第 1 講
    全中文、不用寫程式。一講建立「大型語言模型到底怎麼運作」的直覺，下面三條路線都從這裡開始。整門共 10 講，投影片與作業在課程網頁。
  2. 02
    Anthropic — Building with the Claude API
    要會 Python。67 堂、官方標示 9 小時，從呼叫 API 一路做到工具使用、檢索、agent，並有一整段在教怎麼建立測試資料與自動評分。免費，完成有徽章。
  3. 03
    Karpathy — Neural Networks: Zero to Hero，第 1 支
    要會 Python 與導數。第 1 支「building micrograd」2 小時 25 分，親手寫出反向傳播；整個系列 8 支，最後寫出 GPT。

怎麼走

先決定你要的是哪一種。三條路線需要的底子不同，驗收方式也不同 —— 看完課不算學會，做得出下面那個「產出」才算。

三條路線

用 AI 改善工作不用寫程式
  1. 李宏毅 第 1 講 — 先知道它怎麼運作
  2. AI Fluency: Framework & Foundations — 4 小時，怎麼分工、怎麼描述、怎麼檢查答案
  3. AI Capabilities and Limitations — 3.5 小時，它在哪裡會錯

產出挑一件你每週都在做的重複工作，寫成一份能重複使用的指令：要給 AI 哪些資料、怎麼檢查它的答案。連續用三週，把它出錯的地方記下來。

開發 AI 應用要會 Python
  1. MIT The Missing Semester — shell、git、除錯，寫應用前的工具底子
  2. Building with the Claude API — 9 小時，API、工具使用、檢索、評估
  3. Hugging Face AI Agents Course — 先做 Unit 1，每單元約一週 3–4 小時
  4. 定義成功指標並建立評估 — 官方文件，改一次就跑一次測試
  5. 李宏毅 ML 2026 Spring 前兩講 — 進階，agent 實際怎麼運作

產出做一個根據你自己的文件回答問題的小工具：答案附出處，資料裡沒有時會說不知道。另外準備 30 題測試題，每次修改前後都跑一遍，把分數記下來。

理解或訓練模型要會 Python 與微積分
  1. 3Blue1Brown 神經網路系列 — 先有畫面
  2. 李宏毅 2025 第 5–8 講 — 機器學習、深度學習、LLM 怎麼學、後訓練
  3. Karpathy Zero to Hero — 8 支依序，從 micrograd 到 GPT
  4. Karpathy nanochat — 實際訓練一個小型對話模型

產出不用現成框架，寫出一個能生成文字的小模型；再改一個設定（例如層數或上下文長度），說明訓練損失曲線為什麼跟著變。

完整目錄

上面路線裡的課都在這裡，另外還有更多。按台灣與全球分，要找特定學校、平台或補某一塊時再翻。

台灣

聚合平台先看，單校站只在已經知道要找誰的課時才進去。台灣的 OCW 站普遍更新慢，新課不一定會上；舊課多半留著，但沒有人保證會一直在。

聚合入口

TOCEC 開放式課程聯盟主力

26 校、近 700 門課的共同目錄。非營利、全免費。查台灣課程的第一站。
ewant 育網值得知道

陽明交大建置，台灣第一個 MOOC 平台，課程數最多（近 9,000 門）。品質落差大，靠搜尋不靠瀏覽。
TaiwanLIFE 全民學習平台值得知道

空大主導，約 4,600 門。偏通識與終身學習，資工電機的深度課不多。
ShareCourse 學聯網值得知道

清大系統出身，規模小（約 500 門）但理工課的比例高。
OpenEdu 中華開放教育平台備用

教育部磨課師體系的平台之一。內容與前幾個重疊度高。

單校 OCW

台大開放式課程主力

電資學院的完整課程在這裡，也收林軒田機器學習基石／技法的 MOOC 完整版。台清交裡最值得逛的一個。
清大開放式課程主力

周志遠作業系統、黃能富計算機網路、趙啟超線代與離散、張國浩隨機過程都在這。系統與數學那一半比台大齊。
陽明交大開放式課程備用

2007 年台灣第一所加入全球開放教育組織的學校，但資工電機的公開量偏薄，工學院以材料機械為主。舊網域 ocw.nctu.edu.tw 仍在。
成大開放式課程值得知道

教學發展中心主辦，工學院基礎課紮實。
中山大學網路大學備用

課程列表在網路大學系統裡，介面舊但內容公開。
政大開放式課程備用

課程頁在教發中心，影片放在「政大數位知識城」。社科與商管為主。
台科大開放式課程備用

沒有獨立網域，掛在教學發展中心底下。應用導向的工程課。

不在 OCW 站上，但老師自己全公開

李宏毅（台大電機）主力

生成式 AI 與機器學習系列，每學期改一版跟著領域更新，投影片、作業、Colab 全開，明確歡迎旁聽。全中文授課，材料齊到可以一個人跟完。走自己的網站，不走 OCW。
林軒田（台大資工）主力

機器學習基石與技法的投影片總站。影片在 YouTube 與台大 OCW 都有完整版，不必付 Coursera 的錢。
陳縕儂 — 深度學習之應用 ADL主力

台大資工，比李宏毅更偏「怎麼把模型接成產品」。投影片在課程站，影片在她的 YouTube 頻道。

全球

大學 OCW 是資產但更新慢；真正跟得上 LLM 進度的是下面第三組那些由業界或個人維護的課。

大學 OCW

MIT OpenCourseWare主力

開放課程的老祖宗，2,500 門以上，講義、習題、考古題與解答齊全。要補數學或系統底子時的預設選項。
MIT The Missing Semester主力

shell、git、除錯、遠端機器、資料處理 —— 學校不教但天天要用的那一學期。自己顧伺服器、自己寫部署腳本的人，每一講都會立刻用到。
Harvard CS50值得知道

哈佛的計算機導論，製作規格接近影集，修課人數以百萬計。已經會寫程式的人，價值在它把底層概念講得很清楚，不在教你語法。
Stanford Online值得知道

官方入口，但真正的寶藏是各課自己的網站與 YouTube 頻道：CS231n（視覺）、CS224n（NLP）、CS336（從零做語言模型）。
Open Yale Courses備用

數量少但每門都是完整錄影加逐字稿。強在人文與經濟，理工幾乎沒有。
CMU Open Learning Initiative備用

不是錄影，是互動式教材加即時回饋。設計取向跟其他 OCW 不同，適合真的要練會的科目。
UC Berkeley 課程站（CS61A 等）值得知道

柏克萊沒有統一 OCW，但每門課自己的網站全開：CS61A/61B、Data 8、CS188 都能整門跟完，含作業與自動評分。
NPTEL（印度理工聯盟）備用

量體驚人的工程課程庫，冷門主題常常只有這裡有。英語授課，講法偏傳統板書。

搜尋與聚合

CS 自學指南主力

中文社群維護，把全球頂尖 CS 課按主題排成一條有先修關係的路徑，每門都附難度與評價。比任何單一課程網站更值得先看。
Class Central主力

跨 Coursera／edX／各校平台的統一搜尋與評分。要判斷「這門課到底值不值得」時查這裡。
Open Culture備用

人工整理的免費課程清單，年代久、涵蓋廣，但連結失效率不低。
OSSU Computer Science值得知道

GitHub 上的自學課表，用免費課程拼出一個完整的資工學位。適合當地圖，不適合照單全收。

AI／LLM 專用 — 這組最跟得上

Karpathy — Neural Networks: Zero to Hero主力

從反向傳播一路手刻到 GPT，前 Tesla／OpenAI AI 總監親自帶。全程不用現成框架，所以每一步都看得見。免費。
Karpathy — nanochat主力

Zero to Hero 的續集：約 100 美元的算力就能訓出一個 ChatGPT 形態的小模型，涵蓋資料到強化學習的完整流程。
Hugging Face Learn主力

LLM、Agents、MCP 三條線都有完整課程，免費、全部動手做，附可執行的 notebook。補「模型 → 產品」那一層最直接的地方。
Claude Academy（Anthropic 官方）主力

免費、有結業徽章。subagents、agent skills、MCP 各約 1 小時，是工具本身的正式說明書；Building with the Claude API 是完整的 9 小時。
UC Berkeley — LLM Agents MOOC主力

Dawn Song 主持。agent 的搜尋與規劃、tool use、程式生成與驗證、agentic AI 安全。兩萬多人在修，全公開。
DeepLearning.AI 短課值得知道

Andrew Ng 團隊與各家廠商合作的一到兩小時短課，主題貼著業界最新工具走。影片免費；測驗、互動實驗與結業證書要付費會員。適合零碎時間。
fast.ai — Practical Deep Learning值得知道

刻意反過來教：先讓模型跑起來，再回頭講原理。跟 Karpathy 的由下而上正好互補，挑一種吃得下的。
3Blue1Brown — 神經網路系列值得知道

把梯度下降與 Transformer 用動畫講到直覺層級。三小時，性價比在整張表上排前三。

付費平台 — 先確認還免不免費

Coursera備用

2025 年 8 月起把 Audit 改成 Preview，免費只剩第一個單元。上面的台大課程多半在 YouTube 或台大 OCW 有免費完整版，先去那邊找。
edX備用

MIT 與哈佛共同創辦。多數課程仍保留免費旁聽軌，但逐課不同，報名前要看清楚。證書一律付費。
