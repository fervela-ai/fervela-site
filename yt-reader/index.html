🎬 閱影

by Fervela.ai
一小時的影片，讀完只要幾分鐘。
貼上一個 YouTube 網址，閱影把它整理成可以用讀的三層文章： 一分鐘版看要不要繼續、精華版看重點、完整版逐句都在。 每一段旁邊都有時間，點下去回到影片的那個位置。
影片的處理都在你自己的電腦上做。整理內容用的是你自己登入的 AI，不必另外申請 API key（資料到哪裡去 ↓）。

名字

閱卷的閱，不是瀏覽的瀏
閱影

「閱」是逐一看過、審視的閱——閱卷、檢閱、閱讀，都是把東西攤開來一項一項看完。 閱影就是把影片當文章讀。這個詞是自己組的，不是古語，取的是「閱」那個慢下來、看得完整的意思。

怎麼用

先給你最短的，你說要再往下做
1
貼網址

一支影片，或一整個播放清單。有字幕的影片直接用字幕，不必等語音辨識。

2
先拿到一分鐘版

幾十秒內先給你最短的那層，讓你決定這支值不值得花時間。

3
說「有興趣」才往下

覺得值得，才去產生精華版和完整版。不感興趣的影片不會白白吃掉你的時間和額度。

4
照自己的深淺讀

三個版本標了字數和大概要讀幾分鐘。讀到哪一句想聽原音，點時間就回影片。

每天早上一份片單

不是推薦演算法，是一份清單
它自己去找最近重要的影片

從一份講話型頻道的名單裡，找出近幾天觀看速度遠高於該頻道平常水準的影片，再判斷內容重不重要。 你也可以把自己訂閱的頻道匯入進去。

你只要看片單，不必看影片

每支附一句結論。有興趣的按一下，才會去產生完整的閱讀版。

原作者的連結和頻道名放在最顯眼的位置

閱影的用途是幫你決定要不要看、看完幫你記住，不是取代原影片。

你的資料到哪裡去

哪些留在電腦裡、哪些會送出去，分開講
影片與音訊
留在本機下載與解碼都在你的電腦上。音檔不會傳給任何 AI 服務，也不會傳給 Fervela。
語音辨識
留在本機影片本來就有字幕就直接用；沒有字幕才在你的電腦上用 Whisper 轉成文字。
逐字稿
送到你選的 AI清稿與摘要交給你自己登入的 Claude CLI（用的是你的帳戶與方案）。
成品
留在本機三個版本的文章存在你自己的資料夾，Fervela 沒有副本。
Fervela 不接收你看了什麼。送到 AI 服務的文字怎麼保存、怎麼使用，依你的帳戶方案與該服務的條款而定。
轉出來的東西是給你自己讀的。影片的著作權屬於原作者；要公開分享請附上原連結與頻道名，完整逐字稿不適合轉貼。

跟「影片摘要工具」差在哪

摘要只有一層，讀起來要嘛不夠要嘛太多
三層，而不是一份摘要

一分鐘版用來篩選，精華版用來理解，完整版用來查證。同一支影片，三種深度都留著。

每一段都回得去

段落開頭標時間區間，點下去直接跳到影片那一段。AI 寫錯的時候，你查得到。

不需要 API key

用你既有的 AI 訂閱，不必另外辦帳號、綁信用卡。

英文影片另外給中英對照

勾「練英文」會多一份對照稿和單字表，標出原句與時間。

做不到的事

先講清楚，免得你白裝
  • 沒有字幕的長影片要先做語音辨識，需要時間，不是貼上去就有。
  • 語音辨識會有錯字，人名、公司名和專有名詞最容易錯；安靜的片段偶爾會生出不存在的句子。
  • 需要看畫面才懂的內容（圖表、示範操作），文字版救不回來。
  • 目前只在 Apple 晶片的 Mac 上跑過。
  • 測試版還沒有付費簽章，第一次打開時系統會跳安全警告。
