為什麼會有這個產品？

1

你是不是也這樣：同一個問題，想聽聽 GPT 怎麼說、Claude 怎麼說、Gemini 怎麼說…… 於是你開了三個視窗，複製、貼上、複製、貼上——問題還沒解決，你先變成了傳話機器。

2

為什麼不讓他們坐上同一張桌子當面討論？而且要互相反駁、正式表決—— 只會順著你講的 AI，沒資格叫董事會。

3

你只要做一件事：把題目交代清楚。剩下的，交給他們。

4

然後你去忙你的。董事們自己吵、自己收斂，共識達到 80% 才算數。

5

回來時，桌上已經擺好結論——連分歧和少數意見都幫你留著。 所以，「AI 董事會」誕生了。

版本沿革

每一版改了什麼，用「你感覺得到的差別」來寫。 最新版預設展開，舊版點開來看。

V2.82026-08-26
  • GPT 席不再在 75 秒被誤判成卡死——長會議一路跑到底（實測 35K 字逐字稿，GPT 130 秒、Claude 197 秒完成）。
  • 免費額度用完、單次太長等錯誤改成人話，並自動改用另一家繼續開會，不再中斷整場。
  • 免費引擎新增推薦順序：GPT → OpenRouter → Groq → Gemini，0 元圓桌補上 OpenRouter。
  • 手機版：可長按拖曳換位（含換主席）、橫拿不再跑版、打字區與討論區重新排版。
V2.72026-08-25
  • 長討論不再被中途砍斷——逾時改看「有沒有在產出」，不再一律 180 秒就砍。
  • 一席故障不會卡住整場：連續失敗兩次的席位自動請假，會議繼續跑。
  • 修正「不設角色」的成員無法改名；申請金鑰的連結改成明顯的綠色按鈕。
V2.62026-08-25
  • 0 元也能開董事會：新增 Groq 與 OpenRouter，加上 Gemini 共三家免費層，申請不用信用卡。
  • 新手引導會針對你選的那一家，寫清楚按哪顆按鈕、金鑰長什麼樣。
  • 免費席位標明真實型號與供應商，不讓你以為在跟官方模型講話。
V2.52026-08-19
  • 預設改為「思考模式」與「不設角色圓桌」——不再一開口就被推去談怎麼賺錢。
  • 新增「純討論」模式：不求結論，只把不同角度攤開來，最後給一張討論地圖。
  • 取消所有字數限制；角色卡全面改寫成「視角」而不是「議程」，不再蓋過你當下的意圖。
V2.42026-08-18
  • 三輪決議改版：第二輪改成發散討論優缺點（必須講自己立場的缺點），不再為反對而反對。
  • AI 思考中你仍然可以發言，正在思考的董事會帶著你的補充重想一次。
  • 共識輪不再從格式上逼人同意——先講自己的獨立判斷，才輪到同意誰。
V2.32026-08-17
  • 新增主席評分（1–5 分）與「★ 必收錄」，之後所有討論與報告都會讀到。
  • 勾選動作鍵之後，你送出發言就自動執行，不必再按第二次。
  • 新增六頁基礎教學。
V2.0–V2.22026-08-14 起
  • 從 3 家 AI 擴充到 14 家，每家可選訂閱模式或 API Key 模式。
  • 新增五種介面語言與三種佈景主題。
  • 打包成 Mac App 與 Windows 版，雙擊即開。
