名字

《漢書・藝文志》
「古有采詩之官，王者所以觀風俗，知得失也。」

采風官走進民間，把人們正在抱怨、需要與關心的事帶回來。采風做的也是同一件事：先把值得看的訊號采集回來，再由人決定要不要行動。

每天會收到什麼

一份報告，兩個區塊

① 功能需求與產品機會

說清楚誰遇到什麼問題、目前方法麻煩在哪裡、為什麼值得解決、可能怎麼做，以及證據究竟有多強。

② 熱門軟體中文導讀

用繁體中文解釋軟體用途、適合誰、主要功能、關鍵名詞與已知限制，讓你快速決定值不值得深入研究。

不把 Bug 當成產品需求

單一軟體故障、當機或版面偏移，不會因為留言很多就變成產品機會。

不刊空殼，也不為數量湊題目

證據不足、內容不完整、只有自動訊息或模型無法解讀的候選，不會進入正式報告。

熱門只代表受到注意

stars、forks 與 reactions 不能直接當成品質、使用人數、市場需求或付費意願。

資料怎麼流動

本機研究與公開出版分開
采集
官方介面目前只讀 GitHub 的公開專案、README 與 Issues，保留原始來源連結。
分析
安全分析器使用沒有本機工具權限的 OpenAI API，或明確隔離的本機 Ollama；公開文字不交給可讀取本機檔案的代理人。
本機報告
留在電腦完整候選、歷史與每日報告保存在使用者自己的資料夾。
公開週報
人工選編只公開重新撰寫、查核來源並通過品質檢查的少量精選。
