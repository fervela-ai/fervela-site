每天一份清單：別人正在想要什麼。
想做點東西，最難的不是動手，是不知道該做什麼。 采風每天自動上網，從公開的討論裡撈出人們正在說「我需要一個可以……的工具」， 整理成一份可以讀完的報告；另外附上近期竄起的開源軟體中文導讀。
它只讀公開資料，報告留在你自己的電腦裡。

名字

《漢書・藝文志》
「古有采詩之官，王者所以觀風俗，知得失也。」

古代有一種官，工作就是每天走進民間，把老百姓唱的歌、講的話、抱怨的事收回來， 讓上面知道哪裡出了問題。采的是風，不是答案——他負責把話帶回來，判斷是你的事。 這個軟體每天做的正是同一件事。

每天會收到什麼

一份報告，兩個區塊

① 功能需求

有人正在等的東西

從公開討論裡挑出「想讓軟體完成的工作」：誰需要、現在怎麼做很麻煩、可能怎麼解、有沒有人已經動手了。 每一則都附原始連結，你自己回去看。

② 熱門軟體導讀

最近大家在用什麼

近期關注度突出的開源軟體，用繁體中文說明用途、適合誰、怎麼快速試一次。 不是翻譯說明文件，是讓你三分鐘決定要不要花時間。

它替你擋掉什麼

清單的價值在「沒放進去的那些」
不把 Bug 當需求

「這個功能壞了」和「我想要一個能做這件事的工具」是兩回事。只有後者會進報告。

一個熱門專案最多佔兩則

否則整份報告會被當天最紅的那個專案洗版，看起來很多，其實只有一個題目。

看不懂的就不刊

證據不足、沒有有效討論、只有機器人自動回覆的，直接丟掉。不會用「待解讀」這種空殼湊數。

抓不到資料時直接說抓不到

不會拿範例資料冒充當天的結果，也不會用失敗的報告覆蓋掉前一份成功的。

你的資料到哪裡去

這個軟體不需要知道你是誰
采集來源
公開資料只讀公開的討論與專案資料，不需要你登入任何社群帳號。
分析
送到你選的 AI交給你自己登入的 CLI，或你電腦上的本機模型。不需要另外申請 API key。
報告與歷史
留在本機每天的報告和資料庫都存在你自己的資料夾，Fervela 沒有副本。
采風不會替你發言。它只讀，不留言、不按讚、不追蹤任何人。

做不到的事

先講清楚，免得你期待錯方向
  • 目前只看 GitHub。其他地方的抱怨（論壇、社群、應用商店評論）還沒接。
  • 「很多人星星」不等於「很多人需要」，更不等於「付得出錢」。報告只告訴你有人在講，商業判斷仍然是你的事。
  • 它找的是別人公開講出來的需求。真正的好題目常常沒有人講——那種要靠你自己。
  • 同一天的結果會受當天討論量影響，某些日子就是沒什麼好東西。
