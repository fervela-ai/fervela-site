自己養一隻 AI 助理，現在划算了嗎？

2026-09-03　·　Miles 邁爾思

去年底第一次自架 AI 助理，兩天兩夜失敗。今年二月做好了，但 API 帳單太貴，五月它掛掉我反而鬆一口氣。第三次終於不用再多付一份錢。

去年底我第一次嘗試自架 AI 助理。兩天兩夜，沒睡好，最後失敗。那時候什麼都不懂，看著滿畫面的錯誤訊息，只覺得這東西大概不是給一般人用的。

今年二月我再試一次。有 Claude Code 幫忙，三個多小時就跑起來了，成就感爆棚。它接在 Telegram 上，我在通勤時可以直接問它事情。

然後五月它掛了。我一直沒空修，而且說實話，我有點鬆一口氣。

因為那時候自架助理只能填 API key，跑一個月的帳單看了會心痛。它掛掉那天，我心裡有個聲音說：這樣也好。

中間半年，我到處試別的

那半年我沒有放棄這件事，只是換了方式。我把同樣的需求丟給不同的模型，想找一個便宜又夠用的。

Gemini 是很貼心的秘書。2.5 版是貼心的笨秘書，講什麼都好但常常做不對。3.0 版好一點，堪用。

Grok 的 CP 值不錯。我請它幫我做個人網站，結果調一個小東西調了兩小時還沒搞定。同一件事我丟給 Claude，五分鐘結束。

但那五分鐘的費用，比我用 Grok 一整天還貴。

這就是我半年來的困境。最好用的那顆腦袋，貴到不敢拿來當日常助理用。你不會為了問「今天天氣如何」去啟動一個每次都在跳表的東西。

第三次：這次不用另外付錢了

2026 年最大的改變不是模型變強，是自架工具終於可以直接重用你已經在付的訂閱。

以前要填 API key，那是另一條帳單。現在可以把桌機上已經登入的 CLI 憑證交給它，吃你本來就有的訂閱額度。

我昨天花了一個下午把那隻躺了三個半月的助理救回來，主力接 Claude 最強的模型，備援接 ChatGPT，兩邊都走訂閱。額外支出是零。

同一份錢，多了一個 24 小時待命的助理。 這是我三次嘗試裡第一次覺得這件事真的成立。

要講清楚一件事：不是免費，是不用「再多付一份」。它會吃你訂閱的用量額度，額度不是憑空生出來的。如果你的助理排程很兇，可能會排擠到你自己工作時的用量。

它躺了三個半月，只因為一個字

救援的過程比我想的有意思，因為壞掉的原因都很荒謬。

它從五月就一直重開機失敗。查到最後，原因是設定檔裡一個欄位，舊版寫 true 就好，新版要求寫成一個物件。

一個字的格式差異，讓它躺了三個半月。

這種事在自架的世界很常見。你不動它，它自己更新，然後某個欄位的格式規則改了，服務就起不來。而錯誤訊息通常藏在一個你不會主動去看的檔案裡。

好消息是新版有內建的體檢指令，跑一次就自動修好了。升級後第一件事就跑它，可以省掉很多時間。

最陰險的一關：服務假裝自己活著

修好設定之後，我以為結束了。結果它還是不能用。

而且這次的症狀是我看過最惡劣的：系統顯示服務正在執行、程序確實活著、沒有任何錯誤訊息、標準輸出完全空白。從任何一個角度看，一切正常。

實際上它根本沒有對外開門。

真正的原因是新版加了外掛的權限同意機制，有一個外掛沒取得同意，所以它拒絕宣告自己準備好。而這個訊息只寫在一個暫存目錄底下的日誌檔裡，沒有人會主動去看那裡。

我花了快一小時在系統層面繞圈子，才想到去翻那個檔案。

教訓：查問題的順序要反過來。先看應用程式自己的日誌，再看系統狀態。 系統只知道程序有沒有在跑，不知道程序覺得自己準備好了沒有。

金鑰是自架真正的代價

自架的好處是東西在你手上，代價也是東西在你手上。

我打開那台機器，發現五把 API 金鑰散落在各處：有的明文寫在系統服務設定裡，那個檔案的權限是全機器可讀；有的寫在 shell 設定檔；還有一把是二月從對話裡存下來的筆記，直接以明文躺在助理的記憶目錄裡。

這些都是我自己過去為了方便隨手放的。當下都很合理，累積起來就是一個攤開的錢包。

處理方式不難，把密鑰集中到一個權限鎖死的檔案，服務設定改成指過去就好。難的是要先意識到問題存在。

還有一件更蠢的事我要老實講。 安裝過程中有好幾個畫面會完整顯示 token，我為了問人截了圖，同一天洩漏了兩把。

後來只能一把一把去後台撤銷。那個介面沒有批次操作也沒有指令列工具，只能逐列點垃圾桶。

所以現在我的習慣是：截圖前先遮掉那幾行，或乾脆不截，用文字描述進度。

裝好只是能講話，還不算好用

最後一步反而是投報率最高的。

助理的長期記憶檔案預設非常空泛，通常只有你的名字和使用語言。我花二十分鐘把自己的身分、正在做的專案、工作習慣、還有我討厭它做的事全部寫進去。

重啟之後我問它「我是誰、在做哪些專案」，它答得比某些認識我的人還準。

同時也發現一件事：它停擺的那三個半月，發生的事情它是真的不知道。不是搜尋壞掉，是那段時間它不在。記憶有斷層就要在檔案裡註明，不然它會拿舊資訊當現況，講得非常有自信。

所以，划算了嗎？

划算，但有條件。

如果你只是想要一個聊天視窗，不划算。 現成的服務更快更穩，還不用你維護。

如果你想要一個記得你在幹嘛、會主動找你、可以接進你日常在用的通訊軟體的角色，現在是這件事第一次真的成立。 因為帳單那道門檻消失了。

代價是它會壞，而且壞的方式很無聊。不是模型出錯，是一個布林值變成物件、一個外掛沒同意、一把金鑰放錯位置。這些都不難修，但需要你願意花時間。

我養了三次。前兩次不算白費，因為第三次遇到的每一個坑，我都是靠前兩次的疤痕才認出來的。
