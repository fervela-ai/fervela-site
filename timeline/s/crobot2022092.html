Code as Policies：讓大型語言模型寫出機器人控制程式

Jacky Liang 等八位作者（arXiv 論文）｜9 月 16 日

論文表示，只要給幾個「指令加對應策略程式碼」的範例，語言模型就能為新指令重新組合 API 呼叫，寫出新的機器人策略。

三點帶走

  1. 論文表示：語言模型可依自然語言指令與少量範例，重組 API 寫出機器人策略程式。
  2. 作者宣稱：階層式程式碼生成在 HumanEval 解決 39.8% 問題，那是程式基準而非機器人成功率。
  3. 摘要列出能力（空間推理、泛化、行為常識），但未給機器人任務的成功率數字。
