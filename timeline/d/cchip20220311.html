AMD 發表 Threadripper PRO 5000 WX：64 核心工作站處理器

官方宣稱單插槽效能最高為競品的兩倍，並支援 128 條 PCIe 4.0 通道。

這是什麼

Threadripper PRO 是 AMD 面向專業工作站（視覺特效、設計、模擬、程式編譯）的處理器產品線。

三點帶走

  1. 旗艦 5995WX：64 核心 128 執行緒，288MB 快取。
  2. 效能與功耗比較均為官方對競品的宣稱。
  3. 聯想 ThinkStation P620 是第一批工作站。

重點與分析

官方表示，Ryzen Threadripper PRO 5000 WX 系列以 64 核心 128 執行緒的 5995WX 為首，採 Zen 3 架構，旗艦總快取 288MB、TDP 280W、支援最高 2TB ECC 記憶體。

工作站處理器的核心賣點是核心數、記憶體容量與 I/O 擴充，而不是單純的時脈。5995WX 的 288MB 快取與 2TB 記憶體上限，是原文規格表直接列出的數字，對需要大型場景或大量資料的視覺特效與模擬較有意義；官方同時強調 AMD PRO 技術帶來的企業級安全與管理功能。

官方宣稱，5000 WX 系列單插槽效能最高為競品的兩倍，比用兩顆競品伺服器處理器的工作站最高高 95%；每核心功耗最高低 67%，效能功耗比最高為競品兩倍；支援業界最多的 128 條 PCIe 4.0 通道。

這些全是「競品」比較，原文用註腳標明對象與條件，但在這份文字中沒有逐項列出，因此無法確認比較的是哪一款競品處理器。128 條 PCIe 4.0 通道是規格數字，可以直接驗證；官方並稱圖形效能最高高 43%、儲存效能最高 2.2 倍，同樣是競品比較。

官方表示，5000 WX 系列每核心功耗最高低 67%，可處理 8K 的轉譯與剪輯、複雜模擬與設計，以及程式的快速開發與編譯；效能功耗比最高為競品兩倍。

原文把用途列得很具體（8K 影像、模擬、編譯），但並未提供這些工作的實測時間，所以只能視為產品定位說明。「效能功耗比兩倍」與每核心功耗低 67% 兩個數字出自同一組競品比較，不是兩項獨立的改進。5000 WX 的 PRO 版另有企業級安全與管理功能，與一般 Ryzen 桌機處理器區隔。

官方表示，Dune 視覺特效總監稱 CPU 轉譯時間改善 2 倍；ILM 表示 StageCraft 在 CPU 密集工作最高有 2 倍以上加速；首批工作站為聯想 ThinkStation P620。

這些是客戶引述，不是獨立測試，而且測試的是各自的工作流程。引述的價值在於說明這類處理器的實際用途（影像轉譯、虛擬製作），但數字不能外推到其他軟體。第一批工作站只列出聯想一家，原文沒有說明其他廠商何時推出。稿中另引述 Chaos 共同創辦人，稱新系列讓 3D 美術與建築視覺化的專業者能在更短時間完成更多工作，Binyan Studios 則說今年起把全球製作系統遷移到 AMD，這些同樣是客戶或合作夥伴的說法。
