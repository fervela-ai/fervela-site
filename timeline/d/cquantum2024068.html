Azure Quantum Elements 新增 Generative Chemistry 與 Accelerated DFT｜Microsoft Azure Quantum｜6 月 18 日 事件進階

Azure Quantum Elements 加入生成式化學與加速 DFT

官方表示，Microsoft（MSFT） 推出 Accelerated DFT 並預告 Generative Chemistry，兩者皆在 Azure Quantum Elements 的私有預覽中提供。

這是什麼

Azure Quantum Elements 是 Microsoft（MSFT） 結合生成式 AI 與高效能運算（HPC）的化學與材料科學平台。密度泛函理論（DFT）是計算化學中模擬分子電子結構的常用方法。本篇是產品功能發表，大部分內容是 AI 與古典雲端運算，量子運算僅在結尾提及。

三點帶走

  1. Accelerated DFT 已在私有預覽，官方稱平均比 PySCF 快 20 倍；Generative Chemistry 則是即將推出。
  2. 兩項功能主要靠 AI 與古典雲端 HPC，量子硬體是未來數月才引入的計畫。
  3. 「數日取代數年」與 20 倍都是官方自述，測試條件不完整。

重點與分析

官方表示，Generative Chemistry 是即將推出的端到端工作流程，將透過 Azure Quantum Elements 私有預覽提供，協助科學家快速發現與設計具有所需性質的新化合物。

官方說明流程包括：由使用者輸入目標分子特性、產生種子分子與候選分子、以 AI 篩選模型預測沸點等性質、以 AI 合成規劃過濾難以製造的分子，最後對前幾名候選做高精度 HPC 模擬。這是一個『即將推出』的功能，目前沒有公開的效果驗證。

官方表示，整個流程只需數日，可省下原本試誤式實驗需要的數個月甚至數年。

這是官方對流程時間的說法，並未附上與傳統做法比較的實際案例或數據。文章用的是『可省下』，意味著它是潛在效益；化學中合成候選分子後仍須實驗室驗證，這段時間也不在『數日』之內。

官方表示，Accelerated DFT 可在數小時內算出含數千個原子的分子性質，相較廣泛使用的開源 DFT 程式 PySCF，平均快 20 倍。

20 倍是『平均』值，且比較對象是特定的開源程式 PySCF，文中以註腳標示出處，但沒有列出測試的分子集合與硬體配置。因此它代表在官方測試條件下的結果，並非對所有 DFT 軟體與所有分子的普遍優勢。

官方表示，Accelerated DFT 以軟體即服務提供，使用者不必自行編譯或設定，並提供簡化的 API 與 Python SDK；目前已在 Azure Quantum Elements 私有預覽中提供。

這解決的是 DFT 通常得在 HPC 叢集上自己跑、使用門檻高的問題。文中引述丹麥技術大學教授 Tejs Vegge 與 AspenTech 資深副總裁的正面評價，AspenTech 的說法是『預期』會產生強的使用案例，仍屬評估階段。

官方表示，近期曾結合古典超級電腦、AI 以及 Microsoft（MSFT） 的量子位元虛擬化系統與 Quantinuum H1 硬體所建立的邏輯量子位元，模擬化學催化劑；未來數月將把進階的邏輯量子位元功能引入私有預覽。

這是文章中唯一與量子硬體直接相關的段落，內容是『將於未來數月引入』，並非這次發表的功能。文章再次引用與 Quantinuum 合作建立的邏輯量子位元，錯誤率比對應實體量子位元好 800 倍，這項數字來自先前的成果，而非本次新功能的結果。

通鑑怎麼看

通鑑認為，這則發表的主角其實是 AI 與雲端 HPC，量子部分只是預告。20 倍與「數日」是官方自述，附註腳但缺少測試設定；兩項功能都在私有預覽，一般使用者尚無法自行驗證。
