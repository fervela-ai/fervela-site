NVIDIA 在 Computex 前發表 Rubin 平台與一年一代節奏｜NVIDIA｜6 月 2 日 事件入門

NVIDIA（NVDA） Rubin：Blackwell 之後的下一個平台

NVIDIA（NVDA） 在台北向 6,500 位聽眾說明加速運算平台已全面量產，並首度揭露下一代路線圖。

這是什麼

Rubin 是 NVIDIA（NVDA） 接在 Blackwell 之後的平台代號，包含新 GPU、新的 Arm（ARM） 架構 CPU（Vera）與新網路晶片。官方同時宣布網路產品與 MGX 伺服器參考設計的更新。

三點帶走

  1. Rubin 平台接續 Blackwell，包含 Vera CPU 與 NVLink 6。
  2. NVIDIA（NVDA） 稱產品將以一年一代的節奏推出。
  3. AMD 與 Intel（INTC） 計畫為 MGX 提供自家 CPU 主機模組。

重點與分析

官方表示，Rubin 平台將接續 Blackwell，含新 GPU、Vera CPU、NVLink 6、CX9 SuperNIC 與 X1600 交換器。

這次只有元件名稱，沒有任何規格、時程或效能數字。Vera 是 NVIDIA（NVDA） 自己的 Arm（ARM） 架構 CPU，說明 CPU 與 GPU 搭成一組的做法會延續；X1600 是結合 InfiniBand 與乙太網路的交換器，顯示網路被視為平台的一部分。原文開頭強調的主題是加速運算平台『已全面量產』，所以 Rubin 是路線圖上的下一步，而不是已經能買到的產品。

官方表示，黃仁勳稱公司採一年一代節奏，把整個資料中心尺度的設計拆開、分件銷售。

原話強調『在技術極限上推進一切』。一年一代對客戶的含意是資料中心的採購與折舊週期要重新評估；對供應鏈則意味著 HBM、封裝與散熱等要隨之更頻繁地升級。

官方表示，GPU 加 CPU 的加速運算最高可有 100 倍速度、耗電只增加 3 倍，每瓦效能為純 CPU 的 25 倍。

這是黃仁勳在演講中的概括說法，沒有說明工作負載與基準系統，因此是『最高』情境。『買越多省越多』是銷售語言，不能直接當作任何特定客戶的節省比例。

官方表示，MGX 參考設計支援 Blackwell 與 GB200 NVL2，AMD 與 Intel（INTC） 首度計畫提供自家 CPU 主機模組。

MGX 是讓伺服器廠快速做出 NVIDIA（NVDA） GPU 系統的模組化參考設計。AMD 與 Intel（INTC） 加入代表競爭對手的 CPU 也能成為 NVIDIA GPU 系統的主機，這是平台開放度的訊號，但原文沒有說明時程。MGX 的訴求是讓伺服器廠節省開發時間並維持設計與效能一致，在一年一代的節奏下，這種可重複使用的參考設計更顯重要。

官方表示，Spectrum-X 乙太網路將每年更新，網路效能比傳統乙太網路高 1.6 倍。

1.6 倍的比較對象是『傳統乙太網路』，原文沒有給測試條件。CoreWeave、Lambda 等 AI 雲端業者被列為首批採用者，顯示網路速度已成為 AI 叢集的關鍵瓶頸之一。

通鑑怎麼看

通鑑認為，Rubin 這次只是路線圖預告，沒有規格可供查核；真正值得記錄的是「一年一代」承諾，因為它會牽動 HBM、先進封裝與散熱的升級節奏。
