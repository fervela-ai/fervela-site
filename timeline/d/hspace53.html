Project Kuiper 正式改名 Amazon Leo（AMZN）

Amazon（AMZN） 宣布衛星網際網路計畫 Project Kuiper 的永久品牌為 Amazon Leo，並表示已有 150 多顆衛星在軌道上。

這是什麼

Project Kuiper 是 Amazon（AMZN） 的低軌衛星通訊計畫，原本使用的是內部代號。這則短文宣布代號退場、正式品牌上線，同時交代計畫目前的規模與已簽約的客戶。

三點帶走

  1. Project Kuiper 正式改名 Amazon Leo（AMZN）。
  2. 官方稱已有 150 多顆衛星在軌，並有多家客戶與夥伴簽約。
  3. 服務將在增加覆蓋與容量後開始推出，未給日期。

重點與分析

官方表示，計畫七年前啟動，最初是少數工程師與紙上設計，內部代號取自古柏帶（Kuiper Belt）；現在永久品牌定為 Amazon Leo（AMZN），取低地球軌道（LEO）之意。

這次改名的意義主要在對外：代號用於研發期，品牌則面向客戶。官方說長期使命不變，即讓缺乏高速網路的人與機構取得連線。改名本身不代表服務內容改變，而是計畫進入對客戶推出的階段，因為文章同時說明「將在增加覆蓋與容量後開始推出服務」。

官方表示，Amazon（AMZN） 現在營運全球最大的衛星生產線之一，並已有 150 多顆衛星在軌道上；今年稍早部署了第一批完整的量產衛星。

150 多顆是目前的部署進度，並非可提供連續服務的規模，官方在同段後面也明確說還要擴建初期星座。這段也提到計畫的里程碑：取得初步執照、簽下史上最大規模的發射合約、完成原型任務，這些是官方對自身進度的整理，文章沒有提供各項合約的細節。

官方表示，已有 JetBlue、L3Harris、DIRECTV Latin America、Sky Brasil 與澳洲 NBN Co 等客戶與夥伴簽約，準備部署服務。

官方同段說 Amazon（AMZN） 已發明史上最先進的客戶終端之一，包括首款支援 Gbps 等級速度的商用相位陣列天線。客戶名單涵蓋航空、國防通訊、衛星電視與批發寬頻，顯示 Amazon 把重點放在企業與合作夥伴，而不只是一般家庭用戶。稿件說的是「signing up to deploy」，也就是簽約並準備部署，沒有說明已開始提供服務的客戶，也沒有公布服務開通的時間表。

通鑑怎麼看

通鑑認為，這是一則品牌與進度說明：Kuiper 這個代號正式退場，重點是 Amazon（AMZN） 宣告計畫從建造期邁向對外服務。但服務何時開通，文章只說「增加覆蓋與容量之後」，沒有日期。
