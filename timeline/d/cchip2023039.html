NVIDIA 推六款 RTX Ada 工作站 GPU，含 1,250 美元的 RTX 4000 SFF｜NVIDIA｜3 月 21 日 事件延伸

NVIDIA（NVDA） 把 Ada 架構推進專業工作站，小卡也有 20GB 記憶體

NVIDIA（NVDA） 在 3 月 21 日 GTC 上推出六款 RTX Ada 世代工作站 GPU，鎖定設計師、工程師與資料科學家。

這是什麼

工作站 GPU 是給專業用途（電腦輔助設計、影視後製、科學運算、AI 開發）的顯示卡，和遊戲卡同架構，但搭配經過認證的驅動程式與較大記憶體。這次把 Ada Lovelace 架構擴展到行動工作站與小型桌機。

三點帶走

  1. NVIDIA（NVDA） 推五款 RTX Ada 筆電 GPU 與一款 RTX 4000 SFF 桌機卡。
  2. RTX 4000 SFF 具 20GB 記憶體，4 月起販售、預估 1,250 美元。
  3. 第四代 Tensor Core 支援 FP8，AI 訓練效能最高為上一代 2 倍。

重點與分析

官方表示，RTX 5000、RTX 4000、RTX 3500、RTX 3000 與 RTX 2000 Ada 世代筆電 GPU，效能與能源效率最高是上一代的 2 倍，最多 16GB 繪圖記憶體，本月起由工作站廠商推出。

一次推五款筆電 GPU，是要覆蓋從入門到高階的行動工作站價位。對專業使用者而言，16GB 記憶體上限決定了能載入多大的 3D 模型或 AI 模型，記憶體容量往往比算力更先碰到天花板。「最高 2 倍」是和上一代比的上限值，各型號實際差異稿中沒有列出。

官方表示，桌機用的 RTX 4000 SFF（小尺寸）Ada 世代 GPU 配備新的 RT Core、Tensor Core 與 CUDA 核心，具 20GB 繪圖記憶體、頻寬高於上一代；4 月起由 Leadtek、PNY、Ryoyo Electro 等經銷商販售，預估售價 1,250 美元。

小尺寸卡要塞進迷你桌機，散熱與供電空間都很受限，能放進 20GB 記憶體是這張卡的賣點。1,250 美元的公開售價，讓 Ada 架構的專業卡有了相對親民的入口。官方舉 Genetec 的例子，說明它也適合影像監控這類要同時解碼大量影片串流的應用，Genetec 稱效能最高提升 80%。

官方表示，新 GPU 採 Ada 架構：CUDA 核心單精度浮點吞吐量最高是上一代 2 倍；第三代 RT Core 吞吐量最高 2 倍，可同時執行光線追蹤與著色或降噪；第四代 Tensor Core 的 AI 訓練效能最高快 2 倍，並擴大支援 FP8 資料格式。

Tensor Core 支援 FP8，表示資料中心 H100 上用來加速 AI 的低精度格式，也下放到工作站卡。這讓開發者可以在桌上先用同樣的數字格式開發與測試模型，再搬到資料中心大規模訓練。RT Core 負責光線追蹤，是 3D 設計與數位分身模擬的關鍵。

官方表示，結合高階 NVIDIA（NVDA） GPU、智慧網路卡與最新 Intel（INTC） CPU 的新一代桌上型工作站，本月起由 BOXX、HP 與 Lenovo 等廠商推出；General Motors、Versatile Media 與 Layton Construction 等客戶已使用 RTX 6000 Ada 世代 GPU。

官方特別點名「智慧網路卡」（SmartNIC），表示工作站也開始重視高速網路，以便多人協作與連接資料中心。GM 用 RTX 6000 做車輛開發的虛擬實境測試、Layton 用於建築設計視覺化，顯示專業 GPU 的需求來自製造、影視與營建等產業。這則篇幅偏產品型錄，但補齊了 Ada 架構在專業市場的完整產品線。
