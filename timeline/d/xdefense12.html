Skydio 想讓無人機先抵達遠方現場

在產品發表會上，Skydio 發表固定翼無人機 F10 Lightrunner 與可供它自行起降的 MegaDock。

這是什麼

這是一套把遠距飛行、自動起降和機隊調度接在一起的系統。它要讓應變、搜救與巡檢團隊從固定據點派出無人機，在地面人員前往現場途中，提供現場的即時空中畫面。

三點帶走

  1. F10 把 Skydio 的無人機任務延伸到更遠的應變與巡檢現場。
  2. 自行起降與多機停放，是減少現場人手依賴的關鍵。
  3. 這次發表的核心是把飛行、持續觀察和既有工作流程接起來。

重點與分析

官方表示，F10 設計用於遠距應變、搜救與巡檢，預計交付客戶。官方宣稱它的最高時速可達 100 英里、飛行半徑為 30 英里；一座 MegaDock 的可及範圍接近 3,000 平方英里。

通鑑判斷，這解的是「看見現場」比「趕到現場」慢的卡關。Skydio 原有的 X10 從停機座出發，主要處理附近幾英里的任務；固定翼 F10 則把一個據點能看的範圍推向更遠處。對偏遠地區的應變團隊，先看到道路、地形與事件現況，便能更早判斷該派誰、帶什麼設備。難處在於遠距飛行要同時維持影像、通訊與航線安全，因此速度只是整套能力的一部分。

F10 以吸附式機械夾具自行發射及接回；MegaDock 可容納最多五架 F10。官方表示，停機座設計可在強風中起降，無人機可在夜間及中等雨勢下飛行。

通鑑認為，自行接回比自行飛出去更能決定這套系統能否成為日常工具。若每次出勤都得有人到場放飛、回收，遠距飛行仍受地面人手牽制。停機座能收納多架飛機，則讓同一據點有機會處理同時發生的任務，也能在一架返航充電時由另一架接手觀察。這讓無人機從單次出動的器材，走向可持續值勤的機隊；停機座與飛機的配合，和飛機本身一樣關鍵。

F10 的側置鏡頭避開機翼遮擋；官方表示，系統會在起飛前規劃航線，飛行中依環境與障礙物調整路徑，並在必要時避開附近的有人駕駛飛機。

通鑑判斷，這裡的重點是讓畫面不中斷，而非只讓飛機飛得遠。側置鏡頭像把觀察者移到不會被機翼擋住的位置；航線規劃則像出發前先看地圖，飛行中的調整是遇到變化後重新選路。追蹤對象若在轉彎時消失，應變人員拿到的就只是片段影像。Skydio 把鏡頭位置、飛行控制與空域資料一起設計，是為了讓遠方團隊能持續掌握同一個現場。

Skydio 同時發表 Asset Command 與 Security Command：前者把巡檢任務連到設備清單，後者讓保全團隊依警報派出無人機查看現場。兩套軟體已開放購買，預計之後全面供應。

通鑑認為，這改變的是工作從哪裡開始。巡檢人員原本要先安排飛行，再整理影像對應哪座設備；Asset Command 讓任務從既有設備清單出發，影像回來也跟著設備歸檔。保全人員收到警報時，Security Command 則把查看現場接進處理流程。F10 擴大了飛機能到的範圍，這兩套軟體處理的卻是另一個問題：飛回來的畫面能否直接幫團隊完成原本的工作。

通鑑怎麼看

通鑑認為，Skydio 這次真正要建立的是「遠方事件發生後，先派無人機看清楚」的工作方式。F10 負責抵達，MegaDock 負責反覆出勤，飛行控制維持畫面與安全，軟體再把結果送進應變、巡檢和保全流程。這些環節接得起來，遠距飛行才會成為團隊每天用得上的能力。
