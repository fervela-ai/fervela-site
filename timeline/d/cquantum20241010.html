D-Wave 為 Leap 量子雲端服務推出服務水準協議（SLA）｜D-Wave｜10 月 3 日 事件入門

D-Wave（QBTS） 以服務水準協議為量子雲端服務的正式上線背書

官方表示，D-Wave（QBTS） 為把應用移入正式環境的 Leap 量子雲端客戶推出服務水準協議，並稱過去兩年 Solver API 可用率持續超過 99.9%。

這是什麼

服務水準協議（SLA）是雲端服務商對可用率與效能做出的書面承諾。D-Wave（QBTS） 的 Leap 是讓客戶以雲端存取退火量子電腦與混合求解器的服務。這篇是 D-Wave 的新聞稿，宣布針對進入正式部署客戶的 SLA，並附上使用量與效能數字。

三點帶走

  1. 官方表示，Leap 的 Solver API 與退火機集合過去兩年可用率持續超過 99.9%。
  2. 自推出以來客戶已執行近 2 億次工作，過去 12 個月提交超過 6,000 萬個，成長 215%。
  3. SLA 的賠償條件與適用範圍在新聞稿中沒有說明。

重點與分析

官方表示，D-Wave（QBTS） 的監測資料證實 Leap 服務的 Solver API 與其量子退火電腦集合，過去兩年可用率持續超過 99.9%，即使需求高峰時仍高度回應。

99.9% 是 D-Wave（QBTS） 自己的監測數字，涵蓋的是 Solver API 與退火機的「彙總」可用率，不是單一機器。新聞稿沒有說明 SLA 的賠償條件或適用範圍，也沒有列出價格，所以看不出它對客戶的實際約束力。

官方表示，自 Leap 推出以來，客戶已執行近 2 億次工作，不必預先排程或等待漫長佇列，平均在量子處理器上處理一個工作只需零點幾秒。

近 2 億個工作聽起來龐大，但退火機的每個工作通常是一次短時間的取樣，工作數不能直接等同於運算量或商業價值。官方提供的「零點幾秒」依據是中位數取樣時間量測，這是 QPU 上的處理時間，不包含客戶端的前後處理。

官方表示，過去 12 個月 Leap 服務提交超過 6,000 萬個工作，較前 12 個月成長 215%，並稱最近的服務與 Ocean SDK 改進使處理速度再提升 30%。

使用量成長可以解讀為需求增加，但新聞稿沒有說明來自多少客戶，也不知道是否集中在少數大型用戶。30% 的速度改善同樣是官方數字，沒有說明是和哪一個版本或哪一種工作負載比較。因此這段只能證明使用量上升與公司宣稱的效能改善，無法推論客戶實際體驗的提升幅度。

官方引述 IDC 分析師 Heather West 的說法：科技領導者對量子雲端服務的期待，應與對任何軟體即服務的期待相同，可靠性與可及性是首要標準。

這段話出自第三方分析師，說明為什麼 SLA 是量子服務走向正式使用的條件之一。但引述本身是意見而非對 D-Wave（QBTS） 服務的獨立評測。D-Wave 的技術長 Trevor Lanting 則說，SLA 是為回應客戶加速轉向正式部署而設計。

通鑑怎麼看

通鑑認為，這是量子退火服務商業化的訊號而非技術突破：重點是把可用率寫成合約承諾。所有數字都來自 D-Wave（QBTS） 自己的監測，且新聞稿沒有披露 SLA 條款細節，後續要看客戶採用情形。
