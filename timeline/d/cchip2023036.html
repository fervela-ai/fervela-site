Oracle（ORCL） 雲端導入 BlueField-3，讓 CPU 專心跑客戶程式

NVIDIA（NVDA） 在 3 月 21 日宣布 Oracle（ORCL） Cloud 採用第三代 DPU BlueField-3，延伸 OCI 長期把基礎設施工作移出 CPU 的做法。

這是什麼

DPU（資料處理器，data processing unit）是裝在伺服器網路卡位置的專用晶片，負責網路封包處理、加密、儲存存取等「基礎設施工作」。這些工作原本吃掉 CPU 的運算力，交給 DPU 之後，昂貴的 CPU 核心就能留給客戶的應用程式。

三點帶走

  1. Oracle（ORCL） Cloud 採用 NVIDIA（NVDA） BlueField-3 DPU 卸載基礎設施工作。
  2. 官方稱使用 DPU 的伺服器功耗最多降低 24%。
  3. BlueField-3 支援 400 Gb/s，運算與記憶體頻寬為前代 4 倍。

重點與分析

官方表示，OCI 選擇 BlueField-3 DPU 做為網路架構的最新元件，讓客戶多一個把資料中心工作從 CPU 卸載的選項；官方稱 OCI 藉此延伸其長期以來把基礎設施工作移出 CPU 的做法。

大型雲端業者是 DPU 最主要的客戶，因為它們要在同一台伺服器上安全地出租給很多客戶，網路隔離與加密的負擔特別重。稿中說是「延伸」既有做法，表示 OCI 本來就有自己的卸載方案，這次是加入 NVIDIA（NVDA） 的晶片。具體部署規模與用在哪些服務，稿中沒有說明。

官方表示，測試顯示使用 BlueField DPU 的伺服器，功耗比不使用 DPU 的伺服器最多降低 24%；BlueField-3 支援最高 400 Gb/s 的乙太網路與 InfiniBand。

24% 的省電數字是「最多」，而且是 NVIDIA（NVDA） 自己的測試，具體情境未交代。但方向合理：專用晶片處理固定工作通常比通用 CPU 有效率。400 Gb/s 的網路速度則對應 AI 叢集對高速網路的需求，DPU 在 AI 資料中心裡也負責讓 GPU 之間的資料流動更順。

官方表示，BlueField-3 與上一代相比，運算能力高 4 倍、加密加速最高快 4 倍、儲存處理快 2 倍、記憶體頻寬高 4 倍；並透過 DOCA 軟體框架維持完整向下相容，提供零信任安全功能。

DOCA 是 NVIDIA（NVDA） 為 DPU 準備的開發框架，角色類似 GPU 上的 CUDA：讓開發者寫一次程式、在不同代 DPU 上執行。零信任（zero-trust）指預設不信任任何連線、每次都要驗證，對多租戶雲端特別重要。和 GPU 一樣，NVIDIA 在 DPU 上也是用「晶片＋軟體框架」綁住生態系。

通鑑怎麼看

通鑑認為，這則提醒我們 AI 資料中心不只有 GPU，網路與基礎設施晶片同樣在升級。DPU 讓 CPU 專心跑應用、讓網路更安全，是雲端業者降低成本的另一條路。
