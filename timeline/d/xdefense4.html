Skydio 把無人機偵察的重點從飛行改成接力

Skydio 推出 ISR Command，讓 X10D 無人機的飛行、追蹤、交接與戰術資訊共用同一套任務流程。

這是什麼

像派人在高處持續盯住一輛車，還要把位置傳給需要行動的人。ISR Command 把這些工作接進同一台控制器，讓小型部隊管理 X10D 機隊。

三點帶走

  1. X10D 可在不依賴衛星定位的情況下導航，系統分擔飛行與追蹤工作。
  2. 官方表示，一名操作員可管理兩架飛機，讓觀察任務在換電池時接力。
  3. ISR Command 把目標位置與影像接進戰術網路，重點是讓其他單位跟上現場變化。

重點與分析

官方表示，X10D 能靠機上攝影機在飛行中繪製地形，不依賴衛星定位導航；系統也能處理飛行、目標追蹤、保持距離與避障。

通鑑判斷，這解開的是操作員必須一面看目標、一面顧飛機的卡關。偵察任務中，車輛可能移動，地面也可能有障礙；只要操作員把注意力轉去修正航線，就少了一分辨認現場變化的心力。把飛行細節交給系統後，人可以集中決定該盯哪個目標、變化是否重要，以及該通知誰。不依賴衛星定位也切中受干擾環境的需求，讓任務規劃不必把定位訊號當成唯一前提。

官方表示，操作員可在畫面上選定目標，由系統追蹤並透過 TAK 與 NGC2 更新位置；飛行介面也能與其他 TAK 使用者交換標記和訊息，並向指揮所、鄰近單位及任務團隊傳送即時影像。

通鑑認為，改變最大的是資訊從無人機送到其他人的環節。過去若飛手看著影像，再換裝置報告位置，接收者拿到的可能已是上一刻的情況。ISR Command 讓目標位置隨追蹤更新，並把影像、飛機位置和任務標記放進戰術網路；飛手仍負責判斷目標，其他單位則能依同一份位置資訊協調。它的價值因此不只在拍到畫面，更在縮短看見變化到共同掌握變化的距離。

官方表示，一名操作員可用同一台控制器管理兩架 X10D。當其中一架需要返航換電池，系統會提示準備另一架，並協助接手觀察。

通鑑判斷，這是整套產品最具體的設計：電池用完不必等於觀察中斷。接力難在新飛機要找到同一個目標，操作員還得同時掌握返航中的飛機與現場狀況。ISR Command 讓接手飛機前往任務位置，並在同一台控制器上保留任務資訊，減少重新找目標、重新交代背景的工作。對人手有限的小型部隊，這比單純增加無人機數量更有意義，因為新增飛機若也要新增飛手，持續偵察仍會受人力限制。

Skydio 表示，ISR Command 已可使用，並支援把固定或移動目標的位置資料嵌入影像串流，提供其他系統接收。

同領域的自主系統各有切入點：Helsing 的 Contra 著重協調感測器與攔截器，Leonardo 則將用 Shield 的 Hivemind 開發無人旋翼機能力。通鑑判斷，Skydio 走的是另一條路：先把已在空中的偵察機、操作員與戰術網路接成一條連續流程。接下來最能看出成效的，是實際任務中換機時能否持續追蹤同一目標，以及其他單位收到的位置能否跟上目標移動；這兩個環節會決定整合是否真正減輕現場負擔。

通鑑怎麼看

通鑑認為，ISR Command 的核心進展是讓偵察成為可交接、可共享的任務，而非單架無人機的一段影像。自動飛行減少操作負擔，換機接力延長觀察，戰術網路則讓觀察結果抵達能採取行動的人；三個環節接起來，才是小型部隊能否持續掌握目標的關鍵。
