Anthropic 與 SpaceX 算力合作｜Anthropic｜5 月 6 日 事件入門

Anthropic 擴大算力，先讓 Claude 的使用額度有感

Anthropic 宣布與 SpaceX 達成資料中心算力合作，同時提高 Claude Code 與 Claude API 的使用額度。

這是什麼

這是一項擴充 Claude 運算資源的合作。Anthropic 將使用 SpaceX 的 Colossus 1 資料中心容量，並調整部分訂閱方案及開發者介面的使用上限。對使用者而言，關鍵是忙碌時能否更穩定地使用 Claude。

三點帶走

  1. Claude Code 部分方案的使用上限已提高，但仍有額度限制。
  2. SpaceX 合作增加的是運算容量；實際使用體驗仍需觀察。
  3. 軌道 AI 算力目前只是表達合作興趣，尚非已啟用的服務。

重點與分析

官方表示，Claude Code 的 Pro、Max、Team 與按席位計費的企業版，五小時使用上限翻倍；Pro、Max 帳戶在尖峰時段也不再被額外調低上限。

通鑑判斷，這是最容易讓現有使用者感受到的改變：頻繁使用 Claude Code 的人，可能較少在工作途中碰到額度限制。不過，尖峰時段不再額外降額，並不等於可以無限制使用；各方案原本仍有使用上限。評估訂閱方案時，應看自己的工作量是否常碰到上限，而非只看翻倍這個幅度。

官方表示，將使用 SpaceX 的 Colossus 1 資料中心全部運算容量；官方宣稱，可在本月內取得超過 300 百萬瓦的新容量，包含超過 22 萬顆 NVIDIA GPU。

通鑑判斷，這筆合作的重點在於新增容量的規模與取得速度，而非使用者會接觸到哪座資料中心。Anthropic 表示，新增容量將直接改善 Claude Pro 與 Max 訂閱者可用的容量；實際能改善多少等待或額度問題，仍值得觀察。協議涵蓋資料中心全部容量，也不能直接推定每位訂閱者都會分到固定資源。

官方表示，Claude Opus 模型的 API 速率限制也大幅提高；同一批額度調整已生效。官方文字內未列出具體數值，而是指向下方表格。

通鑑判斷，對把 Claude 接進內部工具或服務的團隊，速率限制提高可能比個人訂閱額度更實用：同一時間能處理多少請求，會影響尖峰時的排隊與系統設計。但文字內沒有具體數值，就無法從文字說明估算特定團隊的增幅。需要確認實際效益的人，應核對自己帳戶適用的模型與限制。

官方表示，這項合作之外，Anthropic 仍有其他算力協議；它也向 SpaceX 表達合作開發軌道 AI 算力的興趣。

通鑑判斷，已簽訂的資料中心協議與表達合作興趣，是兩種不同進度。前者關乎近期可取得的運算資源；後者尚不能視為軌道設施已確定興建或投入使用。把兩者分開看，才能判斷哪些承諾可能影響眼前的 Claude 體驗，哪些仍屬需要觀察的未來方向。

通鑑怎麼看

通鑑判斷，這次公告對使用者最具體的意義，是 Claude Code 額度已調高、尖峰時段不再額外降額；SpaceX 合作則提供後續擴充容量的依據。兩者有關，但官方也提到其他近期算力協議，不能把所有額度變化都歸因於這一筆合作。接下來值得看的是，新增容量到位後，重度使用者的實際可用性是否持續改善。
