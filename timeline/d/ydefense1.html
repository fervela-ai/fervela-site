英國 Project NYX 選出七家無人僚機原型設計夥伴｜英國國防部｜1 月 24 日 事件推薦

英國要讓無人機成為 Apache 的空中僚機

英國國防部公布 Project NYX 原型設計夥伴，準備探索有人直升機與自主無人機協同作戰。

這是什麼

Project NYX 要開發能與 Apache 攻擊直升機協同行動的無人機。它的核心是讓無人機依任務指令，在任務參數範圍內自行調整行動，把部分偵察、打擊與電子戰工作交給無人機。

三點帶走

  1. Project NYX 要讓無人機協助 Apache 執行偵察、目標獲取、打擊與電子戰任務。
  2. 設計重點是讓無人機在設定的任務範圍內自行調整行動，減少逐步遙控的需求。
  3. 後續可查核研發合約選出哪些方案，以及概念展示機如何呈現協同能力。

重點與分析

官方表示，Project NYX 的無人機完成開發後，預計與 Apache 攻擊直升機協同行動，執行爭奪激烈區域的偵察與監視，以及目標獲取、打擊和電子戰任務。

通鑑判斷，這項設計要解的卡關，是直升機機組需要掌握前方情況，卻也得承擔靠近威脅區域的風險。無人機若能先去觀察、尋找目標，機組就多了一種取得資訊與安排攻擊的方式。難處在於這些任務彼此相連：找到目標後，資訊要能幫上直升機的決策；電子戰也要配合整體行動。原型設計能否把各項能力接成可協同的任務流程，比單獨列出無人機能做什麼更關鍵。

官方表示，這些無人機將採取設定任務、而非逐步遙控的方式，利用 AI 在任務參數範圍內自行決策，並隨戰場情況調整。

這比較像交代目的地與規則，讓同行者自己選路，而不是一路指示每個轉彎。通鑑認為，改變的是機組與無人機之間的分工：如果每次變化都要等待人下指令，無人機可能反而增加機組負擔；讓它在既定範圍內調整，機組才有機會把注意力放在整體任務。最難設計的因此不只是飛行能力，還包括任務界線要怎麼設定，讓無人機遇到突發情況時，仍能做出符合任務的選擇。

官方宣稱，七家業者獲邀提出 Project NYX 原型設計，名單包括 Anduril 英國公司、BAE Systems、Leonardo、Lockheed Martin（LMT） 英國公司、Syos Aerospace、Tekever 與 Thales 英國公司。

通鑑判斷，英國目前走的是先讓多家業者提出整套方案，再逐步篩選的路。這與同領域將自主軟體整合到既有無人機、透過飛行展示推進能力的做法，著力點不同：Project NYX 此階段要先比較各家如何設計與 Apache 協作的無人機。這會讓軍方有機會在原型製作前檢視不同構想，也把競爭焦點放在整體任務能力，而不只是單項設備性能。入選名單因此代表設計競爭開始，還不是最終機型名單。

官方當時預計於 2026 年 3 月從入選業者中再選出四家供應商，邀請並提供合約參與研發、製作概念展示機；初始作戰能力目標為 2030 年。

通鑑認為，接下來最有分量的事件，是哪些設計拿到研發合約，以及概念展示機能呈現什麼。前者會顯示軍方準備把資源投入哪些方案；後者才能讓外界看到，任務內自主調整與直升機協同如何實際接在一起。觀察時可分清兩個進度：選出供應商是採購與研發的推進，展示機則是技術成果。兩者都會影響計畫走向，但回答的是不同問題。

通鑑怎麼看

通鑑認為，Project NYX 最值得注意的，是英國把無人機定位為能在任務界線內自行調整的 Apache 僚機。成敗關鍵不只在無人機能否飛行或偵察，而在機組能否用清楚的任務指令，讓它協助完成連貫的作戰流程。下一輪研發合約與概念展示機，將讓這套分工更具體。
