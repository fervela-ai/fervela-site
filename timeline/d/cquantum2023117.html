Microsoft（MSFT） 與 Photonic 合作，從量子網路切入

官方表示，雙方要把 Photonic 的矽自旋量子位元與光子介面，結合 Azure 雲端基礎架構，做長距離量子通訊。

這是什麼

Photonic 是一家溫哥華的量子公司，用矽中的自旋量子位元，再用光子（光的粒子）連接，因此可走標準電信光纖與波長。這篇 Microsoft（MSFT） 部落格講的是合作的目標與分三階段的量子網路路線。

三點帶走

  1. 官方表示 Microsoft（MSFT） 與 Photonic 以矽自旋—光子架構合作，從量子網路切入。
  2. 路線分三階段，第二階段的量子中繼器官方稱為從未示範過。
  3. 合作也計畫把 Photonic 硬體在可用時整合進 Azure Quantum Elements。

重點與分析

官方表示，Photonic 的架構以高度連接的矽自旋量子位元為基礎，具自旋—光子介面，能以超低損耗的標準電信光纖與波長通訊。

這是合作的技術基礎。用標準電信光纖與波長是官方強調的特點；不過原文沒有給出任何傳輸距離、糾纏速率等實測數據。

官方表示，雙方將處理量子網路三階段：第一階段在實體層讓兩個獨立量子裝置透過光子與電信光纖產生糾纏；第二階段在鏈路層做出尚未被示範過的量子中繼器；第三階段在網路層做出容錯且能與 Azure 運作的可靠量子中繼器。

量子中繼器（quantum repeater）是讓量子訊號跨越更長距離的關鍵元件。原文自己承認第二階段的中繼器是「從未示範過」的，所以這些是目標，不是成果。

官方表示，合作也計畫在 Photonic 的量子硬體可用時，將它整合進 Azure Quantum Elements，針對科學探索的 Level 1（基礎量子運算），並承諾朝更高的可靠度與規模邁進。

Level 1 到 Level 3 是 Microsoft（MSFT） 自己提出的量子超級電腦發展分級，官方稱先前（原文為 last June）已公布通往 Level 3 的路線圖。新聞稿沒有給出硬體交付時間表。

官方表示，Microsoft（MSFT） 高層 Jason Zander 稱，除了運算，網路與感測也將開啟新能力；Photonic 創辦人 Stephanie Simmons 稱需要全球生態系。

這兩段引述屬於合作雙方的立場表述。這一頁沒有提到投資金額或雙方的財務安排。

官方表示，Photonic 創辦人 Simmons 稱沒有一家公司或國家能獨力解鎖量子運算；Microsoft（MSFT） 邀請讀者報名 Azure Quantum Elements 私人預覽。

私人預覽代表這項服務在當時尚未全面開放。原文沒有說 Photonic 硬體何時能被放進 Azure Quantum Elements，只用「可用時」帶過，這一點要與前面的路線圖目標分開看。

通鑑怎麼看

通鑑認為，這則的特別之處是它把量子網路（而非只看量子位元數）放在合作核心，並明確承認關鍵元件尚未被示範。後續要看哪個階段先出現可驗證的實驗結果。
