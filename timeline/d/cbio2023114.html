NVIDIA BioNeMo 將登陸 AWS 上的 DGX Cloud，推動生成式 AI 藥物探索｜NVIDIA｜11 月 28 日 事件進階

BioNeMo 登陸 AWS：藥物探索的生成式 AI 模型訓練更容易上雲

官方表示，這項宣布讓使用 AWS 的醫療與生命科學公司，可以用自己的專有資料建立或客製化數位生物學基礎模型。

這是什麼

BioNeMo 是 NVIDIA（NVDA） 為數位生物學打造的生成式 AI 框架，包含預訓練大型語言模型、資料載入器與最佳化訓練配方。這次的重點是它可以透過 AWS 的多種服務與 DGX Cloud 取得，而不再只限於 NVIDIA 自己的環境。

三點帶走

  1. 官方表示 BioNeMo 即將登陸 AWS 上的 DGX Cloud，目前已可經 ParallelCluster 與 SageMaker 使用。
  2. 官方宣稱 ESM-2 在 256 張 H100 上近乎線性擴展，512 張可在幾天內完成訓練，原論文時間為一個月。
  3. 官方列出 Alchemab、Basecamp Research 等六家公司為使用者，但未提供成果數字。

重點與分析

官方表示，NVIDIA（NVDA） 在 AWS re:Invent 宣布，生技與製藥開發者可在 AWS 上部署 NVIDIA Clara 軟體與服務，BioNeMo 即將登陸 DGX Cloud。

稿中同時有兩種狀態：『即將』登陸 DGX Cloud on AWS，與『目前已可』透過 AWS ParallelCluster 和 Amazon（AMZN） SageMaker 使用。對讀者來說，現在已經能用的是後者。官方稿稱數千家醫療與生命科學公司已在使用 AWS，這代表此次的訴求是降低既有 AWS 用戶導入的門檻，而不是新增一個模型。

官方表示，Alchemab、Basecamp Research、Character Biosciences、Evozyne、Etcembly 與 LabGenius 已在使用 BioNeMo。

這份名單是官方稿自己列出的使用者，稿中描述他們用於生成式 AI 加速的藥物探索與開發，但沒有給出每家公司用 BioNeMo 做出什麼具體成果。『已使用』的證據在於這些公司的名稱，而不在於成果數字；若要評估效益，需要各公司自己公布的專案資料，這份官方稿本身無法回答。

官方表示，ESM-2 可在 256 張 H100 上近乎線性擴展，擴到 512 張可在幾天內完成訓練，原論文公布為一個月。

『近乎線性擴展』指 GPU 數量增加時，速度幾乎同比例增加，是這段最具體的效能宣稱。對比對象是『原論文公布的一個月』，並非在同一硬體上的重跑，所以幾天對一個月不是嚴格的同條件比較。稿中也說明可使用 6.5 億與 30 億參數兩種規模的檢查點來訓練 ESM-2。

官方表示，BioNeMo 支援 MegaMolBART 與 ProtT5；Parabricks 可在約 15 分鐘內完成一個人類全基因體的變異呼叫。

另一組數字是 Project MONAI 的醫學影像工作流程已下載超過 180 萬次；Parabricks 的對照組是『只用 CPU 的系統需要一天』。MONAI 與 Parabricks 是 NVIDIA（NVDA） Clara 在 AWS 上提供的另外兩條線：影像與基因體。這些資料顯示 NVIDIA 想把藥物探索、影像與基因體三塊整合在同一個雲端選單，不過稿中未提供第三方的獨立比較，15 分鐘對一天是公司自行比較的結果。

通鑑怎麼看

通鑑認為，這則新聞的本質是散布管道的擴大：模型與框架早已存在，這次是讓 AWS 上的使用者更容易取得。效能數字（256 張到 512 張 H100、幾天對一個月）是官方自述，且對照基準是原論文時間，閱讀時要注意口徑。
