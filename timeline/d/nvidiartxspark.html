NVIDIA 押注 Windows 上的本機 AI 代理

COMPUTEX 的 GTC Taipei 場合，NVIDIA 發表 Windows 電腦 RTX Spark，並說明 OpenShell 與一批今年秋季到位的軟體更新。

這是什麼

NVIDIA 在 GTC Taipei 發表 RTX Spark，是專為本機個人 AI 代理打造的 Windows 電腦。官方搭配 OpenShell 與微軟安全機制，Adobe、Blender 等更新官方說今年秋季到位。

三點帶走

  1. RTX Spark 預計今年秋季上市，官方宣稱最高 1 petaflop 與 128GB 統一記憶體，售價和各機型差異官方文字沒有。
  2. 權限、改走本機、送雲端前遮住資料，以及看螢幕操作，官方都寫成做得到或即將提供，不是買來就代勞。
  3. 官方宣稱 Qwen 的 2 倍與 1.6 倍在 GeForce RTX 5090，2.6 倍是 DGX Spark 對舊檢查點，不宜當成 RTX Spark 速度。

重點與分析

官方宣稱，RTX Spark 有最高 1 petaflop AI 運算與 128GB 統一記憶體，能應付裝置上代理的需求。官方宣稱它涵蓋 AI、創作與遊戲，把三十年技術放進可全天續航的輕薄 Windows 筆電與高效率桌機，預計今年秋季上市。

官方文字說明沒有售價與具體型號，也沒寫最高 1 petaflop 出自哪一種測試。通鑑判斷：較好對照的是官方宣稱的 128GB 統一記憶體，因為本機代理同時處理檔案與模型時，記憶體往往先吃緊。最高只是上限，筆電與桌機有沒有同一數字，官方文字沒有分開。全天續航沒有電量與情境。值得觀察代理是否預設可用，或要另裝其他應用。官方把硬體與軟體放同一季，沒有寫成開箱即用。

官方表示，即將登上 Windows 的 OpenShell，讓使用者規定代理能做與不能做的事，可依隱私政策導向本機模型，並在送雲端前遮住個人資料。官方並說，新的 Windows 應用將能執行軟體任務、跨應用流程、產生影像與影片，以及語意搜尋本機檔案。

通鑑判斷：對上班族，權限與資料要不要離開電腦，比規格更接近每天的工作。通鑑判斷：官方寫的是做得到，不是已發生的結果，也不代表預設打開。值得觀察設太鬆或太緊會怎樣，官方文字沒有舉例。官方另表示 Hermes Agent 與 OpenClaw 會把 OpenShell 與微軟安全機制放進新 Windows 應用。可能要等這些應用，才會碰到跨軟體與搜檔；此前不宜看成買了就代勞。

官方表示，H Company 的工具讓 AI 代理看螢幕並操作滑鼠與鍵盤，無程式介面的軟體也能用，即將提供給支援本機模型的 RTX 與 DGX 電腦。官方宣稱量化並加快後，在 NVIDIA GPU 上達 2 倍、記憶體少 35%。模型現可下載，桌面版即將推出。

通鑑判斷：看螢幕並代為點選，接近仍用舊軟體的情境，官方點明沒有程式介面也能操作。官方寫的是即將提供，而且要支援本機模型的 RTX 與 DGX，不是現在就能在 RTX Spark 上使用。官方宣稱的 2 倍與少 35% 記憶體，是量化 Holo 模型並加快操作層後在 NVIDIA GPU 上取得，官方文字沒有寫顯示卡型號、操作項目與對照版本。值得觀察桌面版上市時是否還要自己下載模型。

官方宣稱，含多詞元預測等調整後，Qwen 3.6 與 3.5 的 27B 為 2 倍、35B 為 1.6 倍；附圖寫明 GeForce RTX 5090 上，Qwen3.6-27B 吞吐量最高 2 倍、35B 最高 1.6 倍，可經 llama.cpp 與 LM Studio 取得。

通鑑判斷：這兩個倍數最容易被當成 RTX Spark 的速度，官方附圖寫的是 GeForce RTX 5090。正文寫 Qwen 3.6 與 3.5，圖說只寫 Qwen3.6，而且只有圖說標了最高，條件並不是同一句。官方另宣稱，DGX Spark 上 Qwen 3.6 35B，經 vLLM 優化加新 NVFP4 檢查點後，效能是先前 Unsloth 版 NVFP4 檢查點的 2.6 倍，比的是舊檢查點，電腦也不是 RTX Spark。官方文字把三台機器分開寫。

通鑑怎麼看

通鑑判斷：這次發表把 Windows 的權限隱私，和一台宣稱撐得住的電腦放在同一批消息。上班族會不會少花時間，取決於代理能否在受控下操作舊軟體與自己的檔案。官方的倍數分屬 RTX 5090、NVIDIA GPU 與 DGX Spark，秋季之前換不成省下的工時。值得觀察最高算力落在哪些機型、看螢幕操作是否納入權限，以及應用是否同期出現。在那之前，它仍是路線圖。
