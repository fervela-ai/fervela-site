AMD EPYC 進入 AWS 專用高效能運算執行個體

AMD 在 1 月 12 日表示，AWS 的 Hpc6a 執行個體已正式上線，使用第 3 代 EPYC，目標是雲端上的科學與工程運算。

這是什麼

高效能運算（HPC）是指流體力學、氣象預報、基因體學這類需要大量運算的工作。EPYC 是 AMD 的伺服器處理器，這則是 AWS 把它做成專為 HPC 設計的雲端租用規格。

三點帶走

  1. AWS Hpc6a 採第 3 代 AMD EPYC，專為雲端 HPC 設計，1 月 12 日正式上市。
  2. 依 AWS 說法，性價比比同類執行個體最多高 65%。
  3. 初期只在美東（俄亥俄）與 GovCloud（美西）提供。

重點與分析

官方表示，Amazon（AMZN） EC2 Hpc6a 執行個體由第 3 代 AMD EPYC 處理器驅動，專為雲端 HPC 工作負載設計，並已正式上市。

這是 AWS 為 HPC 另外做的專用規格，而不是通用型執行個體。稿中列出適用的工作：基因體學、計算流體力學、天氣預報、金融風險建模、半導體設計用的 EDA、電腦輔助工程與地震成像。其中「EDA」值得留意，因為晶片設計本身也是吃算力的雲端用戶。

官方表示，依 AWS 的說法，Hpc6a 的性價比比同類 Amazon（AMZN） EC2 運算最佳化執行個體最多高 65%。

這個 65% 是 AWS 提供、由 AMD 引用的數字，而且是「最多」，稿中沒有交代拿哪一型執行個體當比較對象，也沒有附測試工作內容。所以它是供應商說法，不是獨立評測。價格與效能比的好壞還要看客戶實際工作如何分配在核心與網路上。

官方表示，EPYC 處理器驅動最新 Top500 榜單中的 73 套超級電腦，並創下 70 項 HPC 世界紀錄；Hpc6a 目前在美東（俄亥俄）與 AWS GovCloud（美西）提供。

AMD 用 Top500 的 73 套與 70 項紀錄，說明 EPYC 在 HPC 的地位，並稱「從實驗室的百億億次級系統到雲端彈性規格」都有它。這些是 AMD 自己選用的佐證數字。至於可用區域，稿中只列兩個，並說更多區域「即將」開放，沒有給出時間。

通鑑怎麼看

通鑑認為，這則的意義是雲端業者把 AMD 伺服器處理器包成 HPC 專用規格，讓沒有自建機房的研究單位也能租用，但 65% 的性價比仍是供應商自己的說法。
