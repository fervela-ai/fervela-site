Ranovus 的 Odin 光學 I/O 核心可用於 GF Fotonix 矽光子平台

Ranovus 把光學 I/O 做成可在 GlobalFoundries 300 毫米晶圓平台上製造的 IP 核心與小晶片。

這是什麼

Odin 是 Ranovus 的光學引擎，這次公布它的 100Gbps 光學輸入輸出核心（可當作 IP 或小晶片）已可在 GlobalFoundries 的 GF Fotonix 平台上生產。GF Fotonix 把矽光子與射頻 CMOS 做在同一片矽晶圓上。

三點帶走

  1. Ranovus 宣布 Odin 100G 光學 I/O 核心可用於 GF Fotonix 平台，8 核至 32 核同面積。
  2. 官方稱基於 GF Fotonix 的樣品已開始出貨，但未寫對象與數量。
  3. 單片矽光子的『業界首個』為廠商宣稱。

重點與分析

官方表示，Ranovus 宣布與協定無關的 Odin 100G 光學 I/O 核心上市，基於 GlobalFoundries 剛發表的次世代單片平台 GF Fotonix；官方稱 GF Fotonix 是業界首個在同一矽晶圓結合 300 毫米光子與 RF-CMOS 特色的平台。

『monolithic（單片）』指光學與電子電路做在同一片晶圓，而不是分開製造再組裝。這對 CPO 的意義是縮短封裝步驟、利於大量生產，但『業界首個』是 Ranovus 轉述 GF 的宣稱，稿中沒有獨立佐證。

官方表示，Odin 100G 光學 I/O 小晶片與 IP 核心可與處理器、交換器與記憶體裝置整合，用於機器學習、AI、元宇宙、雲端、5G 以及國防航太等資料中心架構，並可在相同面積內從 8 核擴充到 32 核。

稿中列舉的應用範圍很廣，其中『metaverse（元宇宙）』屬行銷用語，沒有對應的規格或客戶。8 到 32 核的擴充意味頻寬可成倍增加，但稿中沒有寫出總頻寬、功耗或每核通道數等關鍵數字。

官方表示，Ranovus 已發展類比驅動 CPO 2.0 架構與一級生態系，用於 Odin 小晶片的大量製造；首個採用 800Gbps Odin 光學 I/O 的客戶共封裝方案也在 OFC 2022 展示，基於 GF Fotonix 的樣品『現正出貨』。

『samples shipping now』指的是樣品而非量產，這點與同週的 Marvell（MRVL） 800G DSP（稿中明寫 volume shipments）有程度差異。稿中也沒有寫樣品交給誰、數量多少。

官方引述 GF 副總 Anthony Yu 表示，資料中心、運算與感測應用需要極高的處理與傳輸效率，Ranovus 的 IP 核心、小晶片與先進封裝，搭配 GF Fotonix，提供客戶完整的方案；官方並稱兩家公司展位分別為 5917 與 4604。

GF 官員的引言說明這是晶圓代工與光學 IP 公司的生態合作，並非 GF 單獨公布。完整評估需要對照 GF 自己的 GF Fotonix 發表資料，本稿未包含該平台的規格細節。

通鑑怎麼看

通鑑認為，這則顯示光學 I/O 正從『專用光引擎』走向『可在標準晶圓平台量產的 IP 與小晶片』。重要訊號是樣品已出貨，但缺少頻寬與功耗數字，需等後續客戶或量測資料。
