AWS 發表 Graviton4 與 Trainium2

官方表示，Graviton4 是 AWS 目前最強也最省電的處理器，Trainium2 則針對大型模型訓練。

這是什麼

Graviton 是 AWS 自行設計的 Arm（ARM） 架構通用處理器；Trainium 是 AWS 專為訓練 AI 模型設計的晶片。這則新聞發表兩者的下一代，並列出首批客戶。

三點帶走

  1. Graviton4：效能最高 +30%、核心 +50%、記憶體頻寬 +75%（對 Graviton3）
  2. Trainium2：訓練最高 4 倍、記憶體 3 倍、每瓦效能最高 2 倍（對第一代）
  3. 官方叢集上限寫 100,000 顆晶片、65 exaflops，均屬設計目標

重點與分析

官方表示，Graviton4 相較 Graviton3 運算效能最高提升 30%、核心數多 50%、記憶體頻寬多 75%，並對所有高速實體硬體介面全面加密。

三個百分比都是『最高』並以 Graviton3 為基準。全面加密實體介面是這一代新增的安全特色，原文沒有說明加密對效能的影響。官方同時說，目前已有超過 200 萬顆 Graviton 處理器、150 種以上 Graviton 執行個體類型與超過 50,000 位客戶。

官方宣稱，Graviton4 將用於 R8g 記憶體最佳化執行個體，vCPU 與記憶體最高為 R7g 的 3 倍；R8g 現已開放預覽，數月內正式上市。

R8g 面向大型記憶體內資料庫與分析工作。倍數同樣是『最高』，且為預覽階段，正式上市時間只說『未來數月』。Epic、Datadog、Honeycomb 等客戶評語多為測試後的正面感想，不能直接當成效能數據。

官方宣稱，Trainium2 訓練速度最高為第一代的 4 倍、記憶體容量 3 倍、每瓦效能最高 2 倍，每個 Trn2 執行個體含 16 顆晶片。

官方原文寫的是最高 100,000 顆晶片，總運算可達 65 exaflops，並稱可在數週而非數月內訓練 3,000 億參數的語言模型。這些都是設計目標，原文以『designed to』『將能』措辭。

官方表示，Anthropic、Databricks、Datadog、Epic、Honeycomb、SAP 等客戶使用新晶片；Anthropic 預期 Trainium2 在部分關鍵工作負載至少比第一代快 4 倍。

Anthropic 的說法是『預期』，而不是已測得，並說正在與 AWS 合作用 Trainium 開發未來的基礎模型。這則稿的重點因此是：AWS 把自研訓練晶片和外部 AI 公司的實際需求綁在一起，而非單純公布規格。

官方表示，Graviton 支援多項 AWS 託管服務，客戶包含 Datadog、DirecTV、F1、Pinterest、Snowflake、Stripe 等。

客戶名單用來證明 Graviton 已非實驗品：稿中說明它被用於資料庫、分析、網站伺服器、批次處理、廣告投放與微服務等一般工作。這和仍屬規劃的 Trainium2 形成對比：Graviton 已有大規模實際部署，而 Trainium2 在稿中的照片標示仍為 prototype（原型）。

通鑑怎麼看

通鑑認為，Trainium2 與 Graviton4 同日發表，顯示雲端業者把通用處理器與 AI 訓練晶片雙線自研。與同日同場 AWS 對 NVIDIA（NVDA） 的合作公告並讀，更能看出自研晶片是補充而非取代 GPU。
