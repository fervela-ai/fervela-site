AMD 推出 Instinct MI210：把 MI200 家族帶進 PCIe 外形

官方表示，MI210 搭配 ROCm 5，並有多家系統廠商與獨立軟體廠商加入支援。

這是什麼

Instinct 是 AMD 的資料中心加速器產品線，ROCm 是 AMD 的開放 GPU 運算軟體平台。

三點帶走

  1. MI210 是 PCIe 外形的 MI200 家族新成員。
  2. ROCm 5 擴大硬體與作業系統支援。
  3. 生態系的擴張數字多為官方宣稱。

重點與分析

官方表示，AMD 宣布 Instinct MI210 加速器上市，採 CDNA 2 架構，PCIe 外形，並以 ROCm 5 軟體組成「百億億次級技術」給主流使用者；MI200 家族因此多了一種可選的規格。

原文提到 MI200 系列已用於 Frontier 等超級電腦，MI210 的意義是把同類技術放進一般 PCIe 插卡，讓只想買單張卡的客戶也能使用。規格表中 MI210 有 104 個運算單元、64GB HBM2e、最高 1.6TB/s 頻寬；與同日 NVIDIA（NVDA） H100 的 HBM3 相比，AMD 這款仍是 HBM2e，這是兩份新聞稿直接可比的差異，但兩者面向的市場位置不同。

官方表示，ROCm 5 新增 MI200 與 Radeon PRO W6800 支援及 RHEL 8.5 支援；Infinity Hub 提供已最佳化的應用容器，Accelerator Cloud 讓客戶遠端試用。

ROCm 是 AMD 對應 NVIDIA（NVDA） CUDA 的開放軟體平台，軟體生態常是 AMD 加速器採用的瓶頸，因此官方在新聞稿中用大量篇幅列舉支援的應用（PyTorch、TensorFlow、GROMACS、NAMD 等）。Infinity Hub 與 Accelerator Cloud 都是降低試用門檻的做法。原文沒有提供各應用在 Instinct 上與其他平台的效能比較。官方列出的既有支援應用還包括 AMBER、GROMACS、NAMD、OpenMM、PyTorch 與 TensorFlow，但只說「支援」，沒有說明最佳化程度。

官方宣稱平台數量為前代兩倍，新增 Ansys 等軟體廠商；華碩（2357）、戴爾、技嘉（2376）、HPE、聯想與美超微提供系統。

這段是生態系宣稱：平台數量加倍是 AMD 自己對比前一代的數字，原文沒有給出具體平台個數。LUMI 的負責人在稿中引述，說他們用 MI210 先累積使用經驗，準備迎接 LUMI 完整部署，顯示 MI210 在這個案例也扮演開發機角色。

通鑑怎麼看

通鑑認為，AMD 在這份公告中把重點放在軟體與平台數量，而非單一硬體的突破。AMD 是否能縮小與對手的軟體生態差距，要看之後的應用移植與使用數據。
