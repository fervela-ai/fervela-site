NVIDIA Grace CPU Superchip 與 Grace Hopper 伺服器設計：台灣廠商首波採用｜NVIDIA｜5 月 23 日 事件延伸

NVIDIA（NVDA）：台灣廠商將推首批 Grace 伺服器

NVIDIA（NVDA） 在 Computex 發布四種 Grace 系統設計，涵蓋 AI、高效能運算、數位孿生與雲端遊戲。

這是什麼

Grace CPU Superchip 是 NVIDIA（NVDA） 把兩顆 Arm（ARM） 架構 CPU 用高速互連（NVLink-C2C）接在一起的模組；Grace Hopper 則是把 Hopper GPU 與 Grace CPU 接成同一模組。

三點帶走

  1. NVIDIA（NVDA） 公布 Grace CPU Superchip 與 Grace Hopper 的四種 2U 伺服器設計，台灣六家廠商首批採用。
  2. Grace CPU Superchip 最多 144 個 Arm（ARM） V9 核心、1 TB/s 記憶體子系統，兩顆 CPU 以 NVLink-C2C 相連。
  3. 機型預計 2023 上半年起出現，認證要等夥伴系統出貨之後。

重點與分析

官方表示，Grace CPU Superchip 由兩顆 CPU 晶片以 NVLink-C2C 一致性互連，最多 144 個 Arm（ARM） V9 核心，記憶體子系統頻寬 1 TB/s，記憶體頻寬與能源效率為當前領先伺服器處理器的兩倍。

這是 NVIDIA（NVDA） 把「兩顆晶片接成一顆」的做法用在 CPU 上：兩顆 CPU 以高速互連組成單一模組，而非單一大晶粒。「兩倍」是官方與「當前領先伺服器處理器」的比較，新聞稿沒有指名對象，也沒有附測試條件；144 核與 1 TB/s 則是規格值。

官方表示，Grace Hopper Superchip 以 NVLink-C2C 把 Hopper GPU 與 Grace CPU 接成一個模組，CPU 傳資料到 GPU 的速度比傳統 CPU 快 15 倍。

這個 15 倍的對象是「傳統 CPU」與 GPU 之間的資料傳輸，也就是繞過 PCIe 的瓶頸。這是 Grace Hopper 的核心賣點：把 CPU 與 GPU 的記憶體視為同一個系統來協同運作。原文沒有說明比較基準是哪一代 PCIe，因此倍數只能照字面理解。

官方表示，四種 2U 設計為 HGX Grace Hopper、HGX Grace、OVX（數位孿生）與 CGX（雲端遊戲，搭配 A16 GPU），皆含 BlueField-3 DPU。

四個設計對應的是同一組零件不同組合：Grace Hopper 或 Grace 加上 BlueField-3。NVIDIA（NVDA） 提供的是「藍圖與伺服器基板」，讓 ODM 與 OEM 廠商快速做成產品，意思是最終機型與價格由合作夥伴決定。稿中還提到 NVIDIA-Certified Systems 認證計畫將延伸到 Grace 伺服器，但首批認證要等夥伴系統出貨之後。

官方表示，ASUS、Foxconn Industrial Internet、GIGABYTE、QCT、Supermicro 與 Wiwynn 的數十款伺服器預計自 2023 上半年起出現。

時間點是「2023 上半年」且用的是 expected，距離公告約半年以上，這則因此是產品規劃而非現貨。NVIDIA（NVDA） 同時定位 Grace 系統「join x86 and other Arm（ARM）-based servers」，也就是不取代 x86，而是在其旁邊增加選項。副總裁 Ian Buck 的說法是 AI 工廠正在形成，這是 NVIDIA 對資料中心的定位語。

通鑑怎麼看

通鑑認為，這則新聞的實質是 NVIDIA（NVDA） 把「一致性晶片互連」從 GPU 擴到 CPU，並提供設計藍圖讓夥伴做機器；兩倍與 15 倍都是官方比較，實際系統要等 2023 才看得到。
