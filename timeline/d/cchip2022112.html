AWS 發表 Inf2、Hpc7g、C7gn：三款搭載自研晶片的 EC2 執行個體｜Amazon Web Services｜11 月 29 日 事件進階

AWS 推出 Inf2 等三款自研晶片執行個體

AWS 在 re:Invent 上宣布，三款新 EC2 執行個體分別用上 Graviton3E、第五代 Nitro 與 Inferentia2 三種自家設計的晶片。

這是什麼

AWS 自己設計晶片（Graviton 做通用運算、Inferentia 做機器學習推論、Trainium 做訓練、Nitro 負責網路與儲存卸載），再把它們包成 EC2 執行個體出租。這則新聞是三種新晶片同日登場。

三點帶走

  1. AWS 在 2022-11-29 宣布 Hpc7g、C7gn、Inf2 三款搭載自研晶片的 EC2 執行個體。
  2. 官方稱 Inf2 可執行最高 1,750 億參數的模型，相較 Inf1 最多 4 倍吞吐量、低 10 倍延遲。
  3. 稿中明說 Inf2 與 C7gn 當天為預覽，所有比較都是 AWS 自行列出。

重點與分析

官方表示，AWS 宣布三款新 EC2 執行個體，搭載三種新的 AWS 自研晶片：Hpc7g（Graviton3E）、C7gn（新 Nitro 卡）、Inf2（Inferentia2）。官方回顧，AWS 已有五代 Nitro、三代 Graviton、兩代 Inferentia 與 Trainium 晶片，並用雲端電子設計自動化（EDA）來加速設計與驗證。

這段說明 AWS 的自研晶片已經是成系列的產品線：負責通用運算、網路卸載、推論與訓練各有專屬晶片。稿中特別提到用雲端 EDA（在雲上跑晶片設計軟體）做設計與驗證，並稱 AWS 能以可預期的節奏推出採用更新、更省電製程的新晶片，這是官方對自家設計團隊速度的說法。三款執行個體中，稿中明說 Inf2 與 C7gn 當天以預覽形式開放，Hpc7g 的供應時間沒有交代，也沒有給出一般上市時間。

官方表示，Inf2 由新的 Inferentia2 晶片驅動，是第一款支援分散式推論（把大模型切到多顆晶片上）的推論專用 EC2 執行個體，可執行最高 1,750 億參數的模型；相較 Inf1 最多 4 倍吞吐量、最多低 10 倍延遲，且每瓦效能比 GPU 型執行個體最多高 45%；晶片間以 NeuronLink 連接，提供 192 GB/s 環狀頻寬。

Inf2 是這則最貼近 AI 晶片的部分。稿中把背景講得很直接：訓練每花 1 美元，推論最多要花 9 美元；Inf1 在 2019 年推出時，深度學習模型只有數百萬參數，之後模型已增加到數千億參數，大約成長 500 倍。分散式推論與 NeuronLink 的設計，就是為了讓超過 1,000 億參數的模型能切到多顆晶片上跑。稿中還提到支援隨機捨入（stochastic rounding，以機率方式進位以保持精度）與 CFP8 資料型態，但沒有給出各自帶來多少提升。45% 的比較對象是『GPU 型執行個體』，並未指名哪一款。

官方表示，Hpc7g 使用 Graviton3E，浮點效能最多是 C6gn 的 2 倍、比 Hpc6a 最多高 20%，提供 200 Gbps 的 EFA 網路頻寬，可擴展到數萬核心的 HPC 叢集；C7gn 使用第五代 Nitro 晶片的新 Nitro 卡，網路頻寬最多 2 倍、每秒封包處理最多高 50%，每瓦效能比第四代 Nitro 卡高 40%。

這兩款不是 AI 加速器，卻說明 AWS 自研晶片的另一半：Graviton3E 是強化浮點運算的 Arm（ARM） 架構處理器，Nitro 卡則把網路與 I/O 功能從主機 CPU 卸載到專用硬體，讓主機資源更完整地交給客戶的工作負載。稿中說明 HPC 客戶（如 AstraZeneca、Formula 1、Maxar Technologies）已在 AWS 上跑基因體、流體力學與天氣模擬，新晶片的目標是降低這類工作負載的成本。這些數字都是 AWS 對自家上一代產品的比較。

官方表示，客戶見證來自 Qualtrics、Finch Computing 等；Finch 稱遷移到 Inf1 後相較 GPU 降低了 80% 成本，並期待 Inf2 在延遲與吞吐量上的提升。

客戶見證能看出 Inf2 的目標使用者：Qualtrics 在做文字分類、關鍵詞抽取等多任務、多模態深度學習模型；Finch Computing 做即時自然語言處理。Finch 的 80% 成本降幅指的是 Inf1 對比 GPU，不是 Inf2 的成果，兩者不能混為一談。至於實際使用 Inf2 的結果，稿中的說法都是『期待』或『預計』，因為它在發布當天仍是預覽。

通鑑怎麼看

通鑑認為，這則的價值在於 AWS 同日展示三條自研晶片線，其中 Inf2 把『分散式推論』與每瓦效能當作面對大模型的賣點；所有效能比較都是 AWS 對自家前代或對『GPU 型執行個體』的說法，尚待實際使用情況驗證。
