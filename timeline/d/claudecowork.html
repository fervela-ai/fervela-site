Cowork 停在研究預覽，十億美元是 Claude Code 的成績

Anthropic 在擴大 Labs 的官方說明中，把以研究預覽推出的 Claude Cowork，與 Claude Code、模型上下文協定寫在同一套做法裡。

這是什麼

Claude Cowork 是 Anthropic 的桌面應用程式，以研究預覽把 Claude 的 AI 代理能力帶到桌面。官方只稱它是研究預覽，沒有說它已是客戶能依靠的產品。

三點帶走

  1. Claude Cowork 是 Anthropic 的桌面應用程式，以研究預覽把 AI 代理放到桌面；官方沒有說它已是客戶能依靠的產品。
  2. 官方宣稱 Claude Code 在六個月內從研究預覽成為十億美元產品，並宣稱模型上下文協定每月下載一億次；兩項都不是 Cowork 的數字，業界標準也是官方對該協定的形容。
  3. Labs 負責孵化實驗產品，產品組織則要擴大官方宣稱每天有數百萬人依靠的 Claude 體驗。Cowork 的價格、能做的事、負責人和何時結束預覽，官方文字都沒寫。

重點與分析

官方寫，Cowork 以研究預覽推出，把 Claude 的 AI 代理能力帶到桌面。同段寫三件並行的事：在 Claude 能力邊緣試做、交未打磨版本給早期使用者找出可行之處、以及把站得住的做成客戶能依靠的產品。官方表示，這套做法做出了它。

通鑑判斷：官方把試做、把未打磨版本交給早期使用者、把站得住的做成客戶能依靠的產品，寫成一起進行的三種動作。Cowork 只被放在研究預覽，沒有被寫成已經可依靠。值得觀察的是，早期使用者是整套做法的通則，官方沒有另寫 Cowork 開放給誰、範圍多大。可能目前仍偏早期試用，但這是依通則做的解讀，不是官方對 Cowork 的單獨說明。官方文字說明沒有價格、作業系統、能代辦的工作項目，也沒有和 Claude 或 Claude Code 比較。這篇說明給的是位置，不是使用方式。

官方宣稱，Claude Code 六個月內從研究預覽成長為十億美元產品；模型上下文協定（MCP）每月下載一億次，官方並稱它已成為連接 AI 與工具、資料的業界標準。Cowork 寫在同一句，官方沒有給它這兩項數字。

通鑑判斷：官方宣稱的十億美元和每月一億次下載，都不能算進 Cowork。前者的主詞是 Claude Code，條件是六個月、從研究預覽算起；後者的主詞是 MCP，口徑是每月下載次數。業界標準是官方對 MCP 的形容，不宜寫成外界已經公認。官方表示同一套做法做出了這些產品，這是在講做法，不是在講 Cowork 的營收或使用者人數。值得觀察後續說明會不會補上 Cowork 自己的使用數字；這篇沒有。可能有人把六個月路徑看成 Cowork 的預告。官方文字沒有這個推論，不宜代補。

官方擴大 Labs，孵化 Claude 前沿實驗產品。Mike Krieger 過去兩年任產品長，將加入 Labs 做產品。Ami Vora 將領導產品組織，搭配技術長 Patil。官方宣稱每天有數百萬人依靠 Claude 體驗要擴大。

通鑑判斷：把孵化實驗產品，和擴大每天已有人依靠的 Claude 體驗分成兩條線。Cowork 仍是研究預覽；前述數百萬人不是它的人數。Mike Krieger 是 Instagram 共同創辦人，過去兩年任產品長，將加入 Labs，與 Ben Mann 做產品。Ami Vora 將領導產品組織，搭配技術長 Rahul Patil。可能是把試做和做大分開管。總裁 Daniela Amodei 表示 AI 進展迫使他們改做法，Labs 用來打破既有做法。官方沒指定 Cowork 負責人。

通鑑判斷：這篇說明在講 Labs 改組，Cowork 是被點到的例子。它是研究預覽，把 Claude 的 AI 代理放到桌面。同一套做法下，官方宣稱 Claude Code 六個月從研究預覽成為十億美元產品，MCP 每月下載一億次。值得觀察會不會補上 Cowork 的範圍、價格與能做的事。可能有人用 Claude Code 的六個月類推，官方沒有說，不該把金額算到 Cowork。
