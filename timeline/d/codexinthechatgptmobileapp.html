Codex 進 ChatGPT 手機版｜OpenAI｜5 月 14 日 產品進階

Codex 進手機，讓需要人決定的工作繼續往前

OpenAI 推出 ChatGPT 手機版的 Codex 測試功能，讓使用者離開電腦後，仍能查看任務進度並回應需要判斷的環節。

這是什麼

這項功能把手機變成 Codex 任務的管理入口。工作仍在電腦或遠端環境執行；使用者可以從手機查看結果、補充指示、核准指令，或開啟新任務。

三點帶走

  1. 手機能查看並引導既有 Codex 任務，工作仍在原本的電腦或遠端環境執行。
  2. 螢幕截圖、測試結果與程式差異可供審核；複雜變更仍值得仔細檢查。
  3. iOS 與 Android 正逐步開放測試版；連接 Windows 版 Codex app 的支援尚待推出。

重點與分析

官方表示，手機版可載入 Codex 執行環境的目前狀態，讓使用者跨任務查看輸出、核准指令、切換模型，也能開啟新任務。

通鑑判斷，這項功能的重點是把人的判斷接回正在進行的工作。Codex 做到一半若需要選方向或取得許可，使用者可以在手機上處理，不必等回到電腦前。這對耗時較長、途中常有決策點的任務較有用；若工作本來就能一次完成，手機入口帶來的差異可能較小。

官方表示，手機可看到螢幕截圖、終端機輸出、程式差異與測試結果；檔案、憑證、權限及本機設定則留在 Codex 執行的機器上。

通鑑判斷，能否在手機上看懂工作成果，比能否按下核准更關鍵。測試結果和程式差異提供了檢查依據，但螢幕較小，複雜變更仍可能需要回到電腦仔細核對。檔案與憑證留在執行端，也說明手機扮演的是查看與指揮的角色；工作所需的環境仍須先在原本的機器上備妥。

官方表示，Remote SSH 已正式開放，Codex 可連入受管理的遠端環境；連線後，使用者也能透過手機接續處理其中的任務。

通鑑判斷，這讓手機功能不只對個人筆電上的工作有用，也可能接上企業原有的遠端開發環境。團隊若已把相依套件、憑證與安全規則放在受管理的機器上，員工在外仍有機會處理任務的決策點。不過，能從手機接續操作，不等於每個企業環境都已完成連線與權限設定；實際可用範圍仍取決於團隊的配置。

官方表示，手機功能正以測試版逐步提供給支援地區的 iOS、Android 使用者，涵蓋免費方案；連接 Windows 版 Codex app 的支援則預計稍後推出。

通鑑判斷，免費方案也涵蓋在內，有助於更多人試用這種工作方式，但逐步推出代表符合資格的人未必立刻都能用到。使用 Windows 版 Codex app 的人，還要留意手機連接功能尚未推出。讀者評估是否適合自己時，應先看目前的執行環境能否連上，再看手機上的審核資訊是否足夠支撐自己的決定。

通鑑怎麼看

通鑑判斷，Codex 進手機的價值，是讓長時間執行的任務在需要人介入時少等一段。它特別適合查看進度、回答問題與選擇方向；涉及大量程式差異或細部檢查時，手機畫面可能仍嫌侷促。值得觀察的是，使用者能否憑手機呈現的資訊，安心做出核准與修改方向的決定。
