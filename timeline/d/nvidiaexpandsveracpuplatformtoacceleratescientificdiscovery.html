NVIDIA 用 Vera CPU 加速尚未加速的科學模擬

NVIDIA 以新聞稿公布 Vera CPU 機櫃級平台，目標是加快天氣、氣候與分子模擬。

這是什麼

NVIDIA 推出 Vera CPU 機櫃級平台，把 192 顆自研資料中心 CPU、Quantum-X800 InfiniBand 與液體冷卻放在同一櫃，用來加速天氣、氣候與分子這類尚未加速的科學模擬。

三點帶走

  1. 192 顆 CPU、整櫃記憶體頻寬超過每秒 200TB，對準仍靠 CPU 的氣候與分子模擬。
  2. OpenFOAM 是官方測試的 1.9 倍效能與 2.4 倍每瓦；WRF 的 1.6 倍與 2 倍能源效率是預估。
  3. SDK 現已推出，Fortran 編譯器的公開測試版正要推出；機櫃預計 2027 年初，HLRE-5 預計 2028 年初。

重點與分析

官方宣稱，液冷機櫃以 192 顆 Vera CPU 接上 Quantum-X800 InfiniBand，尖峰記憶體頻寬超過每秒 200TB，記憶體約 300TB、儲存 1PB。單顆有 88 個 Olympus 核心、176 執行緒，記憶體頻寬最高每秒 1.2TB。

科學模擬一放大，難處在於資料得在記憶體與處理器之間不停搬。官方點名的氣候模式、分子動力學，是官方列舉的科學運算工作。講者 Ian Buck 表示，CPU 得把大型資料持續搬動，規模變大時效能還得撐住。通鑑判斷，官方宣稱的單顆最高每秒 1.2TB 是把取資料的路拓寬；整櫃超過每秒 200TB，是 192 顆疊進同一液冷櫃。官方表示 SHARP 能減少處理器互相協調的時間。一起算時的空等就是要拆的卡關。

官方宣稱，在該公司測試中，Vera 跑 OpenFOAM 的 motorBike Large 氣流模擬，效能是 x86 系統的 1.9 倍、每瓦效能是 2.4 倍。官方另以開源天氣研究與預報模式 WRF 做測試，預估效能為 x86 的 1.6 倍、能源效率為 2 倍。

兩組數字都只跟 x86 比。OpenFOAM 是官方測試已跑出的結果：1.9 倍約是同樣時間做出近兩倍，2.4 倍每瓦約是同樣工作用電剩四成二。WRF 官方寫明是預估，1.6 倍約把時間縮到六成二五，能源效率 2 倍約是用電砍半。標題的 2 倍對得上這組預估。通鑑判斷，NVIDIA 主線是把計算搬上顯示卡，這次卻拿仍留在 CPU 的氣流與天氣程式，只跟 x86 比。路是去接傳統處理器上的科學軟體。

官方宣稱，針對 Vera 調校的 NVIDIA HPC SDK 26.11 現已推出。新一代 Fortran 編譯器正要推出公開測試版，官方宣稱是與高效能運算中心、國家實驗室合作，讓既有 Fortran 程式不必重寫，就能在 NVIDIA 平台上跑得更快。

官方把 Fortran 稱為科學計算起家的語言。換平台時，卡人的往往是把舊程式重寫。編譯器的公開測試版正要推出，開放後研究室可留在 Fortran，在 NVIDIA 平台上試跑，不必先改寫。HPC SDK 26.11 則現在就能取得。硬體機櫃預計 2027 年初才由 Dell、HPE、Lenovo 與 Supermicro 供貨。通鑑判斷，先鬆開的是程式這一環：有 Fortran 資產的實驗室能先改編譯流程，不必同時決定買整櫃。

官方宣稱，德國氣候運算中心 DKRZ 已選定 Vera CPU，用於 HLRE-5，並搭配 GB200 與 Quantum-2 InfiniBand。預計 2028 年初可用，將支援氣候模擬與 AI 研究，以低於該中心現有系統的能耗做全球公里級氣候模擬。

外部採用目前點名 DKRZ 的 HLRE-5。Vera 機櫃用 Quantum-X800，這台搭配 Quantum-2，官方寫的是選用 CPU。官方宣稱系統預計 2028 年初可用、整櫃 2027 年初由 Dell、HPE、Lenovo、Supermicro 供貨。通鑑判斷，成不成看兩件事：四大廠是否在 2027 年初出貨，以及公里級氣候模擬的耗電有沒有低於該中心現有系統。新聞稿把時程列為前瞻性陳述且不構成承諾，爭議在選定已公告、供貨仍可改期。

通鑑怎麼看

通鑑認為，NVIDIA 肯為還沒改上顯示卡的科學程式，做一顆以記憶體頻寬和機櫃網路為中心的 CPU。OpenFOAM 的倍數若只留在官方測試，已公告的外部採用者是 DKRZ：HLRE-5 能否在預計時程內，用更低能耗跑出全球公里級氣候模擬。Fortran 公開測試版提供舊程式不必重寫的試行途徑：不必重寫若在實驗室成立，Vera 就有機會接住顯示卡還沒吃下的科學計算。
