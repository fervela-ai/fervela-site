Muse Wonder｜Meta｜10 月 12 日 模型進階

Meta 推出主打跨對話做到底的 Muse Wonder

Meta 在新聞室推出 Muse Wonder 系列，說明兩款新模型如何承接個人與專業的 AI 代理任務。

這是什麼

Meta 推出的兩款 AI 模型，用來做個人與專業的 AI 代理，例如保險理賠、看懂租約、做出能用的應用程式。官方表示建在 Muse Spark 之上，預計很快進 Muse，先給訂閱者。

三點帶走

  1. 開發者即日起可用 Muse Wonder；Full 開放給 Muse Code 訂閱者。進 Muse 平台仍預計很快，且先給訂閱者。
  2. 官方把保險、租約、財務、法律、健康與寫程式當目標場景，官方文字沒有寫辦完一次的結果或分數。
  3. 跨對話會帶著要點、變難仍繼續，重要事項執行前先確認。未經許可不外流私人資料；找自己程式缺陷仍被允許。完整安全報告尚未公布。

重點與分析

官方表示，Muse Wonder 即日起經 Meta Model API 與 Muse Code，開放給開發者與建置者；Muse Wonder Full 開放給 Muse Code 訂閱者。前者預計很快會進 Muse 的體驗，並先給訂閱者。

通鑑判斷，資格分層會比模型名稱更影響上班族何時用到：開發者現在能用 Muse Wonder，完整版開放給 Muse Code 訂閱者，Muse 平台官方只說預計很快、且先給訂閱者。可能的落差是，保險、租約、財務像上班族的事，但平台上的體驗現在還碰不到。官方文字說明沒有寫價格、用量上限，也沒有寫非訂閱者何時能用。

官方表示，不論是處理保險理賠、看懂租約或看懂某人的財務，模型都得解讀眼前的資料並把問題做完。兩款模型把這項能力帶到法律、財務與健康；寫程式則涵蓋從遊戲到新事業應用程式。官方自稱它們是迄今能力最強、這類任務表現最先進的模型。

通鑑判斷，這些場景貼近辦公室文件，但官方文字說明沒有任何一次辦完的結果。可能被讀成已經能代辦；原文是在講模型該看懂資料並把問題做完，並說能力涵蓋法律、財務與健康。值得觀察出錯後誰負責，官方文字說明沒有寫。最強、最先進只是官方自稱，不能當成已和別家比過的成績。新聞稿文字沒有測驗名稱、分數或對照對象，怎麼測被指到研究部落格。

官方表示，因工作會延續，新模型有 Active Memory，可把對你重要的事帶進後續對話，並召回與任務有關的細節。另有 Active Focus：變難時仍朝目標做，改試做法、從錯誤恢復並做到底，需要時先澄清，重要事執行前會先確認。

通鑑判斷，對上班族比較有感的是這兩項，而不是最強這類形容。若 Active Memory 把內容留到後續對話，通鑑判斷未經許可外流的風險更高。值得觀察誰能刪、會不會帶進舊對話；官方文字說明沒有寫保留期限或關閉方式。重要事項執行前會先確認，但重要由誰判定，文字沒有定義。變難時改試、從錯誤恢復，可能比較堅持，也可能在當事人不知道時多走幾步。

官方表示，Muse Wonder 系列經訓練：未經許可不分享私人資料，拒絕協助實際有害行為，並致力加強資安、強化對網路攻擊的防禦。開發者與資安團隊仍可用這類模型找自己程式的缺陷，因此這項工作被留下。含更多安全評估的完整報告預計很快公布。

通鑑判斷，這段是在收緊，同時留一道口：找自己程式的缺陷仍被允許。官方說明，個人代理能承接真實任務，常常意味著要跨訊息、行事曆與文件。可能要看請求是在加強自己的系統，還是協助實際有害行為；線畫在哪，官方文字說明沒有舉例。值得觀察完整報告公布前，這篇文字還不能當成安全成績單。新聞稿稱這是走向人人可用的個人超級智慧的一大步，那是官方定位，不是已達成的狀態。

通鑑怎麼看

通鑑判斷，官方說十四個月前開始整頓 AI，並以 Muse Spark 為基礎推出這一系列。現在主要是開發者與 Muse Code 訂閱者能用，Muse 上的體驗仍預計很快、且先給訂閱者。能力最強、最先進是官方自稱，文字沒有分數與對照。安全訓練含不外流與拒有害，也保留找自己程式缺陷的能力，完整評估尚未公布。值得觀察進到 Muse 之後，上班族碰到的是代辦，還是仍要自己逐步下指示。
