NVIDIA（NVDA） 發表 DGX Spark 與 DGX Station：把 Grace Blackwell 放上桌面

NVIDIA（NVDA） 發表兩款桌上型 AI 電腦：DGX Spark（原 Project DIGITS，GB10 晶片）與 DGX Station（GB300，784GB 同調記憶體）。

這是什麼

官方的訴求是讓開發者在桌面上本機微調與推論大型模型，再無縫搬到雲端或資料中心。

三點帶走

  1. DGX Spark 使用 GB10，官方稱最高每秒 1,000 兆次 AI 運算（FP4）。
  2. DGX Station 使用 GB300，具 784GB 同調記憶體。
  3. 兩者皆由 ASUS、Dell、HP、Lenovo 等系統廠開發。

重點與分析

官方表示，DGX Spark 的核心是 GB10 Grace Blackwell Superchip，具第五代 Tensor Core 與 FP4 支援，AI 運算最高可達每秒 1,000 兆次運算。

「1,000 兆次運算」是 FP4 精度下的上限值，精度降低會犧牲數值範圍，與 FP16 等標準精度的算力不能直接比較。原文未說明這個數字是否含稀疏加速。

官方表示，GB10 使用 NVLink-C2C 互連技術，提供 CPU 與 GPU 同調記憶體模型，頻寬是第五代 PCIe 的 5 倍，讓晶片在 GPU 與 CPU 間存取資料以優化記憶體密集的開發工作。

同調記憶體讓 CPU 與 GPU 共用同一位址空間，減少資料複製。這是桌機要塞下大模型的關鍵，但原文這一段沒有給出 DGX Spark 的記憶體容量，需查產品規格頁。

官方表示，DGX Station 是首款採用 GB300 Grace Blackwell Ultra 桌面超級晶片的系統，具 784GB 的同調記憶體空間，並內建支援最高 800Gb/s 網路的 ConnectX-8 SuperNIC。

784GB 同調記憶體已能容納規模相當大的模型，但原文沒有說明價格與上市時間；ASUS、Dell、HP、Lenovo 被列為系統廠，是否都會出貨 Station 也未明講。

官方表示，使用者可以在本機執行模型，或幾乎不改程式就部署到 DGX Cloud 或任何加速雲端與資料中心基礎設施。

「幾乎不改程式」是官方宣稱，可行性取決於 CUDA 軟體堆疊的一致性。這也是 NVIDIA（NVDA） 以軟體生態綁定硬體的策略：桌機與雲端同一套工具鏈。

通鑑怎麼看

通鑑認為，這則的新意在於把資料中心等級的 CPU+GPU 同調架構縮進桌面形態，用於原型與微調。FP4 與同調記憶體是理解其算力與容量宣稱的兩個關鍵條件。
