AWS 推出 Braket 演算法庫，提供現成量子演算法

2022 年 11 月 28 日，AWS 宣布 Braket Algorithm Library，目標是縮短研究者在 Amazon（AMZN） Braket 上開始實驗的時間。

這是什麼

這是一個放在 GitHub 的開源儲存庫，收錄熱門量子演算法的 Python 程式碼，可在本機、受管模擬器或量子電腦上執行，並在過程中估算成本。

三點帶走

  1. AWS 於 2022 年 11 月 28 日發表開源的 Braket Algorithm Library。
  2. 收錄量子相位估計、量子電路 Born 機與量子漫步等實作。
  3. 演算法庫本身不另收費，可在主控台以 Jupyter notebook 執行。

重點與分析

官方表示 Braket Algorithm Library 是開源 GitHub 儲存庫，提供一組熱門量子演算法的現成 Python 實作，以縮短在 Amazon（AMZN） Braket 上起步的時間。

官方指出研究者常卡在建置開發環境、估算在古典與量子硬體上測試的成本、拼接常用子程序，這個演算法庫就是針對這些前置工作。它不是新演算法或新硬體，而是降低使用門檻的工具。

官方表示收錄的實作包括量子相位估計（Quantum Phase Estimation）、量子電路 Born 機（Quantum Circuit Born Machine）與量子漫步（Quantum Walks），每個都是可直接執行、可整合進更複雜演算法的程式碼。

原文以『例如』列出這三項，並未說明完整清單與總數。使用者可在 Braket 主控台用 Jupyter notebook 直接執行，不必從 GitHub 複製程式，並可選擇在本機、受管模擬器或量子電腦上跑，同時估算成本。

官方表示演算法庫可從 Braket 主控台或 GitHub 取得，在提供 Braket 的所有區域不另收費；認可機構的研究者可申請 AWS 雲端研究點數；有意貢獻者可依開源貢獻準則參與。

『不另收費』指的是演算法庫本身；在量子電腦或模擬器上執行仍會產生 Braket 使用費，原文以『估算成本』處理這一點。
