AWS 稱 Trn2 比現行 GPU 執行個體性價比高 30 至 40%，並預告 Trainium3

AWS 推出 Trn2 執行個體與 64 顆晶片組成的 Trn2 UltraServer，並與 Anthropic 規劃 Project Rainier 叢集。

這是什麼

Trainium 是 AWS 自研的 AI 訓練與推論晶片（專用晶片）。Trn2 是搭載 Trainium2 的 EC2 執行個體；UltraServer 則把四台 Trn2 伺服器用 NeuronLink 互連成一台大型伺服器。

三點帶走

  1. Trn2 正式上市，AWS 稱性價比比現行 GPU 執行個體高 30 至 40%。
  2. Trn2 UltraServer 以 64 顆 Trainium2 組成。
  3. Trainium3 預告為 AWS 首款 3 奈米晶片，2025 年底提供。

重點與分析

官方表示，Trn2 執行個體比現行以 GPU 為基礎的 EC2 P5e、P5en 執行個體有 30 至 40% 更好的性價比，每個執行個體含 16 顆 Trainium2 晶片，提供 20.8 petaflops 峰值運算。

30 至 40% 是 AWS 對自家 GPU 執行個體的比較，稿中沒有說明工作負載、模型大小與價格基準，所以這是廠商自述。20.8 petaflops 則是單一執行個體的峰值，未必等於實際訓練表現。

官方表示，Trn2 UltraServer 以 NeuronLink 連接四台 Trn2 伺服器，共 64 顆 Trainium2 晶片，峰值運算可擴展到 83.2 petaflops，是單一執行個體運算、記憶體與網路的四倍。

UltraServer 的設計是把規模擴大放在單一系統內，而不是只靠增加叢集節點。稿中說明原因：模型變大時，單純增加叢集大小因為平行化限制而無法縮短訓練時間，且即時推論會把單一執行個體架構推到極限。

官方表示，AWS 與 Anthropic 共同建置名為 Project Rainier 的 EC2 UltraCluster，包含數十萬顆 Trainium2 晶片，運算量超過 Anthropic 訓練現行模型所用 exaflops 的 5 倍；Poolside 預期訓練成本比 EC2 P5 節省 40%。

Project Rainier 是官方宣布的建置計畫，稿中使用『When completed, it is expected to be』的措辭，代表當時尚未完成。Poolside 的 40% 是客戶預期節省，不是實測。

官方表示，Trainium3 將是 AWS 首款採用 3 奈米製程的晶片，Trainium3 UltraServer 預期比 Trn2 UltraServer 效能高 4 倍，首批執行個體預計 2025 年底提供。

稿中只說『3-nanometer process node』，沒有說明晶圓代工廠或封裝方式。4 倍是預期值，且以 UltraServer 為單位比較，不是單晶片比較。

通鑑怎麼看

通鑑認為，這則新聞顯示雲端業者自研加速器正從單晶片走向大規模系統：16 顆晶片的執行個體、64 顆晶片的 UltraServer 與數十萬顆的叢集。性價比與效能倍數皆為 AWS 自述，Trainium3 的製程與時程屬預告。
