NVIDIA Grace CPU Superchip｜NVIDIA｜3 月 22 日 事件推薦

NVIDIA（NVDA） 推出 Grace CPU Superchip：兩顆 CPU 以 NVLink-C2C 合成一顆

官方宣稱 144 核心、1TB/s 記憶體頻寬，整顆 CPU 含記憶體耗電約 500 瓦。

這是什麼

Grace CPU Superchip 是 NVIDIA（NVDA） 自己設計的伺服器 CPU，與 Grace Hopper 超級晶片共用同一套 CPU 架構與 NVLink-C2C 互連。

三點帶走

  1. 兩顆 CPU 晶片、144 個 Arm（ARM） 核心，用 NVLink-C2C 合成單一插槽。
  2. 官方宣稱 1TB/s 記憶體頻寬、整顆含記憶體約 500 瓦。
  3. 740 分是矽晶片完成前的內部估計，預計 2023 上半年供貨。

重點與分析

官方表示，Grace CPU Superchip 由兩顆 CPU 晶片以 NVLink-C2C 一致性連接，單一插槽 144 個 Arm（ARM） 核心，估計 SPECrate 2017_int_base 為 740。

這是 NVIDIA（NVDA） 第一款資料中心 CPU 產品，而且是用「兩顆晶片合成一顆」的做法，與同月蘋果（AAPL） M1 Ultra 用 UltraFusion 連接兩顆晶粒的思路相近，差別在 NVIDIA 用的是自家 NVLink-C2C。740 這個分數在原文是「estimated」，註腳說明是矽晶片完成前的預估值，並與 AMD EPYC 7742 雙插槽系統的估計值 460 相比，因此「1.5 倍以上」是 NVIDIA 實驗室內部估算，不是公開基準測試結果。

官方表示，記憶體採用帶 ECC（錯誤更正碼）的 LPDDR5x，頻寬為 1TB/s，約為一般 DDR5 設計的兩倍；包含記憶體在內整顆 CPU 只耗電 500 瓦。

伺服器 CPU 通常搭配 DDR5 模組，NVIDIA（NVDA） 選擇把低功耗的 LPDDR5x（原本多用於手機與筆電）接到伺服器 CPU，是為了同時壓低功耗與拉高頻寬。500 瓦是「整顆 CPU 含記憶體」的數字，與傳統只算 CPU 本體的 TDP 不能直接比較；原文也沒有寫記憶體容量，所以這個設計能否滿足大記憶體需求仍不清楚。

官方表示，Grace 採 Arm（ARM） v9，可搭配 ConnectX-7 組成純 CPU 伺服器，或搭載 1、2、4、8 顆 Hopper GPU 的機型；預計 2023 上半年供貨。

這段把產品定位講得很清楚：同一條軟體堆疊（RTX、HPC、AI、Omniverse）可以跑在純 CPU 或帶 GPU 的機型上，目標是讓客戶不必為不同配置改程式。供貨時間「2023 上半年」比同日發表的 H100（第三季）晚了至少半年，代表 CPU 與 GPU 的整合模組要比單顆 GPU 更晚才能到客戶手上。原文只說 NVIDIA（NVDA） 正與 HPC、超級電腦、超大規模與雲端客戶合作，沒有列出客戶名稱。

通鑑怎麼看

通鑑認為，Grace 把 NVIDIA（NVDA） 的產品線從加速器延伸到 CPU，並用同一條互連把 CPU 與 GPU 綁在一起。要判斷它的實際競爭力，得等 2023 年實機與公開基準測試，而不是今天的 740 預估值。
