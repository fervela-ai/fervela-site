IBM 推出 Qiskit Code Assistant 私有預覽版｜IBM｜10 月 9 日 事件延伸

IBM 為 Premium Plan 用戶推出 Qiskit 程式碼助手預覽版

官方表示，Qiskit Code Assistant 結合 IBM watsonx 的大型語言模型，協助用戶用自然語言寫出 Qiskit 量子程式。

這是什麼

Qiskit 是 IBM 的開源量子程式開發工具。Qiskit Code Assistant 是以大型語言模型（用大量文字訓練、能預測下一段內容的 AI）產生量子程式碼的助手，這篇是 IBM 量子部落格的產品公告，說明可用對象、整合的開發環境與未來開源計畫。

三點帶走

  1. Qiskit Code Assistant 以私有預覽形式提供給 Premium Plan 用戶，可在 VS Code 與 JupyterLab 使用。
  2. 官方宣稱依 Qiskit HumanEval 基準它是寫 Qiskit 程式碼的最佳模型，但基準與模型都由 IBM 自己設計與評估。
  3. IBM 計畫開源 Qiskit Granite 模型與 HumanEval 資料集，但沒有給時間表。

重點與分析

官方表示，Qiskit Code Assistant 以私有預覽（private preview）形式提供給 IBM Quantum Premium Plan 用戶，結合 IBM watsonx 的大型語言模型與 Qiskit 用戶社群的集體經驗。

這代表當時它不是公開上線的產品，只有付費方案用戶可以試用。官方把它定位為降低量子程式門檻與提供學習方式的工具，但文中沒有給出使用人數或採用率。「社群集體經驗」指模型訓練所依據的資料來源，細節留給文中提到的兩篇論文。對讀者而言，目前能確定的只有可用對象與定位，實際程式碼品質要等更多用戶試用才看得出來。

官方表示，用戶可在 VS Code 與 JupyterLab 中安裝擴充套件，輸入自然語言提示或函式定義，讓助手產生 Qiskit 程式碼，也可以讓它補完或整理既有的半成品程式。

文中舉的例子是要求助手「定義一個 Bell 電路並在 ibm_brisbane 上用 Qiskit Runtime Service 執行」。這說明它的任務是把常見流程轉成可執行程式，而不是自動設計新的量子演算法。第一次使用者需先接受使用者授權協議，文中提醒其中有使用限制，用戶需自行閱讀。

官方宣稱，以 Qiskit Human Eval 基準測試的結果，IBM 的量子程式碼生成模型讓 Qiskit Code Assistant 成為目前寫出可用高品質 Qiskit 程式碼的最佳模型。

這是 IBM 用自己設計的基準（Qiskit HumanEval）對自己模型做的評估，並由 IBM 自己下結論。文中沒有列出與哪些模型比較，也沒有給分數，所以這個「最佳」只能視為公司的說法。不過 IBM 同時說明已就模型與基準各寫了一篇論文，讀者可以回到論文查核方法。

官方表示，IBM 計畫日後把 Qiskit Code Assistant 的關鍵元件開源，包括作為基礎的 Qiskit Granite 模型與 Qiskit HumanEval 資料集。

開源只是「計畫」，文中沒有給時間表。這點與目前只對付費用戶私有預覽的狀態形成對照：模型與評測資料集若如期開放，外界才能獨立驗證 IBM 所說的表現。在那之前，品質主張仍只有 IBM 自己的數據支撐。

官方表示，Qiskit Code Assistant 最早在 IBM Quantum Summit 2023 預覽，並在 2024 年的 IBM Quantum Challenge 中讓參與者試用，同時邀集公司內部志願者測試安全性。

這段交代了產品從 2023 年預覽到 2024 年私有預覽的過程，以及上線前有做過安全測試。文中沒有說明安全測試發現了什麼問題，也沒有說明生成的程式碼有多高比例可以直接執行，所以「可用」的程度仍需用戶自行驗證。從時間線看，從 2023 年的展示到 2024 年的私有預覽相隔約一年，官方也沒有說明何時會開放給 Premium Plan 以外的用戶。
