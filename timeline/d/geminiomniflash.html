Gemini Omni Flash 讓影片生成走向反覆修改

Google DeepMind 開放 Gemini Omni Flash 公開測試，讓開發者用文字、圖片與影片建立及修改短片。

這是什麼

Gemini Omni Flash 是結合多模態理解、影片生成與對話式編輯的模型。它讓使用者能以不同形式的資料指定畫面，再用自然語言調整影片。

三點帶走

  1. 可以用自然語言修改生成影片，適合反覆試作短片構想。
  2. 使用前要核對片長與參照限制，尤其不能把影片上傳成功當成正確處理。
  3. 估算成本時要把反覆生成和修改算進去，並檢查成果的一致性。

重點與分析

官方表示，開發者可結合文字、圖片與影片輸入生成影片，並用自然語言繼續修改；模型已在 Google AI Studio 與 Gemini API 開放公開測試。

通鑑判斷，關鍵是修改方式：使用者可以先做出片段，再用文字描述想調整的地方，減少每次改動都得重新安排製作流程的負擔。不過，能接受多種輸入，不代表複雜畫面都能穩定維持原貌；實際效果仍要看修改後的人物、場景與動作是否一致。

官方表示，目前每段生成影片長度為 10 秒；在 Gemini API 中，音訊參照與場景延伸尚未支援，影片參照即使不超過 3 秒，也暫時無法正確處理。

通鑑判斷，這些限制決定了它目前較適合試做短片與單一片段的修改。尤其影片參照雖可被介面接受，模型卻無法正確處理，開發者不能只憑上傳成功就認定功能可用。若工作需要接續既有影片、保持跨場景角色一致，仍須逐段檢查成果。

官方表示，影片輸出價格為每秒 0.10 美元，與 Veo 3.1 Fast 相同；透過 Interactions API 保留對話脈絡時，使用者最多可接續進行 3 次編輯。

通鑑判斷，按輸出秒數計價，讓短片試做的基本費用較容易估算，但反覆生成與修改會增加總支出，不能只看單次片段的標價。接續編輯也有條件：官方描述的是透過特定介面保留脈絡的流程，不能直接推成所有使用方式都能無限次修改。

官方展示的室內設計範例，先用 Nano Banana 2 Lite 依房間照片產生設計概念，再交給 Omni Flash 做成動態展示；兩款模型都使用 SynthID 浮水印。

通鑑判斷，這個範例比單純展示特效更能說明用途：先挑靜態方案，再用動態畫面檢視空間氛圍，可能幫助提案者更快溝通構想。但展示片段不能證明模型能準確呈現施工後的樣貌。浮水印提供查驗 AI 內容的途徑，觀看者仍應分清概念影片與實際成品。

通鑑怎麼看

Gemini Omni Flash 的看點，是把生成影片與後續修改放進同一段對話流程，並讓圖片、文字及影片成為創作參照。通鑑判斷，它目前最有機會用在短片構想、商品展示與提案試作；片長、參照處理和跨場景一致性的限制，仍會影響它能否承擔完整製作流程。
