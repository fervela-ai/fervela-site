Google 在超導量子處理器上實作 color code 糾錯｜Google Research｜6 月 23 日 事件推薦

Google（GOOGL） 在 Willow 晶片上做出 color code，比表面碼省空間但錯誤抑制較弱

Google Quantum AI（GOOGL） 在 Nature 發表以超導量子處理器實作 color code（色碼，一種量子錯誤校正編碼）的結果，官方說明它比常見的表面碼更省量子位元、邏輯閘更快，但目前的錯誤抑制效果還不如表面碼。

這是什麼

量子電腦的量子位元很容易受雜訊干擾，所以要把許多「物理量子位元」組成一個比較穩的「邏輯量子位元」，這就是量子錯誤校正。Google（GOOGL） 先前主打表面碼，這次用同一顆 Willow 晶片改試另一種編碼 color code，並量測它在邏輯閘與狀態準備上的表現。

三點帶走

  1. Google（GOOGL） 在 Willow 晶片上做出低於門檻的 color code，距離 5 相比距離 3 邏輯錯誤率降 1.56 倍。
  2. color code 用的物理量子位元較少、單量子位元邏輯操作更快，但糾錯電路與解碼比較難。
  3. 表面碼仍是 Google（GOOGL） 的主力，color code 目前定位為搭配魔術態培育的補充選項。

重點與分析

官方表示，color code 用「三角形貼片上的六邊形磚」排列奇偶檢查，同樣編碼距離下面積遠小於表面碼的正方形，因此需要的物理量子位元較少。

表面碼要把邏輯量子位元排成邊長等於編碼距離的正方形，color code 則是邊長等於距離的三角形，面積差距直接轉成量子位元數量差距。官方同時承認代價：糾錯電路更深、解碼演算法不同，配對式演算法在這種編碼上沒那麼準，所以更難跨過『錯誤校正門檻』。也就是說，省下的是硬體規模，付出的是電路複雜度與解碼難度。

官方宣稱，距離 5 的 color code 相比距離 3，邏輯錯誤率被抑制 1.56 倍；官方自己對照，先前表面碼做到的是 2.31 倍。

這是全文最需要冷靜看的數字：color code 確實出現『距離越大、錯誤越少』的低於門檻行為，但抑制倍率比表面碼小。官方的說法是目前結果較小，但預期幾何優勢會在更大規模與裝置改進後顯現，這是預期而非已證實。比較只涵蓋距離 3 與 5 兩點，還看不出更大距離時兩條曲線是否交叉。

官方表示，color code 中許多單一邏輯量子位元操作可一步完成，邏輯 Hadamard 閘預期約 20 奈秒，而同一裝置上的表面碼可能慢 1000 倍。

差別來自表面碼需要多輪糾錯循環才能完成同一個邏輯操作。文中用的是『預期約 20ns』，並非實測量值；實驗實際展示的是多種單量子位元邏輯操作，並用邏輯隨機基準測試（logical randomized benchmarking）驗證。速度優勢的另一個好處是演算法需要的糾錯循環變少，因此每輪可以容忍較多錯誤、進一步減少物理量子位元。

官方表示，團隊把一個『不完美』的魔術態（magic state，量子演算法需要的特殊資源態）以 99% 保真度注入 color code 邏輯量子位元，這是 cultivation（培育）協定的第一步。

魔術態讓量子電腦能做任意角度旋轉，沒有它量子演算法無法勝過傳統方法，文中稱它長期被認為是實用演算法中最昂貴的部分。理論上 color code 可搭配 cultivation 電路高效產生魔術態，這次只驗證了注入這第一步，後續的挑選與提純並未在這篇文章中展示，所以離『魔術態成本大降』還有距離。

官方表示，團隊讓兩個邏輯量子位元糾纏，並把資訊從一個傳到另一個，保真度為 86% 至 91%；color code 的合併操作可作用在 X、Y、Z 三種基底，表面碼只有 X 與 Z。

兩個邏輯量子位元的閘是用『把兩個貼片合併再拉開』完成。86% 至 91% 的保真度表示距離可用的容錯雙量子位元邏輯閘仍有明顯差距。第三種基底是 color code 的結構彈性，但文章沒有說明它在實際演算法裡能省下多少。

通鑑怎麼看

通鑑認為，這篇的價值在於 Google（GOOGL） 開始用實測數據比較兩種編碼，而不是只押表面碼；但 1.56 倍對 2.31 倍說明 color code 目前並未全面領先。官方自己也說表面碼仍是主力，color code 預期用在魔術態培育等環節，後續要看更大距離的結果。
