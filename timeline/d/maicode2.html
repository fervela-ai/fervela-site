MAI Code 2｜Microsoft｜11 月 17 日 模型推薦

MAI Code 2 把程式 AI 的競爭推向長時間使用成本

Microsoft 在新模型發表中推出 MAI Code 2，並列出程式編寫能力與價格的比較數字。

這是什麼

MAI Code 2 是 Microsoft 的程式編寫模型，可供 AI 代理處理工程工作。它的核心賣點是：以接近其他高階模型的官方比較成績，降低持續使用的費用。

三點帶走

  1. 官方宣稱，MAI Code 2 的編碼品質達 GPT-6.1 Sol 的 98%，價格約為其 40%。
  2. 官方宣稱，與 Opus 5.5 相比，MAI Code 2 達到其 96% 表現，價格為其 5%。
  3. 通鑑判斷，這款模型的價值要看反覆執行程式工作時的成果與總費用。

重點與分析

官方宣稱，MAI Code 2 的編碼品質達 GPT-6.1 Sol 的 98%，價格約為後者的 40%。

通鑑判斷，這組數字瞄準的是程式 AI 長時間工作時的成本關卡。把 AI 代理想成持續接單的程式助理：每讀一次需求、修改一次程式，都會累積費用。若以官方比較的價格計算，原本花在 GPT-6.1 Sol 上的每 100 元，改用 MAI Code 2 約需 40 元；官方稱 MAI Code 2 的編碼品質達 GPT-6.1 Sol 的 98%。對需要反覆修改程式的團隊，這種交換比單看哪個模型分數最高更有實際意義。

官方宣稱，與 Opus 5.5 相比，MAI Code 2 達到其 96% 的表現，價格為其 5%。

通鑑認為，這是 MAI Code 2 最鮮明的市場位置：以大幅降低價格，爭取原本會選高階程式模型的工作。依官方數字換算，同樣拿 Opus 5.5 的價格作基準，MAI Code 2 約花每 100 元中的 5 元，官方稱 MAI Code 2 達 Opus 5.5 的 96% 表現。這讓採購或安排 AI 代理工作的團隊，多了一個具體選項：把昂貴模型留給特別棘手的任務，將大量日常程式工作交給較便宜的模型。

Microsoft 同時推出 MAI Code 2 Flash。官方宣稱，它的表現與 GPT-6 Luna 相近，價格為後者的 65%；價格也是 Haiku 5.5 的 20%。

通鑑判斷，Flash 版本讓選模型從單一的好壞排名，變成按工作量分配。大量、短小的修改與檢查，最在意的可能是每次呼叫的費用；複雜任務則可能需要不同的能力組合。官方把 Flash 分別拿 GPT-6 Luna 比表現與價格、拿 Haiku 5.5 比價格，這兩組比較的基準不同，不能合併成一個排名。對使用者真正有用的下一步，是按自己的任務逐項比較完成效果與總費用。

Microsoft 表示，這次推出一組共 7 款模型，以支援 AI 代理持續處理工程工作；官方宣稱，運行大型模型的 Maia 200 每瓦可產生的詞元數提高至 1.7 倍，但未說明比較基準。

通鑑認為，MAI Code 2 的價格主張也要放在整套供應方式裡看。模型像接單的助理，運算設備則像辦公室的電力與座位；要讓助理長時間工作，兩邊的成本都得計算。Microsoft 一面推出不同用途的模型，一面提高自家設備每單位耗電可處理的詞元數，顯示它正在同時處理模型選擇與運行效率。對企業來說，關鍵將是能否把這些選擇組成可持續運作、費用可預估的工作流程。

通鑑怎麼看

通鑑認為，MAI Code 2 值得注意的地方，是把程式 AI 的競爭焦點從最高成績拉到長時間使用的總費用。官方對 GPT-6.1 Sol 與 Opus 5.5 提出的能力、價格對照都指向同一件事：當 AI 代理反覆執行工程工作，單次費用的差距會持續累積。選用時應以自己的程式任務和帳單，檢查這項價格優勢能換來多少可用成果。
