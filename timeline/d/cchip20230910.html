Synopsys UCIe IP 在台積電 N3E 首次投片成功，3DIC Compiler 支援 3Dblox 2.0｜Synopsys／TSMC｜9 月 27 日 事件進階

小晶片互連 IP 矽驗證成功，Synopsys 補齊台積電（2330） 3DFabric 設計工具

9 月 27 日，Synopsys 宣布擴大與台積電（2330）在多晶粒系統設計上的合作，並公布 UCIe IP 的矽驗證結果。

這是什麼

多晶粒系統就是用多顆小晶片組成一顆大晶片。3DFabric 是台積電（2330）先進封裝技術的總稱，3Dblox 是台積電推動的 3D 封裝設計描述標準。設計工具要能同時規劃晶片與封裝，才能做出小晶片系統。

三點帶走

  1. Synopsys UCIe PHY IP 在台積電（2330） N3E 首次投片成功，16Gbps、可擴充至 24Gbps。
  2. 3DIC Compiler 經台積電（2330）認證，支援 3Dblox 2.0 與 3DFabric。
  3. 搭配 HBM3 IP，鎖定多晶粒 AI 晶片設計。

重點與分析

官方表示，Synopsys 3DIC Compiler 經台積電（2330）認證，能用 3Dblox 2.0 標準與 3DFabric 技術進行全端設計，整合晶粒與封裝的探索、協同設計與分析，並可依 3Dblox 2.0 系統原型共同最佳化熱與電源完整性。

小晶片系統的難處在於晶片和封裝不能分開設計：熱、供電、訊號都會跨越晶片邊界。統一平台讓設計者在早期就能評估可行性。原文提到 Synopsys 與 Ansys 合作整合多物理分析，用於簽核系統層級效應，這反映先進封裝設計需要結合多家工具。

官方表示，Synopsys 在台積電（2330） N3E 上的 UCIe PHY IP 已首次投片成功並被多家領先公司採用，結果顯示在 16Gbps 達到最佳功耗效率與效能、可擴充至 24Gbps，且有穩健的連結餘裕；完整的 UCIe 控制器、PHY 與驗證 IP 支援標準與先進封裝，並提供測試、修復與監控功能。

UCIe PHY 是小晶片之間的實體傳輸電路。16Gbps 與 24Gbps 是每條通道的傳輸速率。「測試、修復與監控」功能很重要：小晶片封在一起後若有一條連線壞掉，能修復就不必整顆報廢，這直接影響多晶粒產品的良率與成本。原文說 UCIe 已是晶粒互連的事實標準。

官方表示，Synopsys 也提供完整的 HBM3 IP，以滿足多晶粒系統的高記憶體頻寬需求；Synopsys IP 與 3DIC Compiler 結合，可自動化繞線、中介層研究與訊號完整性分析，提高生產力並降低 IP 整合風險。

HBM3 IP 是 AI 加速器把 HBM 接到運算晶片所需的控制器與實體層電路。中介層是 2.5D 封裝中承載多顆晶片的底板。把這些自動化，是為了讓更多晶片公司有能力設計 HBM 加小晶片的 AI 晶片。UCIe PHY IP 與 3DIC Compiler 即日起提供。

通鑑怎麼看

通鑑認為，這則公告把小晶片設計需要的工具鏈補齊：互連 IP 有矽驗證、封裝設計工具有晶圓廠認證，加上 HBM3 IP，AI 晶片設計者在台積電（2330）先進封裝上的門檻降低。
