波音（BA）與北約的 PROJECT X 挑戰賽選出多無人機自主概念優勝

波音（BA）與北約在荷蘭合辦三個月的快速原型競賽，兩支團隊提出無人機自主探索與分工的設計，Alpha 隊勝出。

這是什麼

PROJECT X 是北約、波音（BA）、荷蘭政府與荷蘭產業合辦的創新挑戰賽，邀請荷蘭大學（含台夫特理工大學）的創新者針對「自主系統抵達難以進入的地點、提升情勢感知」提出新做法。

三點帶走

  1. 北約與波音（BA）合辦三個月的 PROJECT X 競賽，主題是自主系統。
  2. Alpha 隊的多代理人無人機概念被評為優勝。
  3. 新聞稿只描述概念，沒有公布採購或部署計畫。

重點與分析

官方表示，這場挑戰賽為期三個月，是密集的快速原型競賽，參賽者來自荷蘭各大學，包括台夫特理工大學。

快速原型（先做出能展示的雛形再改）是這場賽事的核心形式。官方把它定位成北約與產業界接觸學界的管道，而不是採購案；新聞稿沒有提到後續採購、經費或實機部署，所以它反映的是「點子與人才的對接」而不是已成軍的能力。

官方表示，Monarch 隊的概念是階層式的專門化無人機，可自主勘查危險區域、評估風險並排定無人機位置，採三層網路結構。

這個設計把無人機分成不同任務層級，用來處理會隨時間變化的環境。新聞稿列出的用途偏向搜救、災害處理、監視與目標偵測，並非直接寫成攻擊用途。這點值得區分：標題講自主能力，實際舉例多為民用或支援性任務。

官方表示，Alpha 隊設計多代理人無人機系統，誘導無人機探索、辨識、查證並處理目標，依優先順序以最有效率的方式完成任務，最後被評審團評為優勝。

多代理人的重點是多架無人機彼此分工、共同排定目標優先順序，而不是單機各自行動。評審由波音（BA）、北約與 Unmanned Valley（荷蘭瓦爾肯堡的自主科技孵化器）的專家組成。新聞稿沒有公布評分標準或測試數據，優勝的依據只能從概念描述來看。
