Claude Opus 4.7｜Anthropic｜4 月 16 日 模型入門

Claude Opus 4.7 同價更能交辦，資安能力先被壓低

Anthropic 以產品公告開放 Claude Opus 4.7 一般使用，官方把它放在 Opus 4.6 之上，主打困難的軟體工作與長任務，價格沿用同一套。

這是什麼

Claude Opus 4.7 是 Anthropic 開放一般使用的新模型。難程式與長任務可以少盯，它會先自行查驗再回報；能力仍低於未廣泛開放的 Claude Mythos Preview。

三點帶走

  1. 長任務可以整段交出去，交回時要看到它自己標出的缺口。
  2. 上班族的升級在簡報、文件與讀圖；缺資料會被標出來，金額與條款仍要抽查。
  3. 標價與 Opus 4.6 相同；資安能力低於仍限量的 Mythos Preview，正當資安測試要另走驗證計畫。

重點與分析

官方宣稱，使用者可把以前得密切監督的最難程式工作交給它，它會做完複雜長任務，並在回報前自行驗證。官方表示，它在 Notion 的複雜流程上比 Opus 4.6 高出 14%，詞元更少，工具錯誤約剩三分之一。

對上班族，這是交辦方式的改變：難任務可以整段交出，人改在交回時才看。官方說的 14% 與工具錯誤下降，來自 Notion 早期試用的自家流程，只能當成那條長流程的例子。長流程容易停在工具出錯的那一步。自行驗證的意義，是你改看交回結果，以及它標出的疑點。一份要跑很久的報告或改稿，交回時會主動標出沒做完、對不上的地方，才算這次升級進了你的工作。

官方宣稱，它看圖解析度更高，簡報、文件與介面的品質更好。官方表示，Hex 評測裡低費力的 Opus 4.7 大致等於中費力的 Opus 4.6，缺資料會直說而非充數；Harvey 高費力得分 90.9%，分得清轉讓條款與控制權變更條款。

簡報、文件與看圖，是多數上班族碰得到的升級。解析度變高以後，流程圖、合約一頁、一張表有機會被看清。Hex 與 Harvey 的數字來自自家評測，Harvey 講者給的 90.9% 停在該公司的內部評測，合約仍要法務過目。值得帶走的習慣有兩件：缺了的資料會被標成沒有；長得像的條款會分開處理。改稿時少碰到被補出來的段落。費力可以看成你准它花多少工夫，低費力的 Opus 4.7 已追上中費力的 Opus 4.6，同樣文件可以先開較低的一檔。金額與法條仍要抽查。

官方宣稱，Claude 全產品、應用程式介面、Amazon Bedrock、Google Cloud Vertex AI、Microsoft Foundry 都可用。定價同 Opus 4.6，每百萬輸入詞元 5 美元、輸出詞元 25 美元。

同價是對採購最實用的一句。模型換代常常加價，官方這次把價錢釘在 Opus 4.6，已在用的團隊可以直接比穩定性與品質。官方標的 5 與 25 美元是每百萬詞元的牌價，長篇簡報、合約或會議紀錄的費用會落在較貴的輸出。資訊部門若已指定其中一家雲，換模型可以沿用原採購。任務變長、輸出變多時，帳單仍可能上升；有講者提到的更省，是自家觀察。所以讓它長篇寫完再叫人刪，通常比一開始就把範圍寫死更貴。

官方宣稱，Opus 4.7 資安能力低於仍限量的 Claude Mythos Preview，訓練時試過壓低該能力，上線會自動擋下被禁與高風險的資安請求。正當用途須加入 Cyber Verification Program。

這段和上班族直接有關。官方明白把 Opus 4.7 放在仍限量的 Mythos Preview 之下，資安這塊還在訓練時被拿來試著壓低。幾週前的 Project Glasswing 把資安同時看成風險與好處，所以一般開放版先自動擋下高風險請求，再用真實使用決定要不要廣放 Mythos。對公司，弱點研究與滲透測試要走官方驗證計畫；簡報、讀約、整理資料照樣是它該做的工作。自動阻擋還在累積真實使用的經驗。

通鑑怎麼看

Opus 4.7 把兩件事放進同一個一般開放版本：長任務可以更放手，資安能力先收著。對台灣上班族，值不值得換，看三個結果：跑很久的文件或整理會不會自己標出缺口；缺資料時會不會照實說沒有；公司指定的那朵雲能不能直接用、價錢維持在 Opus 4.6。廠商百分比來自早期試用。Mythos Preview 繼續限量。一般人現在用到的，是這個在資安上收過的版本。
