阿里巴巴 Qwen4-Max 旗艦模型測試版｜Alibaba｜11 月 11 日 模型推薦

阿里把旗艦模型先放兩週試用，再整個收掉

阿里雲在模型平台文件頁公開 Qwen4-Max-Preview，通義千問系列新一代旗艦多模態模型的限期測試版。

這是什麼

Qwen4-Max-Preview 是阿里雲 Qwen 系列的新旗艦模型，能讀文字、圖片、影片，也能深度推理。目前只是限期測試版，給開發者先試，一般人不會直接碰到。

三點帶走

  1. 這是兩週限時測試版，結束後下線，不適合接進正式服務。
  2. 思考與答案共用輸出額度，舊程式直接換模型可能被截斷。
  3. 相容 OpenAI 與 Anthropic 介面，換模型試用的門檻低。

重點與分析

官方文件說明，這個版本只能透過 Token Plan 訂閱方案取得專屬金鑰，不支援隨用隨付。預覽期約兩週，期間內不會更動，結束後模型下線。

這是一次限時的試駕，不是正式上市。通鑑判斷，阿里是拿一個固定版本讓開發者集中測試，兩週內不改版，回饋才比較好比。對公司的影響很直接：現在不適合把它接進正式服務，因為兩週後就會消失，只適合拿來評估。要看的是預覽結束後，阿里是推出正式版、換名字，還是改成一般計價開放。這個答案才決定今天的測試值不值得投入。

官方文件指出，從這個模型開始，OpenAI 介面的 max_tokens 等同 max_completion_tokens，兩者限制的都是思考加最終答案的總量。舊款 Qwen 模型維持原行為。

這是最容易踩雷的地方。可以想成考試只發一張答案紙：以前草稿算另外的紙，現在草稿和答案寫在同一張，草稿寫太多，正式答案就被擠掉。原本把上限抓得剛好夠寫答案的程式，換成新模型後輸出可能被截斷，使用者看到的是講到一半就停。對把舊程式直接換模型名稱的團隊，這是第一個要改的設定，官方文件也特別用提示框標出來。

思考預設開啟，強度可選 low、medium、xhigh，預設是最高的 xhigh。官方文件提醒，不要同時設定 reasoning_effort 與 thinking_budget。

預設就開到最高強度，代表這個模型的出廠設定是想得最久、最仔細。好處是複雜任務的準確度有機會更好，代價是回應更慢、耗用的詞元更多，在訂閱方案裡就是更快用掉額度。以前使用者要自己決定要不要開推理，現在變成要主動往下調，簡單問答選 low 比較合理。通鑑認為，這種預設值的選擇透露定位：它瞄準的是寫程式、辦公文件這類慢工細活，而不是即問即答的聊天。

官方宣稱上下文長度為 1M 詞元，最大輸出為 393,216 詞元，思考與最終答案共用這個額度。

上下文長度像一張能攤開的書桌，1M 詞元代表可以一次把大量文件、程式碼或長影片資料擺上去。輸出上限同樣很大，適合一次產出長報告或大型程式檔。但這個輸出額度同樣被思考吞掉一部分，所以前一點的設定問題在這裡放大：長任務若沒預留空間，最先犧牲的是結尾。接下來要看的具體指標，是實測時長文件任務在 xhigh 下的完成率與耗時，這比規格數字更能說明好不好用。

官方文件說明，它相容 OpenAI 的 Chat Completions、Responses，以及 Anthropic 的 Messages 介面，並支援網頁搜尋、函式呼叫與結構化輸出。

相容多家介面，等於插座做成通用規格，現有工具多半只改網址和模型名稱就能試。這降低了切換成本，也是中國模型追趕時常見的路線：不要求開發者重寫，先讓人用得上。對上班族的意義在間接：公司若已經用 OpenAI 或 Anthropic 格式的工具，多了一個可以比價比品質的選項。這項的成敗取決於連多輪對話時，歷史思考內容要用專屬欄位回傳，不能併進一般內容，細節處理不好就會出錯。

通鑑怎麼看

通鑑認為，這次重點不在模型多強，而在阿里用限時、固定版本、只給訂閱用戶的方式，先收開發者的實測回饋。贏面在已有 Token Plan 的團隊，可以兩週內評估；輸家是直接換模型名稱的人，會被輸出預算新規則絆到。一般上班族不必急著試，等預覽結束後看阿里是否推出正式版與價格再評估。
