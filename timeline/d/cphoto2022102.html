Microsoft and Meta partner on immersive work｜Microsoft｜10 月 11 日 事件推薦

微軟（MSFT）與 Meta（META） 合作，把 Teams 與 Microsoft 365 帶進 Quest

微軟（MSFT）在 Meta（META） Connect 當天發文，說明將用哪些方式讓 Meta Quest 裝置進入企業工作流程。

這是什麼

這是微軟（MSFT）官方部落格對『微軟與 Meta（META） 合作』的說明，內容是軟體與管理：讓 VR 頭戴裝置可以開 Teams 會議、用 Office 類應用，並讓 IT 管理員像管電腦與手機一樣管頭戴裝置。

三點帶走

  1. 官方表示 Mesh for Teams 與 Microsoft（MSFT） 365 應用將上 Meta（META） Quest 裝置。
  2. Intune 與 Azure AD 將支援 Quest 的企業管理。
  3. Xbox Cloud Gaming 僅在『探索』階段，HoloLens 路線圖官方稱持續。

重點與分析

官方表示，Microsoft（MSFT） Teams 已成長到 2.7 億月活躍使用者，並引述 Work Trend Index 資料：50% 的 Z 世代與千禧世代預期在未來兩年內，部分工作會在元宇宙中進行。

文章用兩個數字鋪陳背景：Teams 的使用規模，以及年輕族群對元宇宙工作的預期。後者是微軟（MSFT）自家 Work Trend Index 的調查結果，文中沒有說明樣本數與問法，所以『50%』只能當作微軟引用的自家調查，不能直接當成市場事實。這段的作用是替後面的合作找理由，不是技術說明。

官方表示，Mesh for Teams 與 Microsoft（MSFT） 365 應用將登上 Meta（META） Quest Pro 與 Quest 2。

官方表示，Mesh for Microsoft（MSFT） Teams 將登上 Meta（META） Quest Pro 與 Meta Quest 2，讓人像在同一空間般連線協作；Microsoft 365 應用（Word、Excel、PowerPoint、Outlook、SharePoint）也將在 Meta Quest 裝置上可用。 Mesh for Teams 是把 Teams 會議放進三維共享空間的功能，官方說明它能在智慧型手機、筆電與混合實境頭戴裝置上使用。這代表微軟不是只做自家 HoloLens，而是把軟體放到競爭對手的硬體上，與文中『軟體可用於使用者喜愛的各種裝置』的平台公司立場一致。原文用『將』字，沒有給出上線日期。

官方表示，Windows 365 未來將上 Quest，Intune 與 Azure AD 將支援 Quest 的企業管理。

官方表示，未來 Windows 365 也將登上 Meta（META） Quest 裝置，可串流含個人化應用與設定的 Windows 雲端電腦；Microsoft（MSFT） Intune 與 Azure Active Directory 將支援 Quest Pro 與 Quest 2，讓 IT 管理員能為使用 Meta 的 Quest for Business 訂閱的使用者配置裝置。 這段偏向企業採用的門檻：企業要大量部署頭戴裝置，需要像管理電腦那樣的身分驗證與裝置管理。官方列出的是微軟既有的 Intune（裝置管理）與 Azure Active Directory（身分管理），也就是把 VR 納入現有 IT 流程，而不是另建一套。文中對 Windows 365 用的是『未來』，同樣沒有時間表。

官方表示，微軟（MSFT）與 Meta（META） 正探索把 Xbox Cloud Gaming 帶進 Meta Quest Store。

官方表示，微軟（MSFT）與 Meta（META） 正在探索把 Xbox Cloud Gaming 帶進 Meta Quest Store，讓玩家在手機、平板、電腦、部分智慧電視與 Meta Quest 平台上串流數百款高品質 Xbox 遊戲。 與前面的工作軟體相比，這項只寫『探索』，是文中確定性最低的一項。它說明合作範圍不只工作也包含遊戲，但沒有提到哪些遊戲能玩、是否需要訂閱，因此目前只能視為意向。

官方表示，這項合作補充（complements）微軟（MSFT）對 HoloLens 的承諾，微軟將繼續以雲端優先的方式發展混合實境裝置路線圖。

最後一段回應外界最可能的疑問：微軟（MSFT）是否放棄自家 HoloLens。官方的說法是不放棄，而是兩者並行；不過文中沒有給出 HoloLens 的產品時程，所以這句更像立場聲明，而非計畫細節。
