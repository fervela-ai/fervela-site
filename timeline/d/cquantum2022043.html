IBM 推出 Qiskit Runtime 基本介面與按秒付費方案

IBM 把『取樣』與『估算』變成量子系統的核心介面，並讓使用者用信用卡就能在雲端跑量子程式。

這是什麼

Qiskit Runtime 是 IBM 把量子與傳統運算綁在一起、在量子系統旁的傳統算力上執行『程式』而非單一電路的服務。這篇文章介紹它的兩個基本介面（primitives）：Sampler 與 Estimator，以及新的雲端計價方式。

三點帶走

  1. IBM 官方表示 Qiskit Runtime 先推出 Sampler 與 Estimator 兩個基本介面。
  2. 按用量付費方案在 IBM Cloud 以 beta 推出，兩台 27 量子位元 Falcon，每執行秒 1.60 美元。
  3. 錯誤抑制與緩解、Quantum Serverless 屬於官方預告的未來方向，文章未給時程。

重點與分析

IBM 表示，量子電腦與傳統電腦最大的不同，是能產生非古典機率分布；對機率分布最基本的操作是取樣與估算，因此第一批基本介面就是 Sampler 與 Estimator。

這是設計哲學的轉變：文章說開發者想表達的是需求（例如要多高的目標準確度、最長執行時間），而不是去控制底層細節，例如重複執行次數（shots）或錯誤緩解方法；新介面直接把『取樣』與『估算』變成對外的操作。文章說 Sampler 估計電路輸出的整個準機率分布，適合像 Grover 搜尋這類演算法；Estimator 計算可觀測量的期望值，可用於分子的電子結構、最佳化問題的成本函數、機器學習的核函數等。重點是介面層級被拉高了，但文章這個階段只是把介面定義出來，並未給出新介面相比舊流程的速度或準確度對照。

IBM 稱，Qiskit Runtime 以『執行程式』取代『執行電路』，省去使用者電腦與量子系統間的反覆通訊；2021 年 5 月曾對某量子化學演算法達到最高 120 倍加速。

這個脈絡解釋了為什麼要做 Runtime：傳統雲端模式每跑一個電路就要往返一次，排隊時間與通訊時間都被放大；把量子與傳統運算一起放在量子系統旁邊執行後，官方說使用者等待時間變短、一天能跑更多電路。文章引用的 120 倍加速是 2021 年的特定量子化學範例，並非這次新介面的成績，閱讀時不宜把兩者混在一起。文章也說未來還會加入錯誤抑制與錯誤緩解等工具，但這是『隨時間』推出的預告，並非本次已內建。

官方表示，新的按用量付費方案在 IBM Cloud 以 beta 推出，任何有 IBM Cloud 帳號的人都能使用兩台 27 量子位元 Falcon 處理器，費率為每執行秒 1.60 美元，無須訂閱或長期承諾。

在此之前，文章寫明使用 IBM 最先進的系統需要機構層級的專屬容量承諾。新方案把門檻降到信用卡或 IBM Cloud 點數，這對個人開發者、教學與小團隊是明顯的變化。但要注意範圍：開放的是兩台 27 量子位元的 Falcon，而不是 IBM 全部系統，且是 beta 階段。文中還提到 Strangeworks 成為第一個提供以用量計價存取 IBM Quantum 系統的 IBM 商業夥伴，顯示計價能力也透過 IBM Cloud 的帳務與使用者管理基礎設施開放給生態夥伴。

IBM 表示，未來方向包括建立允許彈性量子—傳統基礎設施配置的『無伺服器開發模型』（Quantum Serverless），讓開發者不必成為基礎設施專家。

文章最後描繪的願景是：開發者辨識出需要量子解法的問題、快速寫出程式、無縫執行，而不必設定硬體。官方把 Runtime 帶來的效率與速度提升描述為『可擴展』，並預告隨平台最佳化，程式可以在開發者不費力的情況下跑得更快。這些屬於路線圖層級的承諾，文章沒有給出時程；真正的檢驗點，是後續是否把錯誤抑制、錯誤緩解變成服務的預設能力，以及 Quantum Serverless 何時能讓開發者實際使用。
