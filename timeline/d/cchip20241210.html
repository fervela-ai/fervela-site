Marvell（MRVL） 與 AWS 的五年協議：客製 AI 晶片與雲端 EDA

新聞稿說明協議涵蓋的資料中心半導體範圍，以及 Marvell（MRVL） 以 AWS 雲端加速晶片設計的做法。

這是什麼

Marvell（MRVL） 是資料基礎設施半導體公司。這份協議把它供應給 AWS 的資料中心晶片（含客製 AI 產品）與它使用 AWS 做設計運算的兩個方向放在一起。

三點帶走

  1. Marvell（MRVL） 與 AWS 簽署五年期多世代協議。
  2. 涵蓋客製 AI 產品與多種互連晶片。
  3. Marvell（MRVL） 擴大使用 AWS 雲端進行 EDA。

重點與分析

官方表示，兩家公司擴大策略關係，簽署五年、多世代的協議，涵蓋多項 AWS 產品與 AWS 雲端基礎設施的使用。

協議的期間（五年）與『多世代』是公開的條件；稿中沒有提供金額、數量或具體產品型號，因此無法評估規模。

官方表示，協議涵蓋 Marvell（MRVL） 的客製 AI 產品、光學 DSP、AEC DSP、PCIe 重定時器、資料中心互連（DCI）光模組與乙太網路交換晶片。

清單中只有『custom AI products』與客製 AI 加速器直接相關，其餘為連接與互連晶片。這代表協議的範圍遠大於 AI 運算晶片本身，而新聞稿沒有拆分各項的比重。

官方表示，Marvell（MRVL） 採雲端優先做法，與 AWS 合作在雲端執行 EDA，以先進且可擴展的運算能力加速矽晶片設計；先進製程節點的設計工作負載具有突發性，AWS 的規模與彈性適合處理。

這是供應鏈之外的另一個面向：晶片設計本身的運算需求。稿中沒有提供縮短時間的數字，只有 Marvell（MRVL） 與 AWS 兩位執行長的說法。
