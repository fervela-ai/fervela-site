Microsoft Quantum Development Kit 1.0 發布｜Microsoft Quantum｜1 月 12 日 事件進階

Microsoft（MSFT） 重寫 QDK 發布 1.0：瀏覽器就能寫量子程式，舊專案需要移植

Microsoft（MSFT） 在 Q# 官方部落格宣布 Quantum Development Kit 1.0，這是對舊版的大幅重寫，主打瀏覽器可用、安裝簡化、最高 100 倍效能，並帶來除錯與資源估算功能。

這是什麼

QDK 是 Microsoft（MSFT） 提供的量子程式開發工具，核心語言叫 Q#。1.0 版把整套工具從頭重寫，讓開發者可以在瀏覽器版 VS Code 直接寫、模擬與除錯量子程式，也能用 Python 套件安裝。

三點帶走

  1. QDK 1.0 是重寫版，主打瀏覽器體驗、簡化安裝與最高 100 倍效能（官方說法）。
  2. 新增除錯器、稀疏模擬器、資源估算，並可從編輯器送程式到 Azure Quantum 硬體夥伴。
  3. 舊 QDK 專案需移植到新架構，因為 .csproj、NuGet、C# 整合已移除。

重點與分析

官方表示，1.0 是對舊 QDK 的大幅重寫，重點是速度、簡單與好用，亮點包含完整瀏覽器體驗、簡化安裝、最高 100 倍效能。

「最高 100 倍」是官方文中的說法，原文也沒有把比較對象與測試條件寫在這一則公告裡，而是引導讀者去看先前的技術文章。這代表它是一個上限值，而不是所有情境的平均。值得注意的是，這次的改變是「重寫」而非小改版，因此速度與安裝的改善來自底層架構更換；代價則寫在後面「舊專案要移植」的段落，兩者要一起讀。

官方表示，只要開啟 vscode.dev/quantum/playground，就能在瀏覽器中使用已預載 QDK 擴充套件的 VS Code，不必安裝也不必讀取本機檔案。

把開發環境放進網頁，降低了「想試試看」的門檻：初學者不用裝任何東西就能跑範例演算法。對教學與評估很有用。官方也提供本機安裝路徑：在 VS Code 擴充商店搜尋 QDK，安裝由 Microsoft（MSFT） DevLabs 發行的「Microsoft Quantum Development Kit」，並稱安裝在數秒內完成。需要注意的是，原文用「幾秒」描述，沒有提供實測時間。

官方表示，QDK 內含稀疏模擬器，可在 VS Code 擴充與 Python 套件中輸出診斷訊息與量子狀態，並提供可設中斷點、可單步執行、可在伴隨（adjoint）操作中倒著走的除錯器。

除錯器是這次最具體的新功能。量子程式的難處之一是看不到中間狀態，所以能在執行時同時檢視量子與傳統狀態很有價值；「倒著單步執行」是利用量子操作有反向（adjoint）版本的特性。稀疏模擬器（白話：只記錄有意義的量子態以省記憶體，此解釋為編者補充）。限制是模擬器仍然是在傳統電腦上算，模擬的量子位元數受電腦記憶體限制，原文沒有講上限。

官方表示，資源估算功能已搬進客戶端，可在編輯器內直接估算程式所需的實體資源，並與 Azure Quantum 服務整合，把 Q# 程式直接從編輯器送到硬體夥伴。

官方把資源估算放在「通往量子超級電腦路線圖」的脈絡裡：目前是 Level 1 的 NISQ（含雜訊的中等規模）時代，產業正朝 Level 2（開始使用邏輯量子位元）前進。資源估算的用途是在真實硬體出現前，先算出程式需要多少實體量子位元與多長時間。另外，若編譯器設成「base」設定檔而程式用到硬體不支援的功能，編輯器會立即報錯，避免送出才失敗。

官方表示，qsharp Python 套件只有數 MB、無相依套件；舊 QDK 稱 Classic QDK，新版稱 Modern QDK，舊專案需移植。

這一段是整則公告最重要的相容性訊息。新架構移除了以 .csproj 為基礎的專案架構、NuGet 套件發行與 C# 整合，所以既有專案與範例必須移植。舊版仍可執行既有程式，但官方明講新版才是後續版本的基礎，建議能移就移。對已有 C# 整合流程的團隊，這是需要規劃的搬遷成本，原文沒有給搬遷工具或時程。
