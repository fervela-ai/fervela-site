Claude computer use｜Anthropic｜3 月 23 日 產品入門

Claude 開始代操作電腦，便利與風險一起交到手上

Anthropic 推出 Claude computer use，讓 Claude 在取得許可後操作電腦上的應用程式，完成原本需要人逐步點選的工作。

這是什麼

這是 Claude Cowork 與 Claude Code 的電腦操作功能。當現有工具無法處理任務時，Claude 可以看螢幕、操作滑鼠與鍵盤；

三點帶走

  1. Claude 會優先使用連接工具，必要時才操作電腦畫面。
  2. 可從手機交辦，但電腦端應用程式需持續運作，成果仍要檢查。
  3. 功能仍在研究預覽階段，先從低風險、容易驗證的任務試用。

重點與分析

官方表示，Claude 會先使用 Slack、Google Calendar 等服務的連接工具；沒有適用的連接工具時，才透過瀏覽器、滑鼠、鍵盤與螢幕操作。

通鑑判斷，這個先後順序很關鍵。直接透過服務的連接工具辦事，通常比在畫面上尋找按鈕更明確；電腦操作則補上沒有連接工具的缺口。對上班族來說，可交辦的工作範圍可能因此擴大，但畫面只要改版、跳出視窗或出現模糊選項，Claude 就得重新判讀。交辦時仍要說清楚完成條件，並檢查最後結果。

官方舉例，搭配 Dispatch，可從手機交辦製作晨間簡報等任務，再回到電腦查看成果；電腦端應用程式必須保持開啟並持續運作。

通鑑判斷，手機交辦的吸引力在於人離開座位後，工作仍有機會繼續；但這是官方描述的使用情境，不能當作任務都能順利完成的實績。它也依賴電腦端持續運作。適合先從容易核對、出錯後能重做的工作試起，例如整理簡報材料；涉及對外送出或修改重要資料的步驟，則應保留人工確認。

官方表示，Claude 操作電腦前會要求明確許可，存取新的應用程式前也會再次詢問；使用者可隨時停止操作。

通鑑判斷，許可機制讓使用者有機會在 Claude 跨入新應用程式時確認界線，但它無法代替逐步檢查。一次許可之後，Claude 仍可能在該應用程式內做出不合預期的操作。交辦前值得先想好它可以讀取哪些資料、可以改到哪一步；執行期間也要留意畫面與成果，尤其是帳號、信件和共享文件。

官方提醒，這項功能仍是研究預覽版；複雜任務有時需要重試，透過畫面操作也比直接串接服務慢。官方建議先用信任的應用程式，避開敏感資料。

通鑑判斷，現階段應把它視為能代做部分操作的助手，而非可以放心放著不管的同事。速度與成功率會影響它是否真的省時：若任務經常卡住，人工接手和重試的成本可能高於自己完成。安全方面，官方也承認防護仍在改進，部分應用程式預設不可使用；實際試用宜從低風險、結果容易驗證的任務開始。

通鑑怎麼看

通鑑判斷，computer use 的價值是讓 Claude 能處理缺少連接工具、仍須在電腦畫面上操作的工作。它目前最適合有清楚目標、可核對成果、出錯可重做的任務。能否成為可靠的日常工具，值得觀察的是跨應用程式操作的穩定度，以及使用者需要花多少時間監督與修正。
