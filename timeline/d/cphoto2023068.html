visionOS SDK 開放：開發者可開始為 Vision Pro 做 App

Apple（AAPL） 6 月 21 日開放 visionOS SDK，讓開發者用熟悉的框架為 Vision Pro 設計空間運算 App，硬體測試則要等下個月的實驗室與開發者套件。

這是什麼

SDK 是開發者建立 App 所需的工具與程式介面。對頭戴裝置而言，內容與 App 是能否被使用的關鍵，所以 Apple（AAPL） 在 Vision Pro 發表後約兩週就開放工具，讓開發者在硬體上市前先備好內容。

三點帶走

  1. visionOS SDK 與 Reality Composer Pro 即日起提供給 Apple（AAPL） Developer Program 成員。
  2. 下個月在六個城市開設開發者實驗室，並開放開發者套件申請。
  3. Unity 移植下個月起支援。

重點與分析

官方表示，visionOS SDK、更新版 Xcode、Simulator 與 Reality Composer Pro 即日起提供給 Apple（AAPL） Developer Program 成員，並附有技術文件、新設計套件與更新的 visionOS 人機介面指南。

這是整份稿件的主訊息：工具已經能用，但硬體還沒到開發者手上。模擬器讓開發者在沒有裝置的情況下測試版面，卻無法驗證眼動、手勢追蹤、續航與光學舒適度這些只有真機才有的條件。這也是為什麼官方同時預告實驗室與開發者套件。

官方表示，開發者可使用 Xcode、SwiftUI、RealityKit、ARKit 與 TestFlight 等熟悉的框架，建立跨越沉浸程度的新型 App：有深度的視窗（windows）、可從任何角度觀看的體積（volumes），以及可完全沉浸的空間（spaces）。

三種容器對應不同沉浸度：視窗接近傳統 2D App 但可帶深度，體積是放在使用者空間裡的 3D 物件，空間則取代整個周遭環境。官方強調沿用既有框架，是為了降低既有 iOS 與 iPadOS 開發者的轉換成本；實際要把 2D 介面重做成空間介面，仍需要設計上的重新思考。

官方表示，下個月 Apple（AAPL） 將在 Cupertino、倫敦、慕尼黑、上海、新加坡與東京開設開發者實驗室，讓開發者在 Vision Pro 硬體上測試 App 並獲得工程師支援，開發團隊也可申請開發者套件。

六個實驗室覆蓋北美、歐洲與亞洲，顯示 Apple（AAPL） 預期開發者人數分布全球。實驗室名額與開發者套件的發放數量，官方沒有公布，所以開發者能否在上市前取得真機仍是未知。

官方表示，使用 Unity 開發 3D App 與遊戲的開發者，下個月起可將 Unity App 移植到 Vision Pro；官方並引述 Elsevier Health、Algoriddim、JigSpace 與 PTC 等開發者的展示與評語。

支援 Unity 很實際，因為不少 3D 內容與遊戲已用 Unity 製作，可以縮短內容空窗期。引述的四個案例涵蓋醫學教育（Complete HeartX）、音樂（djay）、產品溝通（JigSpace）與製造（PTC）。這些評語出自合作廠商，屬於官方挑選的案例，不代表整體開發者看法。

通鑑怎麼看

通鑑認為，這則新聞的重點在平台策略：硬體上市前先把工具、模擬器、實驗室與 Unity 支援都鋪好。至於內容是否足夠吸引使用者，要等開發者套件與實機出貨後才看得出來。
