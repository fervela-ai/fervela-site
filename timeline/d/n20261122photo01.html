Lambda 以 NVIDIA 光學交換器連接逾萬顆 GPU

Lambda 使用 NVIDIA Photonics 共封裝光學交換器，連接搭載超過 10,000 顆 GPU 的 NVIDIA GB300 NVL72 機櫃。NVIDIA 表示，Lambda 測試中的網路延遲在機櫃規模降低約 4%，在 pod 規模最多降低約 10%。

這是什麼

這款交換器將光學元件與交換器晶片放在同一封裝中。Lambda 測試顯示，在機櫃、可擴充單元與 pod 三種配置下，網路吞吐量與傳統可插拔光學元件相同。

三點帶走

  1. Lambda 使用 NVIDIA Photonics 交換器，連接搭載超過 10,000 顆 GPU 的 NVIDIA GB300 NVL72 機櫃。
  2. Lambda 的測試顯示網路延遲下降，但對整體工作的幫助可能因用途而異。

重點與分析

Lambda 使用 NVIDIA Photonics 共封裝光學交換器，連接搭載超過 10,000 顆 GPU 的 NVIDIA GB300 NVL72 機櫃。

當大量 GPU 同時運作，網路中斷可能拖慢整個訓練工作；這項部署值得看的是大規模叢集能否持續穩定運作。

NVIDIA 表示，Lambda 測試中的網路延遲在機櫃規模降低約 4%，在 pod 規模最多降低約 10%；三種測試配置的吞吐量則與傳統可插拔光學元件相同。

延遲改善可能有助於資料在叢集內更快傳遞，但對整體工作效率的影響，仍取決於實際工作如何使用網路。

NVIDIA 表示，這項技術相較傳統可插拔光學元件，能源效率最多提高 5 倍、可靠性最多提高 15 倍，使用的雷射數量減少 4 倍。

若這些特性在長期運作中持續成立，可能減少網路用電與元件故障帶來的中斷。

Lambda 使用的交換器各有 144 個 800Gb/s 連接埠；其回報的光學元件溫度中位數為 36°C，傳統可插拔光學元件為 51°C。

較低的運作溫度可能有利於設備穩定性，實際效果仍取決於部署與維護情況。

通鑑怎麼看

這項部署顯示，AI 叢集的效能可能取決於 GPU 之間的連接品質。值得持續觀察的是，測試中的延遲表現，以及 NVIDIA 所述的能源效率與可靠性優勢，能否轉化為長期運作效益。
