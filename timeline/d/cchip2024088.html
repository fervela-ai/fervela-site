Cerebras 推出晶圓級晶片驅動的推論服務

晶圓級晶片廠 Cerebras 於 2024 年 8 月 27 日宣布推論服務上線，並引用第三方 Artificial Analysis 的基準測試。

這是什麼

Cerebras 的 WSE-3 是把整片晶圓當作一顆晶片的處理器。這次不是賣硬體，而是把它包成雲端推論 API，讓開發者按 token 付費使用 Llama 3.1 模型。

三點帶走

  1. 官方宣稱 Llama 3.1 8B 每秒 1,800 token、70B 每秒 450 token，價格 10 美分與 60 美分每百萬 token。
  2. Artificial Analysis 量測 8B 逾 1,800、70B 逾 446 token/秒，並稱品質與 16 位元原生精度相符。
  3. 20 倍與 100 倍為對 GPU 雲端方案的比較，條件未列出。

重點與分析

官方宣稱，Cerebras Inference 在 Llama 3.1 8B 達每秒 1,800 個 token、70B 達每秒 450 個 token，比超大規模雲端的 NVIDIA（NVDA） GPU 方案快 20 倍；定價為 8B 每百萬 token 10 美分、70B 每百萬 token 60 美分，並稱價格效能高 100 倍。

價格單位需留意：新聞稿寫 60 cents（60 美分）每百萬 token。『20 倍』與『100 倍』都是公司對 GPU 雲端方案的比較，對手的具體配置、批次與精度並未列出。頁尾聲明稱比較依據第三方基準或內部測試，實際加速可能因工作負載、設定、日期與模型而異，這代表數字不宜視為通用倍數。

官方引述 Artificial Analysis 執行長 Micah Hill-Smith 的說法：他們測得 Llama 3.1 8B 每秒輸出超過 1,800 個 token、70B 超過 446 個，是該基準中的新紀錄，並已驗證品質評測結果與 Meta（META） 官方 16 位元原生精度相符。

這是少見有第三方量測背書的廠商發表：8B 的 1,800 與 70B 的 446（低於官方標題的 450）說明廠商數字與獨立量測接近。但引述的是廠商新聞稿中選取的段落，無法確認基準測試的完整條件。官方強調全程維持 16 位元精度，不以降低精度換速度。

官方表示，推論服務由 CS-3 系統與 WSE-3 處理器驅動，並稱 WSE-3 的記憶體頻寬是 NVIDIA（NVDA） H100 的 7,000 倍；服務分免費、開發者與企業三層，API 與 OpenAI Chat Completions API 相容，企業版可部署在 Cerebras 託管私有雲或客戶自有機房。

7,000 倍是官方拿晶片上 SRAM 頻寬對 H100 的 HBM 頻寬比較，原文沒有說明比較口徑。這個比較點出設計取捨：晶圓級晶片把記憶體放在晶片上換取頻寬，但能承載的模型大小受限，原文也沒有說明 70B 模型如何分配到晶片上。相容 OpenAI API 的介面降低了開發者換服務的門檻。

通鑑怎麼看

通鑑認為，這則的價值在於罕見的第三方量測：Artificial Analysis 的 8B 與 70B 速度與官方宣稱接近。但 20 倍與 100 倍的比較條件未公開，WSE-3 的取捨（片上記憶體容量）原文也沒有說明。
