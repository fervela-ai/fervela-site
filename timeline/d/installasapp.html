Install as app｜Anthropic｜11 月 24 日 產品推薦

Claude 產出變成桌面應用，真正的關鍵是權限

Anthropic 推出 Install as app，讓 Claude 製作的部分產出能以 Mac 或 Windows 應用程式開啟。

這是什麼

這項功能把原本在 Claude 裡使用的互動產出，變成有獨立圖示與視窗的桌面工具。它也能在取得許可後使用電腦功能，讓一份產出從臨時交付的頁面，走向每天會開啟的工作工具。

三點帶走

  1. Claude 的部分產出可裝成 Mac 或 Windows 應用程式，並隨原產出修改而更新。
  2. 通知與連接服務讓工具能融入日常工作；授予完整電腦存取權前，要確認它確實需要操作本機檔案。
  3. 功能正逐步開放，使用時須連線登入；向 Claude 發出的請求會計入方案用量。

重點與分析

Anthropic 表示，安裝後的產出會有自己的圖示和視窗，可分享給別人；修改原本的產出，應用程式也會自動更新。

通鑑判斷，這解開的是做完工具之後還要讓人持續使用的卡關。原本一份互動頁面可能藏在 Claude 對話裡，使用者得回頭尋找；現在它能像其他桌面程式一樣開啟。自動更新也讓製作者修改同一份產出後，使用者接著用到新版，不必重新寄送檔案。價值不在桌面多了一個圖示，而在臨時做出的工具有了固定入口，適合會反覆使用、也會持續調整的工作流程。

官方表示，安裝後的應用程式可以使用 Claude 與使用者的連接服務，也能在獲准後發送通知，或放進 Mac 選單列與 Windows 系統匣。

把連接服務想成讓工具取得已接入的工作資料：例如從行事曆和電子郵件準備會議資料，再於需要處理時發出通知。通鑑認為，這使 Claude 產出的角色從等人打開查看的頁面，轉向會在工作途中提醒人的工具。對上班族來說，差別是少一道主動檢查的步驟；對製作者來說，設計重點也從畫面呈現，延伸到何時提醒、提醒後能做什麼。通知若沒有對準真正需要處理的時刻，獨立安裝也難以帶來日常價值。

官方列出三級權限：預設限於瀏覽器可做的事；應用程式權限可要求通知等功能；完整電腦存取權則可執行程式及讀取、修改或刪除檔案，無須每次詢問。

通鑑判斷，權限選擇比安裝動作更值得花時間看。前兩級像把工具留在有欄杆的工作區；完整存取權則等於交出電腦檔案與程式的操作能力。官方表示，完整存取權只可給自己製作的應用程式；Team 與 Enterprise 使用者也可給組織內同事製作的應用程式。官方不會在安裝前審查應用程式，而且來自其他網站的部分可能變動而不再次詢問。實際選擇時，先看工具要完成的工作是否真的需要碰觸本機檔案，再決定給到哪一級。

官方表示，Install as app 正以測試版逐步開放所有方案；使用時須連線並登入 Claude，應用程式向 Claude 發出的請求會計入方案用量。Claude Docs、Slides、Sheets 等產出不能安裝。

通鑑認為，這些條件決定了它適合哪種工具。常用的查詢或整理頁面可以變得更好開啟，但只要工作需要 Claude 回應，就得把方案用量算進日常使用；必須離線開啟的工具也不適合依賴它。企業導入還多一道管理決策：官方表示 Team 預設開啟功能、關閉完整存取權，Enterprise 則須由擁有者開啟；HIPAA-ready 組織與混合部署不能使用。接下來最值得觀察的，是哪些反覆使用的工作工具，能在這些連線、用量與權限條件下持續被打開。

通鑑怎麼看

通鑑認為，Install as app 的進展，是讓 Claude 產出有機會成為持續使用的桌面工具。獨立入口、自動更新和通知，補上了從做出互動頁面到每天使用之間的缺口；而權限分級則決定工具能走多遠。最有價值的應用，會是需求明確、反覆使用，且所需權限說得清楚的工作工具。
