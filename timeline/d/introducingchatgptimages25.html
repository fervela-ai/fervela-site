Introducing ChatGPT Images 2.5｜OpenAI｜9 月 8 日 產品入門

ChatGPT Images 2.5 把修圖控制權交回使用者

OpenAI 發表 ChatGPT Images 2.5，除了提升生成與編輯能力，也在 ChatGPT 加入手繪構圖、圖片註解與提示詞分享功能。

這是什麼

ChatGPT Images 2.5 是 OpenAI 的圖像生成模型。這次更新的核心，是讓使用者更容易指定畫面、局部修改圖片，並在反覆調整時保留已有的成果。

三點帶走

  1. 需要局部修圖的人，應優先試多次修改能否保留不想動的部分。
  2. 官方宣稱的速度提升有比較對象及「最多」的條件，不能視為每次生成都快一半。
  3. 草圖、模板與圖片註解提供了比單靠文字更具體的表達方式。

重點與分析

官方表示，新模型更能保留參考照片中的主體特徵；修改指定元素時，也更能維持畫面其他細節。連續編輯後，先前的修改較可能保持一致。

通鑑判斷，這比單次生成一張好看的圖更貼近日常工作。製作商品照或簡報圖片時，常見的需求是換背景、改文字或調整局部，同時保留主體與版面。若每次修改都牽動整張圖，省下的製圖時間很快又會花在重做上。官方描述的是能力改善，實際能否穩定用於工作，仍要看複雜圖片和多次修改的結果。

官方宣稱，Images 2.5 的圖片生成延遲比 Images 2.0 最多降低 50%，並改善光線、材質與複雜視覺指令的處理。

通鑑判斷，速度的價值在於讓人願意多試幾種構圖與修改方式，而不是只等一張成品。不過「最多降低」不代表每次生成都快一半；官方文字也沒有交代不同圖片或工作情境下的速度分布。畫質同樣需要分開看：光線和材質更自然，不等於文字、版面及人物特徵在每張圖上都準確。

官方表示，使用者可在 ChatGPT 用 Sketch 畫草圖作為參考、從海報等模板開始製作、直接在圖片上加註解，並選擇連同圖片分享提示詞。

通鑑判斷，這些工具降低了描述畫面的門檻。想指定物件位置時，草圖可能比一長段文字清楚；想請模型改某個角落，直接在圖片上標註也更容易對準。模板適合快速起稿，分享提示詞則方便別人沿用做法。值得觀察的是，草圖和註解能否讓修改更精準，以及模板產出的圖片是否仍有足夠調整空間。

官方表示，開發者可透過 API 使用 GPT‑Image‑2.5 Flare 與 Sunburst；Flare 是多數應用的預設選擇，延續畫質、編輯與速度的改善，Sunburst 提供更細的編輯控制，但生成時間較長。

通鑑判斷，兩種選項反映圖片工作有不同取捨：大量製作初稿時，等待時間會影響流程；要細修正式圖片時，控制能力可能更重要。官方宣稱，Flare 相較 GPT‑Image‑2 有較高畫質及低 50% 的延遲，但這是指定模型間的比較，不能直接套用到所有 ChatGPT 使用情境。團隊仍需按自己的圖片類型檢查結果。

通鑑怎麼看

通鑑判斷，這次更新最值得留意的是「反覆修改」：從草圖指定構圖、在圖片上指出要改之處，到多次編輯時維持原有內容，都是為了讓圖片更接近可交付的成果。官方提出了多項改善，但實際工作仍應檢查人物、文字與版面是否在修改後保持一致。
