Amazon Braket 上架 Xanadu Borealis：第一個公開可用、有同儕審查優勢宣稱的量子電腦｜Amazon Web Services｜6 月 2 日 事件入門

Borealis 上 Braket：任何人都能自己驗證量子優勢宣稱

亞馬遜（AMZN）在 Nature 論文發表的第二天，把 Xanadu 的光子量子處理器放上雲端，讓研究者可自己檢驗優勢宣稱、探索應用。

這是什麼

Amazon（AMZN） Braket 是 AWS 的量子運算雲端服務，原本有超導與離子阱元件。這次加入光子元件，讓研究者能在同一服務下使用專用的高斯玻色取樣機器，並搭配 AWS 的古典運算去挑戰優勢宣稱。

三點帶走

  1. 官方宣稱 Borealis 是第一個公開可用、有同儕審查優勢宣稱的量子電腦。
  2. 它是專用的高斯玻色取樣機，不是通用量子電腦。
  3. AWS 自己也說優勢宣稱未必是定論，且應用屬推測性。

重點與分析

官方表示，Borealis 是第一個公開可用的量子電腦，且在同儕審查研究中宣稱有量子運算優勢。

這句話的措辭值得細看：AWS 寫的是「a claim to quantum computational advantage」，也就是宣稱，不是定論。部落格自己也提醒，量子優勢「不是一條硬性的界線」，宣稱常會激發更有效率的古典技巧，進而推動更大的量子裝置；所以 AWS 把開放存取視為鼓勵這種良性競爭。以往聲稱達成優勢的裝置都不對外開放，這是這次上架的新意。

官方說明，Borealis 以 216 個相位鎖定的光脈衝、6 MHz 時脈，通過三組延遲 1τ、6τ、36τ 的迴圈做干涉，其中 τ=167 奈秒。

部落格以白話重述論文的硬體：單一雷射產生脈衝串，每個脈衝是一個「qumode」（連續變數量子資訊單位，不同於只有兩個狀態的量子位元），經擠壓後送入可程式化迴圈干涉儀。最後用以超導轉變邊緣感測器為基礎的光子數解析偵測器讀出。這段與 Nature 論文一致，可作為論文的入門版本。

官方引用論文，估計富岳超級電腦平均要 9,000 年產生一個樣本，Borealis 只要 36 微秒，並說明仍有可能出現更有效的演算法。

AWS 在轉述數字時加上保留：「it remains to be seen」是否有人想出更有效率的演算法。這是比 Xanadu 新聞稿更謹慎的說法。此外部落格也說明，優勢任務本身未必有產業用途，只是技術上的必要而非充分條件；高斯玻色取樣能對應的圖論問題，其應用屬於「speculative」，量子優勢是否成立也不確定。

官方表示，使用者可用 Xanadu 的開源 Strawberry Fields 函式庫操作 Borealis，學術研究者可申請 AWS 研究點數。

使用方式上，電路必須遵守固定的閘序列格式，因為閘與實體干涉儀佈局綁定，使用者只能調整參數：初始擠壓、旋轉角度、分光器透射率。範例中取樣 250,000 次。這意味著它是專用機，不能拿來跑任意演算法。裝置在美東（維吉尼亞北部）區域，可用時段要看 Braket 主控台。

通鑑怎麼看

通鑑認為，這則的意義是優勢宣稱第一次可被外部檢驗；AWS 的措辭（宣稱、尚待觀察）比一般新聞稿保守，值得照其原意閱讀。
