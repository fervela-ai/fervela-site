哈佛：在真實都會光纖上做出兩節點量子網路

哈佛公報說，Mikhail Lukin 團隊用鑽石中的矽空位色心當量子記憶節點，展示了在繁忙都會環境中實現糾纏的可行性。

這是什麼

量子網路是用單一光子攜帶量子資訊的網路，與傳統網路用古典位元不同。難題之一是訊號衰減無法用一般光纖中繼器補強，因為量子資訊不能被直接複製。哈佛團隊用具備記憶功能的節點來接力，並在真實的商用光纖上測試。

三點帶走

  1. 官方表示，哈佛在約 22 英里的波士頓都會光纖上糾纏了兩個量子記憶節點。
  2. 官方稱這是量子記憶節點間最長的光纖距離，與 AWS 研究人員合作並發表於 Nature。
  3. 目前只有兩個節點，下一步是增加節點與協定。

重點與分析

官方表示，哈佛團隊在經過劍橋、薩默維爾、沃特敦與波士頓的約 22 英里光纖迴路上，糾纏了兩個量子記憶節點。

『最長』指的是能儲存、處理並傳遞資訊的裝置之間的光纖距離，並非所有量子網路中最長的距離。公報也提到，兩個節點實際上相隔一層樓，位於同一棟實驗室內，光纖是迴路。因此這個展示重點是『在真實光纖環境中』，而不是兩個遙遠地點間的實際連線，讀者要區分這兩者。

官方表示，每個節點是鑽石薄片中的矽空位色心，有兩個位元：用於通訊的電子自旋，與壽命較長、用來儲存糾纏的核自旋記憶位元。

這個設計說明了『量子記憶』的實體形式：把通訊與儲存分給兩個不同壽命的位元。公報說，這項技術解決了量子網際網路的主要難題之一，也就是無法以傳統方式增強的訊號損失。矽空位色心需冷卻到接近絕對零度，這是系統的實際代價，公報沒有深入討論。

官方表示，光子先通過第一個節點而與之糾纏，再把糾纏轉移到第二個節點，團隊稱之為光子介導的糾纏。

這種做法是量子中繼器的基本構件：用光子當信使，把兩個遠端記憶節點連成糾纏對。第一作者 Can Knaut 解釋了這個流程。公報沒有給出糾纏的成功率或保真度，只說明方法可行，所以還不能推斷實際網路的通訊速率。

官方表示，團隊多年來向波士頓一家公司租用光纖，將示範網路架設在既有光纖上，以顯示類似網路線路也能建成量子網際網路。

這點是研究的實際意義：使用的是商用電信光纖，而不是專門為實驗鋪設的線路。不過『可行』仍是示範階段，Lukin 的說法是這是『邁向實用的量子電腦間網路的重要一步』。團隊下一步是增加節點並嘗試更多網路協定，目前只有兩節點。

官方表示，這項工作得到 AWS 量子網路中心與哈佛量子計畫研究聯盟、美國國家科學基金會等單位的支持。

公報明確說明 Nature 論文是與 Amazon Web Services（AMZN） 的研究人員一同完成，並標出資助來源。這提醒讀者，雲端業者正投入量子網路的研究，但公報沒有談商業化時程。論文題目為『Entanglement of Nanophotonic Quantum Memory Nodes in a Telecom Network』，有興趣可查原文。
