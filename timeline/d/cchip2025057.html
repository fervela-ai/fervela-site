NVIDIA（NVDA） Grace CPU C1 瞄準邊緣與電信的低功耗場景

NVIDIA（NVDA） 在 5 月 18 日的部落格介紹 Grace CPU C1 的客戶與應用，強調每瓦效能。

這是什麼

Grace 是 NVIDIA（NVDA） 自行設計、以 Arm（ARM） 架構為基礎的資料中心 CPU。除了與 GPU 組成的 Grace Blackwell，另有雙 CPU 的 Grace Superchip，以及這次強調的單 CPU 版本 Grace CPU C1，適合電力受限的分散式部署。

三點帶走

  1. Grace CPU C1 是單 CPU 版本，鎖定邊緣、電信與儲存。
  2. 官方宣稱能效比傳統 CPU 高 2 倍，稿中未說明比較對象。
  3. 多家系統廠宣布開發中，尚無大量部署數據。

重點與分析

官方表示，Grace 架構現有兩種主要配置：雙 CPU 的 Grace Superchip 與新的單 CPU Grace CPU C1；C1 在邊緣、電信、儲存與雲端部署中受到關注，因為每瓦效能最重要。

文中的 C1 定位清楚：不是追求單機最高算力，而是在電力與空間受限的環境運作。稿中沒有給出 C1 的核心數、時脈、記憶體頻寬或功耗，所以「受歡迎」只能理解為夥伴宣布支持，沒有銷量或出貨數字可驗證。

官方宣稱，Grace CPU C1 的能效比傳統 CPU 高 2 倍；Foxconn、Jabil、Lanner、MiTAC Computing、Supermicro 與 Quanta Cloud Technology 正開發採用它的系統。

「2 倍」在原文寫成 claimed，並沒有說明對照的是哪一款傳統 CPU 或哪種工作負載。夥伴名單全是系統製造商，代表現階段多為系統設計階段，而不是已大量部署的客戶案例。

官方表示，電信領域的 NVIDIA（NVDA） Compact Aerial RAN Computer 結合 Grace CPU C1、L4 GPU 與 ConnectX-7 SmartNIC，用於分散式 AI-RAN；WEKA 與 Supermicro 也把 Grace 用在儲存方案。

AI-RAN 是把 AI 運算放進行動基地台網路，需要小體積、低功耗，與資料中心機房條件不同。這是 C1 的主打場景之一，但稿中沒有電信業者名稱，也沒有現場部署數據。

官方表示，Grace Blackwell NVL72 整合 36 顆 Grace CPU 與 72 顆 Blackwell GPU；ExxonMobil 用 Grace Hopper 做地震成像，Meta（META） 用於廣告推薦，德州先進運算中心與台灣國家高速網路與計算中心也使用 Grace CPU。

這幾個客戶案例都是 Grace Hopper 或 Grace 系統，而非本篇主角 C1，所以不能直接當作 C1 的成果。Meta（META） 一例特別提到 NVLink-C2C（CPU 與 GPU 之間的高頻寬互連）用來處理龐大的推薦資料表。

通鑑怎麼看

通鑑認為，這則偏向夥伴與場景的宣傳稿，缺少 C1 的規格與實測。2 倍能效是 NVIDIA（NVDA） 宣稱，對照基準不明。
