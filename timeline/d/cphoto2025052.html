Android XR SDK 開發者預覽版 2 上線

Google（GOOGL） 在 I/O 期間發布 Android XR SDK 開發者預覽版 2，補強影片、手部追蹤、模擬器與 Unity 支援。

這是什麼

SDK 是軟體開發套件。這次更新讓開發者可以用熟悉的 Android 工具與開放標準為 XR 裝置寫 App，並預告 Android XR 首批裝置。

三點帶走

  1. Android XR SDK 開發者預覽版 2 新增影片、手部追蹤與模擬器整合。
  2. Samsung Project Moohan 先上市，之後是 XREAL Project Aura。
  3. 眼鏡的開發者參與方式，原文說之後再公布。

重點與分析

官方表示，Jetpack XR SDK 現在可播放 180° 與 360° 影片，立體影片可用 MV-HEVC 規格編碼；Jetpack Compose for XR 可定義適應不同 XR 顯示配置的版面，Material Design for XR 也支援更多元件覆寫。

MV-HEVC 是專為立體影片設計的編碼規格。這些都是開發工具層面的更新，使一般 Android App 比較容易調整成 XR 版本，原文沒有講到使用者能感受到的數據改善。

官方表示，ARCore for Jetpack XR 現在可在取得權限後追蹤手部，手部由 26 個姿態關節組成，可用來偵測手勢；Android XR 模擬器改善穩定性、支援 AMD GPU，並完整整合進 Android Studio；Unity 套件新增動態更新率、SpaceWarp 支援等。

手部追蹤需要使用者授權，這是平台設計上的隱私邊界。Unity 側的動態更新率與 SpaceWarp 都是降低運算負載、省電的手段，但原文沒有提供效能數字。

官方表示，Android XR 將先出現在 Samsung 的 Project Moohan，當年稍後推出；隨後 XREAL 將推出代號 Project Aura 的可攜式有線裝置，並以開發者版本推出。Google（GOOGL） Play 也將為 Android XR 上架做準備。

這段把硬體時程講得具體：首款是頭戴裝置，隨後是 XREAL 的有線眼鏡型裝置。至於眼鏡，原文說「正在形塑開發者體驗」，之後才會公布參與方式，所以眼鏡的開發套件尚未開放。

通鑑怎麼看

通鑑認為：這則的價值在於平台時間表與工具鏈：開發者已能開始為 Android XR 寫 App，首批裝置的順序也講清楚。眼鏡型裝置的開發者參與方式仍待後續公布。
