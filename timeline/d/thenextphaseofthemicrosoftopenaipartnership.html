微軟與 OpenAI 修訂合作：Azure 仍優先，雲端選擇更開放

微軟在官方公告中說明與 OpenAI 修訂合作協議，雲端供應、技術授權與分潤方式都出現變化。

這是什麼

這是一份重新劃定雙方合作權利的協議。微軟保有主要雲端夥伴地位，OpenAI 則取得更大的雲端供應與產品選擇空間。

三點帶走

  1. Azure 仍是優先推出平台，但協議設有例外。
  2. OpenAI 可透過任何雲端供應商提供產品；這是權利變更，不等於各平台已全面供應。
  3. 微軟保留技術授權與股權利益，分潤安排則已改變。

重點與分析

官方表示，微軟仍是 OpenAI 的主要雲端夥伴；OpenAI 產品會優先在 Azure 推出，除非微軟無法且選擇不支援所需能力。

通鑑判斷，這保留了 Azure 的優先位置，但優先並不等於獨家。對採購 AI 服務的企業來說，值得觀察的是產品首次推出的平台，與後續實際可購買、可部署的平台是否相同。公告沒有列出哪些能力可能觸發例外，因此不能把這項條款解讀成所有新產品都必定先在 Azure 上架。

官方表示，OpenAI 現在可以透過任何雲端供應商，向客戶提供旗下所有產品。

通鑑判斷，這項權利可能讓使用其他雲端的企業更容易評估 OpenAI 產品，卻不代表每項產品已在各家雲端推出。企業仍須看實際供應情況，包括所在地區、可用功能與採購條件。它也與 Azure 優先推出的條款並存：先在哪裡發布，和之後能在哪裡提供服務，是兩件需要分開看的事。

官方表示，微軟繼續取得 OpenAI 模型與產品的智慧財產授權（期限至 2032 年），但授權改為非獨家。

通鑑判斷，微軟仍能依授權使用相關技術，同時不再獨占這項授權；這可能改變其他業者取得授權的空間。非獨家只說明微軟不再是唯一被授權的一方，不能據此推定其他公司已拿到相同權利。企業在比較產品時，仍應看各項服務實際提供的模型、功能及合約條件。

官方表示，微軟不再向 OpenAI 支付營收分潤；OpenAI 向微軟支付的分潤則持續到 2030 年，不受 OpenAI 技術進展影響，維持原比例，並設有總額上限。微軟仍是 OpenAI 的主要股東。

通鑑判斷，雙向分潤改成單向，加上總額上限，使雙方未來的收入關係有了較清楚的邊界。不過，公告沒有提供原比例或上限金額，無法計算哪一方會因此增加多少收入。微軟仍持有股份；授權、雲端業務與股權利益應分開理解，不能只憑分潤條款判斷整體得失。

通鑑怎麼看

通鑑判斷，這份協議的核心是讓緊密合作與各自擴展同時成立。微軟保有雲端優先權、技術授權及股東身分；OpenAI 則能跨雲端提供產品。對企業最實際的問題，是產品何時、在哪個雲端，以哪些條件供應。協議劃出了權利範圍，實際選擇仍要等產品供應情況明朗。
