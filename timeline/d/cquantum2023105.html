Pasqal 發表 Qadence 數位類比量子程式庫｜Pasqal｜10 月 11 日 事件進階

Pasqal 推出開源量子程式庫 Qadence

官方表示，Qadence 是開源 Python 函式庫，目標是讓研究者更容易在互動式量子位元系統上寫數位類比量子程式。

這是什麼

數位類比量子運算（DAQC）是把數位式運算的精準度，與類比式運算對量子位元連續控制和交互作用的能力結合的混合做法。Qadence 是替這種做法準備的軟體工具。

三點帶走

  1. 官方表示 Qadence 是開源 Python 程式庫，專為數位類比量子程式設計。
  2. 整合 PyTorch 自動微分，著重量子機器學習。
  3. 路線圖包含雜訊通道與錯誤緩解，目前尚未涵蓋。

重點與分析

官方表示，Qadence 是用於建構與執行數位類比量子程式的開源 Python 程式庫，並稱 DAQC 結合數位運算精準度與類比運算的連續控制和交互作用。

這則新聞的類別是軟體而非硬體。原文說 Pasqal 的下一代中性原子量子電腦將能原生執行數位類比演算法，意思是原生執行是下一代設備的能力；新聞稿沒有說明現在能在哪些真機上跑。原文把 DAQC 視為「可能的早期量子優勢路徑」，這是公司的判斷，並非已證實。

官方表示，Qadence 在量子機器學習上特別突出，具備原生符號參數、與 PyTorch 自動微分引擎整合，以及適用於真實中性原子設備的高階微分參數位移規則。

自動微分整合的意義是：量子電路的參數可以像神經網路一樣被訓練，讓熟悉 PyTorch 的開發者較容易上手。參數位移規則是在量子硬體上算梯度的方法，因為量子狀態不能像古典程式那樣直接取導數。原文沒有給任何效能數字或與其他程式庫（如 Pennylane、Qiskit）的比較。

官方表示，Qadence 讓開發者能建構類比與數位類比演算法、從模擬轉到真實設備，並把部分類比操作轉成類似數位電路的高效模擬。

「從模擬轉到真實設備」是設計目標，原文沒有說明目前有哪些設備可用、使用限制為何。這類工具的實際價值，取決於模擬器能否處理夠大的系統，以及真機何時開放，這兩點原文都未交代。對沒有量子硬體的研究者來說，能先在模擬器上建立、除錯程式，是最直接的好處。

官方表示，Pasqal 打算讓 Qadence 加入雜訊通道、針對交互作用量子位元的錯誤緩解技術，以及更多數位類比模擬模式。

路線圖中提到雜訊與錯誤緩解，說明目前版本尚未涵蓋這些，而真機實驗最需要它們。軟體副總裁 Mario Dagrada 稱 Qadence 補上了現有量子軟體生態中對 DAQC 的缺口，這是公司自己的定位說法。

官方表示，Pasqal 把自己定位為中性原子量子運算公司，Qadence 的目標是成為執行數位類比程式的「黃金標準」。

「黃金標準」是公司的抱負用語，原文沒有列出採用者數量、授權方式細節，只說是開源。軟體生態通常需要社群長期投入，所以這則新聞能確認的是起點：功能設計方向清楚，但成熟度與影響力還要觀察。
