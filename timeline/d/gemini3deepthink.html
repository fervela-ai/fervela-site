Gemini 3 Deep Think 把推理能力帶進研究現場

Google DeepMind 在官方文章介紹 Gemini 3 Deep Think 的更新，重點放在科學研究與工程問題。

這是什麼

Gemini 3 Deep Think 是 Google DeepMind 的專門推理模式。這次更新聚焦資料不完整、答案未必唯一的研究與工程難題，並開始提供研究人員透過 API 申請測試。

三點帶走

  1. 官方舉了論文邏輯檢查、晶體生長配方設計等研究用途。
  2. 閱讀測試分數時，要保留測試項目與是否使用工具等條件。
  3. 訂閱者可在 Gemini app 使用；透過 API 測試仍須申請早期存取。

重點與分析

官方表示，羅格斯大學數學家 Lisa Carbone 用 Deep Think 審閱一篇高度專業的數學論文，找出先前人工同儕審查未發現的細微邏輯缺陷。

通鑑判斷，這個案例比單純答對數學題更能說明用途：研究者可以請模型檢查既有論證，把注意力放在可能出錯的推導環節。不過，官方提供的是單一案例，尚不能據此推定它能穩定找出各類論文的錯誤。研究者仍需要自行核對模型指出的問題，再決定是否修改結論。

官方表示，杜克大學 Wang Lab 用 Deep Think 設計複雜晶體生長的製程配方；官方宣稱，配方達到生長超過 100 微米薄膜的指定目標。

通鑑判斷，這顯示模型的角色可能從解釋知識，延伸到提出可供實驗的具體方案。對工程團隊來說，價值在於能否縮短尋找候選做法的過程，而不是模型寫出配方就代表材料研發完成。官方文字沒有交代這套配方在其他條件下的表現，也無法從這個案例判斷它是否普遍適用。

官方宣稱，Deep Think 在不使用工具的 Humanity’s Last Exam 測試得分 48.4%；官方宣稱，在經 ARC Prize Foundation 驗證的 ARC-AGI-2 測試得分 84.6%。

通鑑判斷，兩項測試提供了觀察推理能力的線索，但測試成績不能直接換算成工作上的可靠度。它們考驗的題型與研究者手上的混亂資料、實驗限制並不相同；其中一項明確是在不使用工具的條件下取得成績。讀者比較模型時，需要連同測試名稱與條件一起看，避免把不同測試的百分比當成同一把尺。

官方表示，Google AI Ultra 訂閱者可在 Gemini app 使用更新後的模式；研究人員、工程師與企業可申請透過 Gemini API 早期測試。

通鑑判斷，這次更新同時面向個人操作與研究流程整合，但兩者的開放程度不同。訂閱者已有 app 入口；API 則需申請早期測試，不能視為所有團隊都已能接入。值得觀察的是，研究團隊取得 API 後，能否把模型提出的檢查結果或設計建議接進現有驗證流程，並留下可供人員複核的紀錄。

通鑑怎麼看

通鑑判斷，Deep Think 最值得關注的不是單一排行榜分數，而是它能否在論文檢查與實驗設計中，提出可由專家驗證的線索。官方案例已展示具體用途，但案例數量與測試條件仍有限；把它當成協助提出、檢查方案的工具，比直接採納答案更符合目前證據。
