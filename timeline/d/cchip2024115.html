Cerebras 公布 Llama 3.1-405B 推論 969 tokens/秒｜Cerebras Systems｜11 月 18 日 事件進階

Cerebras 以 WSE-3 跑 Llama 3.1-405B：969 tokens/秒，客戶試用中

Cerebras 宣布其推論服務在 Llama 3.1-405B 模型上創下速度紀錄，並公布價格與供貨時程。

這是什麼

Cerebras 的晶片是一整片晶圓大小的 Wafer Scale Engine 3（WSE-3），CS-3 系統以它為核心。這份新聞稿說明它在最大的開源模型上的推論速度與供貨條件。

三點帶走

  1. Cerebras 稱 Llama 3.1-405B 推論達 969 tokens/秒，首 token 240 毫秒。
  2. 官方稱 WSE-3 記憶體頻寬是 H100 的 7,000 倍。
  3. 大模型目前客戶試用，預計 2025 年第一季全面上市。

重點與分析

官方表示，Cerebras Inference 在 Llama 3.1-405B 上產生 969 個輸出 token／秒，首個 token 時間 240 毫秒，並以 128K 完整上下文長度、16 位元精度執行客戶工作負載。

『128K 完整上下文』與『16 位元精度』這兩個條件讓這個速度更有可比性，因為縮短上下文或降低精度都能提高速度。但新聞稿也說，『最高比 GPU 快 75 倍』與同一頁後面的『最高快 74 倍』並不一致，兩個數字出自同一稿，實際比較對象與條件只有 Artificial Analysis 的資料能確認。

官方表示，WSE-3 的記憶體頻寬是 Nvidia H100 的 7,000 倍，這解決了生成式 AI 的根本技術挑戰──記憶體頻寬。

7,000 倍是 Cerebras 自行與 H100 做的比較，新聞稿沒有說明比較的是哪一種記憶體、或測量方式。新聞稿把記憶體頻寬視為生成式 AI 推論的關鍵限制，這是 Cerebras 自己的論點。

官方表示，Llama 3.1-405B 目前在客戶試用中，預計 2025 年第一季全面上市，價格為每百萬輸入 token 6 美元、每百萬輸出 token 12 美元；API 與 OpenAI Chat Completions API 相容。

『客戶試用中』表示該速度尚未對所有人開放。價格與相容 API 讓客戶能以少量程式修改遷移，但新聞稿沒有說明試用名額與容量，所以實際供應量不明。

官方表示，更快的推論速度可以讓模型使用鏈式思考等執行期技術，花更長時間『先思考再回答』，Cerebras 稱可使模型在最高快 74 倍的條件下思考更久並產生更準確的結果。

這是 Cerebras 把速度優勢連結到推理型模型的說法；新聞稿引用 OpenAI 等的研究方向，但沒有提供自家服務在推理基準上的準確度資料。因此這段是推論，不是量測結果。

通鑑怎麼看

通鑑認為，Cerebras 的賣點是以晶圓級晶片換取推論速度與記憶體頻寬。但新聞稿同一頁出現 75 倍與 74 倍兩個數字，且大模型仍處於客戶試用階段，讀者應等 2025 年第一季全面上市後再看實際表現。
