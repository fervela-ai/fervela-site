EmbeddingGemma 2｜Google｜10 月 6 日 模型進階

Google 押注手機上的跨媒體搜尋

Google DeepMind 在官方網頁推出 EmbeddingGemma 2，前代只處理文字，這一代把文字、程式、圖片、影片與音訊收進同一套向量。

這是什麼

EmbeddingGemma 2 是 Google 的輕量開源模型，把文字、程式、圖片、音訊與影片編成同一套向量，讓應用程式能在手機等裝置上離線比對哪些內容彼此相近。它負責搜尋與檢索，不是聊天。

三點帶走

  1. 官方表示可在裝置上做完全離線的跨媒體搜尋；單次音訊最多 5.5 分鐘，數小時錄音如何分段，這篇文字沒說明。
  2. 記憶體數字帶條件：官方宣稱在量化後的 Pixel 11 Pro 上，文字權重執行時約 191MB，完整多媒體約 567MB。
  3. MTEB Code 的 9.92 分是官方宣稱、相對前代；下載超過 2,000 萬次也是官方對前代文字模型的說法。

重點與分析

官方表示，EmbeddingGemma 2 把文字、圖片、音訊與影片的組合，原生映到同一套向量空間。同一個模型可以依語音備忘找出特定影片片段，或依文字查詢，在數小時的錄音裡搜尋。

通鑑判斷，對上班族比較有感的是檔案留在自己的裝置上，用一句話或一段聲音對應照片、錄音與影片。官方以能協助來描述這些找法，並請人在 Google AI Edge Gallery 試用；這篇文字沒有職場採用數據。值得觀察長度：官方宣稱上下文 8K 詞元、為前代 4 倍，本機最多處理 5.5 分鐘音訊、29 張圖、58 個影片畫格，或交錯組合。數小時錄音與單次 5.5 分鐘寫在一起，分段方式這篇文字沒有說明。可能要開發者自己切段，好不好找要看試用結果。

官方宣稱模型有 7.4 億參數；只做文字最少約 2.7 億，視覺編碼器 1.7 億、音訊編碼器 3 億可另開。經量化後在 Google Pixel 11 Pro，文字權重的執行時記憶體可低到約 191MB，完整多媒體約 567MB。

通鑑判斷，這組數字在講佔用，不在講答得比雲端模型準。約 191MB 與約 567MB 都有前提：做過量化，且是 Pixel 11 Pro；這篇文字沒有其他手機的數字，不能看成每支手機都裝得下。文字、視覺與音訊可拆開載入，只留文字較接近 191MB，完整多媒體才約 567MB。官方另宣稱，向量可從 768 維截到 512、256 或 128 維，本機資料庫與記憶體用量最多降為六分之一，此為上限。官方表示與 Gemma 4 共用文字分詞器與音訊編碼器，一起跑時合計記憶體較低，但沒有寫出低多少。

官方宣稱，參數未滿 10 億的多媒體嵌入模型裡，MTEB Code 與 MAEB 等評測由它取得同體積領先，文字、視覺與音訊追平或超過許多更大模型。官方宣稱 MTEB Code 從 68.76 分升到 78.68 分、提升 9.92 分，且多語文字與前代相當。

通鑑判斷，9.92 分只是 MTEB Code 上跟前代的差距，不能換成找檔案少錯一成。官方宣稱，圖像、影片、文件與音訊在未滿 10 億參數的模型裡，以單位參數的水準創下新標準，並超過一些體積超過它兩倍的專門模型；一些不是全部，公告沒有點名，完整分數放在模型卡。官方表示前代下載超過 2,000 萬次、超出預期，用於裝置上搜尋與重視隱私的檢索增強生成；那是文字版，不能記成這一代的用量。官方說新版適合本機程式索引、語意搜尋與寫程式 AI 代理的檢索，公告沒有企業採用數字。

通鑑怎麼看

通鑑判斷，這篇要看的是小模型能否在手機上做跨媒體搜尋。官方寫的最有能力、同體積領先與新標準，是廠商自己的評價，要連評測名稱和比較範圍一起讀。官方以 Apache 2.0 釋出，可商用。官方表示它與 Gemma 4 共用文字分詞器及音訊編碼器，一併執行時合計記憶體較低；搭配 Gemma 4 等生成模型，可在裝置上做多媒體檢索增強生成。本機產生向量，官方表示有助確保資料隱私、降低流程延遲，並能完全離線；幅度沒有數字。
