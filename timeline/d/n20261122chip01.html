SK hynix 展示連接多個運算型記憶體單元的 Custom HBM Array

SK hynix 在 Supercomputing 2026 展示 Custom HBM Array 的技術概念、產品模型與說明資料，並陳列 HBM4E、HBM4 與 HBM3E。

這是什麼

Custom HBM Array 採用連接多個具運算功能的 cHBM 單元的結構。SK hynix 預期，與傳統以 GPU 為核心的系統相比，這種設計可縮短回應時間、提高能源效率，並減輕資料搬移的瓶頸。

重點與分析

SK hynix 表示，傳統以 GPU 為核心的系統可連接的 HBM 單元數量固定，限制了頻寬能擴充的程度；執行大型語言模型的答案生成工作時，也會浪費 GPU 資源。

值得看的是，把部分運算放進記憶體後，實際工作負載能否減少 GPU 資源耗用；成效可能取決於系統如何分配運算。

Custom HBM Array 以多個具運算功能的 cHBM 單元相連。SK hynix 說明，cHBM 可依需求加入功能；整合運算功能時，可將記憶體與運算單元垂直堆疊，縮短資料傳輸距離。

這種設計可能減少資料在記憶體與運算單元之間往返；能否帶來預期效益，仍取決於實際系統與工作負載。

SK hynix 在展區並列展示 HBM4E、HBM4 與 HBM3E。

這顯示公司同時展示現有產品與下一代產品方向；Custom HBM Array 值得持續觀察的是它如何與這些產品搭配。
