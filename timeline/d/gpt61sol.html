GPT-6.1 Sol 把高階 AI 任務的成本往下壓

OpenAI 發表 GPT-6.1 Sol，主打程式開發、文件處理與電腦操作。這次值得看的，是它在特定測試中接近 GPT-6 Astra 的表現，以及完成任務所需的成本。

這是什麼

GPT-6.1 Sol 是 GPT-6 Sol 的升級模型，供訂閱者在 ChatGPT Work、Codex 使用，也開放開發者透過 API 存取。它的定位是以較低成本處理需要多步推理與操作的工作。

三點帶走

  1. 程式開發、專業文件與電腦操作，是這次最值得留意的應用。
  2. 比較模型時，要連同測試條件、推理強度與單題成本一起看。
  3. 符合資格的訂閱者可在 ChatGPT Work 或 Codex 使用；一般 Chat 介面尚未提供。

重點與分析

在真實程式庫的複雜開發任務測試 DeepSWE v1.1，官方宣稱 GPT-6.1 Sol 的成績與 GPT-6 Astra 相當，成本約為後者的五分之一；它也以較低的推理強度與成本，超過 GPT-6 Sol 最佳成績 6.4 個百分點。

通鑑判斷，這是對軟體團隊最具體的進展：如果較便宜的模型能完成同類型的長時間開發任務，團隊就可能把更多工作交給 AI 代理反覆嘗試。不過，成績來自指定測試環境；實際專案的程式庫、工具與審查方式不同，採用前仍要用自己的任務確認完成率和總花費。

在需要讀懂表格、圖表與細節的專業 PDF 問答測試 GDP.pdf，官方宣稱 GPT-6.1 Sol 在受測推理設定下，得分高於帶有備援機制的 Opus 5.5，單題成本不到其一半；相較 GPT-6 Astra，單題成本約為五分之一。

通鑑判斷，這項結果與一般辦公室的文件工作較有關係，因為難處往往藏在表格、圖示或小字裡。但測試衡量的是回答指定問題的準確度，不能直接推成模型能獨立審核整份契約、財報或醫療文件。若要用於重要決策，仍應讓人核對它引用的頁面與數字。

在跨應用程式操作的 OSWorld 2.0 離線測試集，官方宣稱 GPT-6.1 Sol 在最高推理強度下，比 GPT-6 Sol 高 7 個百分點，成本不到一半；與 GPT-6 Astra 的成績相差 2.1 個百分點，單題成本約為七分之一。

通鑑判斷，電腦操作能力若持續改善，AI 代理可能更適合處理必須在不同畫面間切換的工作。不過，這裡報告的是特定版本離線測試集的部分獎勵分數，並非所有任務都已完整成功。企業評估時，值得特別看它能否遵守操作限制，以及遇到錯誤後是否停下來請人確認。

在刻意挑選的困難事實查核題目中，官方宣稱 GPT-6.1 Sol 以低推理強度作答時，含有事實錯誤的回答比例，從 GPT-6 Sol 的 11.4% 降至 7.7%。官方也說明，這批題目不代表一般使用情況。

通鑑判斷，低推理強度下的改善值得注意，因為使用者未必每次都願意等待模型深入思考。但這個指標只記錄回答是否至少有一處事實錯誤，無法說明錯誤的嚴重程度；題目又來自曾被使用者指出錯誤的對話。因此，它能顯示模型在困難題目上的相對進步，不能當成日常回答的出錯機率。

官方宣稱 GPT-6.1 Sol 的標準 API 價格為每百萬輸入詞元 2 美元、快取輸入詞元 0.10 美元、輸出詞元 10 美元。目前開放 ChatGPT Work 與 Codex 的指定訂閱者使用，尚未進入一般 Chat 介面。

通鑑判斷，快取輸入價格對會重複提供相同背景資料的 AI 代理尤其有參考價值；真正支出仍取決於輸入能否使用快取、每次輸出多長，以及任務是否需要重試。想試用的上班族也要先看自己使用的介面：已有訂閱資格，不等於能在一般 Chat 對話裡選到這個模型。

通鑑怎麼看

通鑑判斷，GPT-6.1 Sol 的看點是多項指定任務測試同時呈現能力與成本的變化，而非單一總分。它可能讓需要大量執行的程式與辦公流程更容易負擔；但測試結果仍須回到實際工作驗證，尤其要核算重試成本，並保留重要文件與操作的人工檢查。
