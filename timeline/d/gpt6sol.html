GPT-6 Sol 把模型選擇帶回能力與成本的取捨

OpenAI 推出 GPT-6 Sol 與 Luna，讓日常工作多了兩種能力與成本配置。

這是什麼

GPT-6 Sol 是 OpenAI 的人工智慧模型，與 Luna 一同推出。兩者都面向日常工作，但能力與成本的平衡不同；選哪個模型，取決於工作需要多少能力，以及願意付出多少成本。

三點帶走

  1. Sol 與 Luna 面向日常工作，選擇取決於任務需要的能力與成本。
  2. API 降價的比較基準是 GPT-5.6 促銷價格，不能套用到訂閱費。
  3. 使用範圍依服務與方案而異；Free、Go 的桌面試用公告只列出 Luna。

重點與分析

OpenAI 的發表頁摘要將 Sol 與 Luna 定位為兩款面向日常工作的模型，提供不同的能力與成本平衡。

通鑑判斷，這個定位比單看模型名稱更有用：一般工作未必每次都需要同一種能力。撰寫草稿、整理資料與處理較難的問題，可以依成果要求分別試用，再比較完成品質與花費。不過，摘要沒有提供足以判定兩款模型各自適合哪些任務的實例；不能只憑「Sol」或「Luna」替工作分級。

OpenAI 開發者社群的官方公告表示，Sol 與 Luna 的 API 價格，比 GPT-5.6 的促銷價格低官方宣稱的 50%。

通鑑判斷，這項降價對大量透過 API 處理重複工作的團隊較有參考價值，因為每次呼叫的價格會累積成持續支出。但比較基準是 GPT-5.6 的促銷價格，適用範圍是 API；不能把這個降幅當成所有訂閱方案的省款幅度。實際支出仍要看使用量，以及工作是否需要反覆修改或重做。

OpenAI 開發者社群的官方公告列出：Sol 與 Luna 已在 ChatGPT Work、Codex 和 API 提供；Plus、Pro、Business、Enterprise、Edu 使用者可在前兩項服務使用。

通鑑判斷，對已使用這些服務的人，最直接的變化是可以在原有工作流程中比較模型，不必先建立新流程。公告另外提到 Free 與 Go 使用者可在桌面應用程式試用 Luna，並未把 Sol 列入這項試用範圍。選用前應先確認自己使用的服務與方案，再以手邊的實際任務比較結果，避免把「已提供」理解成所有人都能在每個入口使用。

通鑑怎麼看

通鑑判斷，Sol 的關鍵是讓使用者多一個在能力與成本之間調整的選項。官方資料交代了定位、API 價格比較與提供範圍，卻不足以證明 Sol 在某種日常工作上一定比 Luna 合適。最實用的做法是拿相同任務比較成果、修改次數與成本，再決定是否固定使用。
