AWS 開源量子實驗室雲端佇列，讓原型量子裝置可以遠端共用

AWS 在 2023 年 3 月 7 日的部落格宣布，與費米實驗室發起的 QICK 開源控制平台社群合作，把實驗室裡的量子原型裝置接上雲端排隊系統。

這是什麼

QICK（量子儀器控制套件）是一套開源韌體，能把一塊 AMD Xilinx 的通用 FPGA 開發板變成控制量子裝置的平台。原本它只能讓在實驗室現場的人使用；AWS 開發的雲端佇列讓裝置擁有者能建立帳號、分配權限，讓世界各地的研究者遠端送出實驗並取回結果。

三點帶走

  1. AWS 2023 年 3 月 7 日開源 Cloud Queue for Quantum Devices，以 MIT 授權發布在 GitHub。
  2. 它讓使用 QICK 控制平台的實驗室，把原型量子裝置開放給遠端使用者排隊實驗。
  3. QICK 由費米實驗室、芝加哥大學與普林斯頓大學發起。

重點與分析

官方表示，QICK 由美國能源部費米國家加速器實驗室、芝加哥大學與普林斯頓大學合作發起，是開源韌體專案，可把 AMD Xilinx 通用原型開發板變成以 FPGA 驅動的量子裝置控制平台。

這段交代工具的來歷：QICK 由國家實驗室與大學發起，並獲橡樹嶺國家實驗室所在的量子科學中心支持。實驗物理學家打造新量子裝置時，控制用的微波、雷射等設備通常昂貴又需客製；用一塊通用 FPGA 板加開源韌體來取代部分設備，可以降低建置成本。AWS 這次做的是在這個基礎上加上「雲端連線」。

官方表示，AWS 量子團隊與 QICK 團隊合作打造雲端佇列，讓多位使用者遠端送出測試、把實驗結果上傳雲端分析，當月已在 GitHub 公開程式碼。

雲端佇列解決的是「共享」問題：一台原型裝置原本只能由實驗室成員排時間使用，加上佇列後，裝置擁有者可以建立使用者帳號、管理權限與工作排程，外部研究者透過網頁介面查看可用裝置、送出實驗、取回結果。對資源有限的實驗室來說，這是擴大合作的方式；對 AWS 來說，則是讓自家雲端服務進入量子實驗室的日常流程。

官方表示，目前 Amazon（AMZN） Braket 上所有的量子電腦都始於實驗物理學家的實驗室。

這句話說明 AWS 為什麼關心實驗室原型：今天能在雲端租用的商業量子電腦，都是從實驗室原型一路演進而來。把工具送進實驗室，等於提早接觸下一代可能出現的量子硬體。不過這個佇列服務本身與 Braket 是分開的，接上的是實驗室自己的裝置，並非把這些原型放上 Braket 對外販售。

官方表示，程式以 MIT 授權發布，AWS 邀請全球社群貢獻更多管理裝置、使用者與實驗的功能，也希望與 ARTIQ、QubiC、QIBO 等其他開源控制平台合作。

MIT 授權是相當寬鬆的開源授權，允許商業使用與修改，因此商業廠商也能拿去擴充，文章也明白歡迎廠商加入。這是第一個釋出版本，功能仍有限；量子科學中心主任 Travis Humble 稱此合作是 QICK 研究加速量子技術發展的例子。文章沒有提供目前有多少實驗室實際採用，後續需看 GitHub 社群活動。

通鑑怎麼看

通鑑認為，這則規模不大，但點出量子研究的一個實際瓶頸：原型硬體難以共享。把控制平台與雲端佇列都做成開源，是降低實驗室合作門檻的務實做法，成效要看有多少實驗室真的接上。
