Anthropic 與 AWS 深化合作：Trainium 底層 kernel 與 Neuron 軟體堆疊

這則公告同時涉及投資、雲端與模型服務，與晶片相關的內容是 Trainium 加速器的軟硬體共同開發。

這是什麼

Trainium 是 AWS 自研的 AI 訓練加速器（ASIC，專用晶片）。Annapurna Labs 是 AWS 的晶片設計團隊。本則只取公告中與晶片相關的部分。

三點帶走

  1. Amazon（AMZN） 追加 40 億美元，總投資 80 億美元。
  2. Anthropic 與 Annapurna Labs 共同開發未來世代 Trainium，並貢獻 Neuron 軟體堆疊。
  3. 公告未提供 Trainium 的效能或規模數字。

重點與分析

官方表示，新一輪包含 Amazon（AMZN） 追加 40 億美元投資，使 Amazon 對 Anthropic 的總投資達 80 億美元，維持少數股東身分，AWS 成為其主要雲端與訓練夥伴。

這是合作的商業背景：訓練夥伴的選擇意味著 Anthropic 的訓練算力將以 AWS 的自研晶片為重點。公告沒有說明 Trainium 在訓練運算中的占比或規模。

官方表示，Anthropic 與 AWS 的 Annapurna Labs 緊密合作開發與最佳化未來世代 Trainium 加速器，撰寫底層 kernel 直接介接 Trainium 矽晶片，並貢獻 AWS Neuron 軟體堆疊，工程師與晶片設計團隊密切合作以榨出最大運算效率。

公告描述的是模型公司的工程師直接寫底層 kernel、並貢獻 Neuron 軟體堆疊，也就是模型客戶實際參與晶片軟體的開發。公告沒有給出效能或價格比較，只用『強勁的性價比』形容。

官方表示，這種軟硬體緊密共同開發，加上 Trainium 平台的性價比與大規模擴展能力，使 Anthropic 能從矽晶片到整個堆疊最佳化模型訓練的每個環節。

『性價比』與『擴展能力』在公告中沒有數字，是定性描述。公告只說計畫用 Trainium 訓練最先進的基礎模型，沒有列出具體模型或時程。

通鑑怎麼看

通鑑認為，這則公告的晶片面向是模型公司與自研加速器廠商在軟體堆疊上的深度合作。投資金額是確定的數字，但 Trainium 的效能與採用規模沒有揭露。
