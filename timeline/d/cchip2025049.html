Oracle（ORCL） 啟用數千顆 Blackwell GPU，液冷 GB200 NVL72 機櫃上線

NVIDIA（NVDA） 在 4 月 28 日說明，Oracle（ORCL） 雲端基礎設施（OCI）已啟用首批 GB200 NVL72，並透過 NVIDIA DGX Cloud 提供。

這是什麼

GB200 NVL72 是把 36 顆 Grace CPU 與 72 顆 Blackwell GPU 放在同一個機櫃的液冷系統。這則是 NVIDIA（NVDA） 對雲端夥伴 Oracle（ORCL） 部署進度的說明。

三點帶走

  1. Oracle（ORCL） 已啟用首批液冷 GB200 NVL72 機櫃，數千顆 Blackwell GPU 可用。
  2. OCI Superclusters 計畫擴展到超過 100,000 顆 Blackwell GPU。
  3. 原文未說明液冷細節與時程。

重點與分析

官方表示，Oracle（ORCL） 已架設並調校第一批液冷 NVIDIA（NVDA） GB200 NVL72 機櫃，數千顆 Blackwell GPU 已部署在 NVIDIA DGX Cloud 與 Oracle Cloud Infrastructure 上，供客戶開發與執行推理模型和 AI 代理。

原文只用『數千顆』描述規模，沒有確切數量或所在地區。這則在本分頁的相關性在於它明確指出機櫃是液冷設計，但稿中沒有說明液冷方式（冷板、冷卻液分配單元等）或機房功率。

官方表示，GB200 NVL72 是結合 36 顆 Grace CPU 與 72 顆 Blackwell GPU 的機櫃級系統；OCI 的部署搭配 Quantum-2 InfiniBand 與 Spectrum-X 乙太網路，OCI Superclusters 計畫擴展到超過 100,000 顆 Blackwell GPU。

『超過十萬顆』是計畫中的擴展目標，原文沒有給時程。同一份稿件中，NVIDIA（NVDA） 說自己也會用這批機櫃進行推理模型訓練、自駕車開發及加速晶片設計與製造，屬於官方說明用途，沒有進一步成果。

官方表示，OCI 以公有雲、政府雲、主權雲，以及透過 OCI Dedicated Region 與 OCI Alloy 的客戶自有資料中心提供 Blackwell；已有大型科技公司、企業、政府機構與承包商、區域雲端業者計畫立即部署工作負載。

這段說明的是交付形態：同一套機櫃可放在 Oracle（ORCL） 的機房，也可放進客戶自己的資料中心。對需要資料留在境內的客戶，這是賣點，但稿中沒有點名任何客戶，也沒有說明哪些交付形態今天已可使用，只有最後一句明確指出機櫃在 DGX Cloud 與 OCI 已上線可用。

通鑑怎麼看

通鑑認為，這則是一份簡短的部署公告，可核對的事實是『首批液冷機櫃已上線』與『計畫擴展至十萬顆以上』，後者缺少時程。
