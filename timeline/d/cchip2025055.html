Arm（ARM）：小米 XRING O1 以 Armv9.2 核心與 3 奈米製程打造

Arm（ARM） 在 5 月 26 日的新聞室部落格說明小米自研 SoC 的 IP 組成與首批搭載裝置。

這是什麼

SoC（系統單晶片）把 CPU、GPU 與互連等功能放在同一顆晶片上。Arm（ARM） 授權處理器與 GPU 的設計藍圖（IP），小米的晶片部門 XRING 以此為基礎自行完成後端與系統設計。

三點帶走

  1. XRING O1 使用 Armv9.2 Cortex、Immortalis GPU 與 CoreLink 互連 IP。
  2. IP 針對 3 奈米製程最佳化。
  3. 首批裝置為小米 15S Pro 與小米 Pad 7 Ultra。

重點與分析

官方表示，XRING O1 採用最新的 Armv9.2 Cortex CPU 叢集 IP、Arm（ARM） Immortalis GPU IP 與 CoreLink 互連系統 IP，這些標準 IP 針對先進的 3 奈米製程最佳化。

稿中沒有寫明晶圓代工廠、核心數量、頻率或電晶體數，所以「3 奈米」是 Arm（ARM） IP 的最佳化目標，原文沒有交代實際製造方。這是 Arm 的角度：強調自家 IP 被用在新晶片上，不是小米的完整規格發表。

官方表示，XRING 團隊在後端與系統層級設計表現「很出色」，使 O1 達到良好的效能與能效；晶片面向高階手機與平板。

後端設計指的是把電路實際擺放與繞線，會直接影響頻率與功耗。這句評價出自 Arm（ARM） 作者，沒有附跑分、功耗或電池續航數字，所以屬於形容。對外部讀者而言，可核對的是它屬於高階機型使用。

官方表示，XRING O1 將首度出現在小米 15S Pro 智慧型手機與小米 Pad 7 Ultra 平板，Arm（ARM） 與小米自 2011 年第一代小米手機起即為合作夥伴。

這證實了兩款首批裝置，是稿中最明確的產品資訊。Arm（ARM） 同時強調雙方 15 年關係，意在說明小米改走自研晶片後仍使用 Arm 架構，授權關係延續，這也說明 Arm 架構在手機晶片自研潮中仍是主要選擇。
