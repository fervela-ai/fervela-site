OpenAI 押注 Astra 能接下模糊的大工作

OpenAI 以開發者影片介紹 GPT-6 Astra，重點放在電腦操作、創作輸出，以及做到一半還能改方向的長任務。

這是什麼

GPT-6 Astra 是 OpenAI 的新一代模型，定位是能操作電腦、寫程式，並接下定義還模糊的工作。它被當成一位資深協作者來賣，重點是少逐步交代、多交給它收尾。

三點帶走

  1. 看畫面、在背景操作既有軟體，人才同時做別的事；填表與手機測試比畫風示範更接近工作，金鑰這類輸入要自己再核對。
  2. 長任務可以做到一半改方向，已啟動的工具不必整段重來；改完仍要核對結果是否對得上新要求。
  3. 簡報與文章更好讀、更好改，目前只見成功樣本，要用自己的稿子試改再判斷。最好與第一次就好，是講者的評價，不能直接當成成績。

重點與分析

講者表示，Astra 看截圖就能操作應用程式，應用程式留在背景，人可同時做別的事。示範是拍照交給 Codex，用 Krita 畫成梵谷風格，並在背景加上金門大橋；也能填寫 API 金鑰表格、做手機應用程式的品質測試，而且比講者又快又好。

對上班族，這段的重點在模型盯著畫面、於背景把既有軟體用完。梵谷畫風是效果展示，填表與手機品質測試才更接近日常；影片沒有出示填錯欄位、跳出登入或權限不足時會怎樣。講者說比自己又快又好，比的是一個人、一場準備過的示範，還不能當成辦公室的穩定成績。金鑰表格尤其敏感：模型看得到畫面又代為輸入，方便和出錯的代價綁在一起，官方沒有說明如何事後核對。示範走的是 Krita 這類已安裝的繪圖軟體，和在對話框裡直接生圖是不同的工作方式。

講者說明，Responses API 新增非同步工具呼叫與轉向。工具還在跑時，模型可以先做任務的其他部分，結果回來再接上。途中若改變要求，已啟動的工具不必取消、也不必整段重做，完成後的結果會納入新的脈絡。

長任務的成本常常落在做到一半改規格。寄信前換收件人、報表做到中段改口徑、查資料時又補限制，都是辦公室常態。講者這次強調工具繼續跑、人可以中途改口，結果再併進新方向，等於把改需求從整段作廢變成流程的一部分。判斷上，這比再加一個最聰明的頭銜，更接近真實交辦。官方只講機制，沒有一個完整長任務的實例，也沒說明方向一改再改時，前後指示衝突要採哪一次。少返工是否成立，要看改口之後的結果對不對得起來。對台灣常見的跨部門改稿，這比多一個聰明形容詞有用，前提是新舊指示要能一起看懂。

講者表示，創意與知識工作的產出明顯好過先前模型，更注意細節，也更懂使用者的提示。三維模型被特別點名，曾渲染花園、船廠、動物、城市景觀，甚至戴森球。簡報和文章更好讀、更好改，來回給回饋時，回應的個性也更自然。

對非工程師，簡報和文章才是每天會用到的部分；三維場景則用來證明細節變多這件事有畫面可看。花園、船廠、城市能被渲染出來，代表模型處理得了空間、物件和風格。這些例子全是講者展示的成功樣本，沒有對照前一代的同一題目，也沒有失敗案例。更好讀、更好改、來回時更自然，對上班族很要緊，因為文件的時間多半花在修改。官方沒有給出改了幾輪、省下多少時間。個性更自然同樣是感受，適合先拿一份真實簡報試改，再決定定稿要不要交給它。戴森球這種題目用來展示想像力的上限，日常簡報用不到那麼誇，卻能看出它肯處理複雜畫面。

通鑑怎麼看

官方宣稱 Astra 是迄今最聰明、也最對齊的一代，電腦操作、程式、資安與科學都屬高水平。對齊是指更照著人的目標走。開發者影片實際演的是背景操作軟體與長任務中途改方向，三維與簡報、文章只是講者口述。資安和科學沒有演示，先只記成清單。講者說的最好、第一次就好，沒有對照可核。它已可在 ChatGPT、Codex，以及供開發者呼叫的 API 使用。上班族宜拿下一份真要交的文件試，看自己改幾輪。
