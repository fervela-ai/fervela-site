英國追加 1.7 億英鎊推進 Sizewell C，加快開工前準備

在 Great British Nuclear 啟動後一週，英國政府宣布加快 Sizewell C 核電廠的開工前準備。

這是什麼

Sizewell C 是規劃在英格蘭 Suffolk 興建的大型核電廠，設計與正在興建的 Hinkley Point C 相同。目前仍處在最終投資決定之前的開發階段，政府先出資讓場址整備、供應鏈採購等工作提前進行。

三點帶走

  1. 英國 2023 年 7 月 24 日確認再投入 1.7 億英鎊（屬已編列資金）推進 Sizewell C。
  2. 電廠規劃 2 部反應爐、3.2GW，約占英國電力需求 7%。
  3. 政府希望以 RAB 模式與綠色分類吸引民間投資。

重點與分析

官方表示，部長確認再投入 1.7 億英鎊先前已編列的資金，用於準備 Sizewell C 場址、向供應鏈採購關鍵組件並擴充人力。

「先前已編列」是理解這筆錢的關鍵：它不是新增預算，而是動用 2022 年 11 月設立的 7 億英鎊投資計畫。新聞稿最後也說明，這筆撥款在補貼管制規則下屬於對既有計畫的修改。所以這則新聞的實質是「提早花錢、加速準備」，而不是政府加碼。

官方表示，Sizewell C 與 Hinkley Point C 一樣由 2 部反應爐組成，總發電 3.2GW，相當於英國電力需求的 7%，可在 60 年間為相當於 600 萬戶住家供電。

和同時期推動的小型模組化反應爐相比，Sizewell C 是傳統大型核電路線。官方用「600 萬戶、60 年」說明規模，並稱每年可減少多達 900 萬噸二氧化碳排放。這些是政府估計，原文沒有說明計算假設，例如替代的是哪一種發電來源。

官方表示，施工高峰期 Sizewell C 將支持全國 1 萬個工作機會，供應鏈計畫讓 70% 的建設合約價值流向英國企業。

70% 是供應鏈「計畫」比例，屬於目標值。大型核電工程的本土採購比例常被用來爭取地方與國會支持。原文沒有提到總建設成本與工期，這兩項正是大型核電最受質疑的地方，但新聞稿沒有談到。官方另說 Sizewell C 是 Hinkley Point C 與 2050 年核電目標之間的橋樑，等於把它定位為維持大型核電施工團隊與供應鏈不中斷的專案。

官方表示，這些措施也有助吸引民間投資新核電，搭配政府引進的 RAB 模式，以及在徵詢意見的前提下把核電納入英國綠色分類標準。

RAB（受管制資產基礎）模式是讓用電戶在建設期間就開始分攤部分成本，以降低投資人的資金成本，這是英國為大型核電設計的融資方式。把核電納入綠色分類（taxonomy）則可能讓更多以永續為目標的資金投入。兩者都是為了讓 Sizewell C 能走到最終投資決定，而原文沒有給出最終投資決定的時間。

通鑑怎麼看

通鑑認為，這則新聞是政府先動用既有資金替 Sizewell C 鋪路，而非新增承諾；電廠能否開工仍取決於最終投資決定與民間資金，成本與工期才是真正的未知數。
