Snap OS v5.58：Spectacles 新增相機資料、雲端多模態 LLM 與影像立體化 API｜Snap Inc.｜11 月 15 日 事件進階

Snap OS v5.58 讓 Spectacles 開發者能用相機資料與雲端 LLM

Snap 發布 Spectacles 的系統更新，開放相機資料與雲端多模態 LLM，並用兩款示範 Lens 展示相機加機器學習的做法。

這是什麼

Snap OS 是 Spectacles AR 眼鏡的作業系統。這次更新主要面向開發者：提供可以拿到眼鏡相機畫面和呼叫雲端 AI 模型的介面，讓 Lens 能辨識真實物體並做出反應。

三點帶走

  1. 官方表示 Snap OS v5.58 開放相機資料 API 與雲端多模態 LLM 的 Fetch API。
  2. Image Spatialization API 以生成式 AI 把 2D 影像轉成 3D，並新增空間錨點、基本定位等功能。
  3. 原文未說明隱私保護機制、辨識準確度與延遲。

重點與分析

官方表示，Piano Tutor Lens 以 SnapML 自訂模型辨識並追蹤各種鋼琴，即時把音符疊在琴鍵上；另一個機器學習模型判斷彈奏好壞並給出即時回饋。

這是用相機加機器學習做 AR 教學的示範：Lens 不是預先對好位置，而是辨識真實鋼琴在哪裡，再把音符疊在對應琴鍵。原文把重點放在「自訂 ML 模型」，意味著開發者可以用 SnapML 訓練並放進 Lens。原文沒有給出辨識準確度、支援的鋼琴型號數或延遲，所以實際體驗無法從新聞稿判斷。

官方表示，Ball Game Lens 把實體球變成控制器，用自訂 ML 追蹤模型追蹤球的移動，讓人同時與實體與數位元素互動並練習踢球挑戰。

與 Piano Tutor 一樣，核心是辨識實體物件，但這個例子的物件會動，所以展示的是即時追蹤的能力。兩個示範都集中在『相機看見東西』這件事，呼應文章開頭的立場：官方認為相機存取才能發揮 AR 的完整潛力。原文沒有說明這兩個 Lens 的追蹤幀率或需要的光線條件。

官方表示，新增的 Fetch API 加上延伸權限的開發者設定，讓 Lens 可直接連接雲端託管的多模態 LLM；另有 Image Spatialization API 用生成式 AI 把常見 2D 影像格式轉成 3D。

這是這次更新最重要的兩項：一是讓眼鏡上的 Lens 能把相機畫面送到雲端 AI 模型，二是用生成式 AI 把平面照片變成有深度的 3D 效果。原文用「延伸權限的開發者設定」指出這些功能需要額外授權，沒有說明具體的隱私保護機制或資料如何處理，這是使用相機與雲端模型時最需要追問的問題。

官方表示，更新還包括空間錨點（把數位物件固定在特定位置並可再回來）、基本定位（取得 GPS 座標）、版面模式（從手機匯入圖片並立體化）、網頁檢視（把網頁嵌入 Lens）與 Lens 解鎖（用網址分享尚未上架的 Lens）。

這五項屬於補強開發彈性的基礎能力：錨點讓內容可以持續存在於同一地點，GPS 讓戶外體驗更真實，Lens Unlock 則方便開發者在 Lens 還沒歸類或進入 Lens Explorer 前，用網址給別人測試。與前三項相比，這些項目的描述較簡短，原文也沒有說明錨點的精度或 GPS 的更新頻率。

通鑑怎麼看

通鑑認為，這次更新代表 Spectacles 的開發重心轉向「相機加 AI」。但雲端 LLM 與相機資料的隱私處理，原文沒有交代，是使用者與開發者都該追問的部分。
