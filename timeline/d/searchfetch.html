DeepSeek 開放搜尋 API，讓 AI 應用能查網頁、讀內容

DeepSeek 在 API 文件中宣布開放 Search & Fetch，讓開發者能把網路搜尋與網頁內容擷取接進自己的應用。

這是什麼

Search & Fetch 是 DeepSeek 自家搜尋引擎的 API。它提供搜尋網頁和擷取內容的能力，讓使用這套 API 的產品能取得網路資料，再決定如何呈現或處理。

三點帶走

  1. Search & Fetch 已開放 API，提供網路搜尋與網頁內容擷取。
  2. 官方宣稱的請求量與索引規模，不能直接證明搜尋結果準確。
  3. 官方表示會過濾低品質內容；重要資訊仍應核對原始網頁。

重點與分析

DeepSeek 開放 Search & Fetch API，支援網路搜尋與擷取網頁內容；官方表示，服務由自家搜尋引擎提供。

通鑑判斷，這項發布的關鍵是開發者能在自己的產品中呼叫搜尋服務。搜尋回答「有哪些相關網頁」，擷取則讓產品取得網頁內容，兩者接在一起，才有機會讓 AI 根據找到的資料繼續處理問題。對上班族來說，日後可能在工作工具裡遇到這種功能；但這份公告只確認 API 已開放，沒有展示具體工作流程或使用成果。

官方宣稱，搜尋引擎每天處理數億次來自全球的搜尋請求，索引數千億個網頁。

通鑑判斷，這兩個數字分別說明服務的使用量與收錄範圍，不能直接當成搜尋品質的證明。索引規模大，仍可能找不到某篇需要的文章；請求量高，也無法告訴讀者結果是否準確。若要評估它能否協助查政策、競品或市場消息，值得觀察的是實際查詢時能否找到相關來源，以及擷取後的內容是否完整。

官方表示，搜尋引擎支援多語言搜尋，並宣稱結果具相關性、權威性與時效性。

通鑑判斷，多語言支援對需要同時查中文與外文資料的工作有潛在價值，例如整理不同市場的公開資訊。不過，支援多語言沒有說明各語言的搜尋表現是否相同；相關性、權威性與時效性也是官方對自家結果的評價。這段官方文字沒有提供按語言區分的測試結果，因此不能據此推定繁體中文查詢的效果。

官方表示，搜尋引擎會過濾 SEO 垃圾內容、GEO 操縱手法，以及低品質 AI 生成內容。

通鑑判斷，過濾這些內容切中使用搜尋資料時的一個難題：排在前面的頁面未必值得相信。如果產品再把搜尋結果交給 AI 整理，來源選錯可能連帶影響最後的回答。不過，這段官方文字沒有列出過濾的測試方法、誤擋情況或實際案例。現階段較穩妥的做法，是把過濾能力視為官方宣稱，重要資料仍回到原始網頁核對。

通鑑怎麼看

通鑑判斷，Search & Fetch 讓 DeepSeek 的搜尋能力延伸為開發者可以直接呼叫的搜尋與擷取 API。它是否好用，不能只看官方宣稱的索引規模或過濾能力；更值得觀察的是搜尋結果能否附上可核對的來源、擷取內容是否完整，以及繁體中文查詢的表現。對使用這類工具整理工作資料的人，來源仍是查證的起點。
