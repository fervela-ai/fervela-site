Anthropic 不廣釋新模型，先讓防禦方起跑

Anthropic 以 Project Glasswing 宣布，Claude Mythos Preview 不對一般人開放，先提供給維護關鍵軟體的組織。

這是什麼

Project Glasswing 是 Anthropic 的計畫，用 Claude Mythos Preview 幫全球關鍵軟體找漏洞、加快修補，並讓防禦方先用上這類能力。

三點帶走

  1. 寫程式變強會連帶帶來找漏洞的能力，不廣釋是在決定誰先用，不是單純延後上市。
  2. 講者提到的當機舊錯與權限提升都已修補，該看的是發現速度。
  3. 官方宣稱的一億美元是使用額度，先給守關鍵軟體的人；講者說工期以數月到數年計。

重點與分析

講者表示，掃描後幾乎每個主要平台都有漏洞，過去幾週找到的錯誤多過他其餘人生的總和。OpenBSD 一個存在二十七年的錯誤，送出少許資料就讓伺服器當機；Linux 則讓無權限使用者執行程式後升為管理員。兩處都已通知維護者並部署修補。

這兩則比模型名稱更接近日常。很多人依賴的網路服務背後就是這類系統，少許資料就能讓伺服器當機。Linux 那則更直接，無權限的人可以變成管理員。講者說幾週內的發現多過其餘人生，這是個人比較，不是產業普查。能核對的是通知與修補都已完成。講者說的二十七年舊錯，幾週內就被掃出，只靠人力可能不夠。

講者表示，Claude Mythos Preview 不是專為資安而訓練，資安能力是練寫程式後的副作用。辨識錯誤已近專業水準，能把三到五個影響有限的漏洞串成精密利用，並能自主推進研究員一整天的任務。能力若落入不當人手可能傷人，因此不廣釋。

重點不在資安產品的包裝。講者的說法是，模型為了寫程式而變強，找漏洞是連帶出現的能力。一般人更該看串接：單獨小錯往往做不了什麼，三到五個排起來就可能變成一次入侵，而且它能自己把任務做到一整天。這解釋不廣釋：能力先外流，攻擊方不必自養團隊。不過接近專業水準是講者判斷，官方沒有獨立成績。不廣釋只是暫緩；先交給誰，才決定空窗對誰有利。

官方宣稱，Anthropic 承諾最高一億美元使用額度，另捐四百萬美元給開源安全組織。模型每百萬輸入詞元二十五美元、輸出一百二十五美元。除啟動夥伴外，另有超過四十個維護關鍵軟體的組織取得使用權。

官方宣稱的一億美元是額度、四百萬美元是捐贈，錢主要在模型上，不是現金。以上述標價計，輸出是輸入的五倍，自動修補會花在輸出。夥伴含雲端、設備、資安、銀行與開源，如 Apple、Google、Microsoft、NVIDIA、JPMorganChase 與 Linux Foundation。這些名字涵蓋日常服務與金融體系，不是實驗室自用。官方宣稱已開放超過四十個組織，不是十二家就結束。

官方宣稱，有合作方過去幾週找出上一代沒看到的複雜漏洞；也有合作方指稱，發現到被利用可從數月縮成數分鐘。開源程式被指占現代系統絕大多數，維護者長期自己顧安全。講者表示，這是數月甚至數年的工作，沒有單一組織做得完。

一般公司修補多半照舊時鐘：等通知、排窗、測試再上線。若數月被壓成數分鐘，流程還沒跑完，攻擊可能已發生。企業更該看開源：大塊程式不是自己寫的，維護者常無大型資安團隊，工具若只給付得起的公司，缺口會在共用底層。時間縮短與幾週內的新發現都是參與者自述。講者定的工期跨數月到數年，這次不是完成式；官方只寫與美國官員談過，沒有政府已加入。

通鑑怎麼看

這不是給一般人申請的新服務，而是發放順序的決定。模型因寫程式變強，Anthropic 選擇不廣釋，把額度與早期權限交給守關鍵軟體的組織。上班族不會在自己的帳號裡看到它，而會在公司已用的系統裡感到修補變快，或攻擊窗口變短。官方宣稱的一億美元是額度，不是保證修好。數分鐘與幾週產量仍是夥伴的說法。能站住的是誰先拿到模型。工期被說成數月到數年，這次是起跑，不是安全已經完成。
