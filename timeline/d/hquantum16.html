Windows 11 預覽更新 KB5067036 加入 ML-KEM 與 ML-DSA 的 API 支援

Microsoft（MSFT） 在 2025 年 10 月 28 日的 Windows 11 非安全性預覽更新 KB5067036 中，加入符合 NIST FIPS 203、204 的後量子演算法 API。

這是什麼

ML-KEM（用於建立共用密鑰）與 ML-DSA（用於數位簽章）是 NIST 標準化的後量子演算法。這次更新建立在 Microsoft（MSFT） 的密碼函式庫 SymCrypt 上，讓開發者能透過 Windows 的密碼 API（CNG，Cryptography: Next Generation）與 .NET 呼叫它們。這則更新說明的主角其實是開始功能表等多項改動，後量子只是其中一條。

三點帶走

  1. Windows 11 預覽更新 KB5067036 加入 ML-KEM 與 ML-DSA 的 API。
  2. 開發者可用 CNG 與 .NET 使用，涵蓋金鑰交換、簽章與解密。
  3. 頁面後續更新紀錄顯示此功能歸屬在 11 月曾更正。

重點與分析

官方表示，這次更新建立在 SymCrypt 的後量子演算法上，為 NIST 的 ML-KEM 與 ML-DSA 提供 API 支援，依 FIPS 203 與 FIPS 204 標準。

這裡的重點是它是「API 支援」，也就是給開發者的元件，不是說 Windows 的所有連線已自動改用後量子演算法。更新說明沒有提到哪些系統功能（例如 TLS）預設啟用，因此讀者不應從這一條推論作業系統層級的預設行為已改變。

官方表示，這些演算法可用於金鑰交換、簽章與解密，並可透過 CNG 與 .NET 使用。

原文用的是「key exchange, signing, and decryption」。以白話說，ML-KEM 對應金鑰交換相關用途，ML-DSA 對應簽章；至於「解密」一詞如何對應到 KEM 的封裝與解封裝，更新說明沒有展開。程式要用到時，仍需依 CNG 與 .NET 的文件操作。

官方表示，此更新的組建編號為 26200.7019 與 26100.7019，屬於 2025 年 10 月的非安全性預覽更新（KB5067036）。

這是預覽版（Preview），通常是下一次每月安全更新前的測試性更新。頁面後續的更新紀錄顯示，2025 年 11 月 3 日出現更正，11 月 5 日又註明後量子密碼這項新功能「包含在 10 月非安全性更新（KB5067036）中」，表示該頁面在發布後曾調整功能歸屬；讀者應以最新版頁面為準。

官方表示，同一次更新的亮點還包括重新設計的開始功能表、電池圖示色彩提示、Microsoft（MSFT） 365 Copilot 頁面等。

把這些列出來，是為了提醒後量子 API 只是這份更新說明中的一行，而非這次更新的主題。對一般使用者而言，最顯眼的是開始功能表（新增可捲動的「全部」區，以及分類與格狀兩種檢視）與工作列的改變；後量子 API 則主要影響要寫密碼相關程式的開發者。同一份說明還提到，開始功能表的手機連結按鈕支援 Android 與 iOS 裝置，並預定在 2025 年內推向歐洲經濟區。
