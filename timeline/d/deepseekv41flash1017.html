DeepSeek-V4.1-Flash-1017｜DeepSeek｜10 月 17 日 模型進階

DeepSeek 小幅更新，值得看的是代理任務能否更省時

DeepSeek 發表模型更新，將推理、程式與視覺能力的提升，連同任務時間和成本，放在同一張成績單上。

這是什麼

DeepSeek-V4.1-Flash-1017 是 V4.1-Flash 的小幅更新。官方表示，新版改善推理、程式、AI 代理任務與視覺測試表現，並縮短任務執行時間及輸出長度。

三點帶走

  1. 程式與視覺測試都有進步，但分數受測試條件影響。
  2. 官方表示任務更快、成本更低；具體可省多少仍要實測。
  3. 網頁版與 App 已更新，API 用法與價格維持不變。

重點與分析

官方宣稱：在使用 Claude Code 測試框架的 Terminal-Bench 4.0 中，新版得分 42.3，前版為 31.2；在使用 Mini-SWE-V2 測試框架的 DeepSWE v1.1 中，新版為 77.0，前版為 74.2。

通鑑判斷：兩項程式任務測試都進步，但幅度不同，讀成全面大幅升級會失準。測試使用指定的操作框架，分數反映模型在那些條件下完成任務的能力，不能直接換算成辦公室導入後能省多少人力。若團隊正用 AI 處理程式工作，較有用的下一步是拿自己的任務比較完成率、人工修改量與花費。

官方宣稱：在搭配工具的 Chartography 測試中，新版得分 83.0，前版為 78.9；搭配工具的 BabyVision 測試則為 92.5，前版為 89.6。

通鑑判斷：視覺測試的進步，讓這次更新值得從純文字工作以外觀察。不過，這些分數都有搭配工具的條件，不能把成績直接理解成模型單獨閱讀任何圖片、圖表都同樣可靠。若要用於報表或圖片判讀，仍應以實際檔案試做，檢查它是否看對數字、標籤與關係，再決定哪些步驟可以交給它。

官方表示，新版縮短任務執行時間與輸出長度，讓使用者能更快、以更低成本完成任務；官方文字說明沒有提供這兩項改善的具體幅度。

通鑑判斷：對反覆執行多步驟工作的團隊，時間與輸出長度可能比單一測試分數更影響使用體驗及費用。但目前無法從官方文字算出每件工作可省多少錢，也無法判斷縮短輸出後，答案是否仍保有需要的細節。評估時應把任務完成率、耗時、輸出品質與實際帳單放在一起看。

官方表示，模型權重以 MIT 授權公開，上下文長度為 100 萬詞元；官方網頁版與 App 已換成新版，API 呼叫方式與價格不變。

通鑑判斷：已在使用網頁版或 App 的人，可以直接留意常做的工作有無變化；使用 API 的團隊，則能在原有呼叫方式與價格下比較新舊結果。公開權重也提供自行部署的選項，但超長上下文是模型規格，不能保證長文件裡每處細節都能準確找出。正式採用前，仍需用自己的文件和流程驗證。

通鑑怎麼看

通鑑判斷：這次更新最值得追蹤的，不是某個最高分，而是模型能否在完成同一件事時減少等待、輸出與費用。官方列出的多項測試顯示新版有所進步，改善幅度卻因任務而異。對一般上班族，先用熟悉的工作比較結果，比只看排行榜更能判斷是否有感。
