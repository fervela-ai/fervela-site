VLMaps：把視覺語言模型「貼」到 3D 地圖上，機器人能聽懂「沙發和電視中間」

Google（GOOGL） 研究部落格 3 月 23 日介紹 VLMaps，一種讓機器人把語言理解與空間地圖結合的方法，論文將在 ICRA 2023 發表。

這是什麼

VLMaps 是一種地圖表示法：機器人邊走邊把每個像素的視覺語言特徵存進與 3D 地圖對齊的大型張量，之後就能用文字查詢「書架上的書在哪」，再把座標交給導航或程式產生模組使用。

三點帶走

  1. VLMaps 把視覺語言特徵融合進 3D 地圖
  2. 零樣本導航最多比基線高 17%，空間目標最多高 29%
  3. 同一地圖可為不同機器人產生不同障礙地圖

重點與分析

官方表示，VLMaps 把預訓練視覺語言特徵直接融合進環境的 3D 重建，不需要額外標註資料或模型微調，就能讓機器人用自然語言索引地標。

不需要額外標註與微調，是這個方法容易被採用的原因：機器人只要有攝影機畫面與位置資訊，就能借用網路規模資料訓練出的視覺語言模型。官方也點出研究動機：視覺語言模型很強，但如何把它們接到機器人可用的空間表示上，仍是開放問題。VLMaps 的答案是把語意直接存進幾何地圖，而不是另外維護一份物件清單。

官方表示，VLMaps 可搭配 Code as Policies，處理「走到沙發和電視中間」「往椅子右邊三公尺」這類空間目標；長時程空間目標導航最多提升 29%。

Code as Policies 是讓語言模型寫程式來控制機器人的方法。VLMaps 回傳地標座標後，程式模型就能把『中間』解讀成兩點座標的算術。這把『語言理解』和『幾何計算』分工：語言模型負責理解指令結構，地圖負責提供精確位置。這種組合比純粹端到端的模型更容易除錯，但也代表任一環節出錯都會影響最終結果。

官方表示，VLMaps 在 Habitat 與 Matterport3D 的零樣本物體目標與空間目標導航任務中，比 CoW、LM-Nav 等基線高出最多 17%。

零樣本（zero-shot，不針對該任務額外訓練）是重點，說明方法的泛化能力。不過這些評估都在模擬環境中完成；部落格提到在模擬與真實環境都做了實驗，但真實機器人的量化成績沒有在文中列出。17% 與 29% 都是『最多』，不是全部任務的平均提升。

官方表示，同一份 VLMap 可為不同型態的機器人產生各自的障礙地圖，例如桌子對大型移動機器人是障礙、對無人機卻可飛越，此做法讓導航效率最多提升 4%。

這展示了開放詞彙（open-vocabulary，可用任意文字描述類別，而非預先固定的類別清單）地圖的實用面：只要列出各機器人能或不能通過的物體類別，就能從同一份地圖產生不同的路徑規劃依據。官方也坦言目前的方法主要針對靜態環境，處理有人走動的動態環境是未來工作；程式碼與互動式模擬示範已公開。

通鑑怎麼看

通鑑認為 VLMaps 示範了一條務實路線：讓大型視覺語言模型提供語意，讓傳統 3D 地圖提供幾何，兩者結合解決機器人導航。成績多來自模擬，真實場景與動態環境仍需驗證。
