Siemens 擴充 Simatic AX，加入動作控制工程工具

Siemens 發表 Simatic AX Motion Control Engineering，讓工程師能在同一個文字式環境中處理 PLC 邏輯與動作控制。Simatic AX Logic Control Engineering 也已在全球正式供應。

這是什麼

新工具讓工程師以文件式方式設定動作控制所需的技術物件，支援 PLCopen，並直接整合 Git 進行版本控管。兩項工具均可透過 Siemens Digital Exchange 取得。

三點帶走

  1. Siemens 的 Simatic AX 現在涵蓋動作控制工程，並讓相關工作與 PLC 邏輯共用文字式環境。
  2. Git 整合與 PLCopen 支援，可能有助於團隊沿用熟悉的開發流程。
  3. 這項消息主要與工業自動化工程人員有關。

重點與分析

Simatic AX Motion Control Engineering 讓工程師在處理 PLC 邏輯的同一個文字式環境中管理動作控制工作，無須切換至另一套工程工具。

對同時開發機器控制邏輯與動作功能的團隊而言，這可能減少切換工具的工作；實際效益仍取決於團隊原有流程。

工程師可用文件式方式設定技術物件；工具支援 PLCopen，並直接整合 Git 進行版本控管。

值得看的是，熟悉軟體開發流程的工程師，可能較容易把動作控制工作納入既有的版本管理方式。

Simatic AX Logic Control Engineering 已在全球正式供應，可用文字程式碼、命令列介面與腳本為 Simatic S7 PLC 編寫程式。

這可能讓偏好文字與命令列工具的團隊有更多選擇，是否適合仍取決於其設備及開發習慣。

通鑑怎麼看

這次擴充的重點，是讓動作控制與 PLC 邏輯工作進入同一個開發環境。它對工廠自動化工程團隊可能有直接意義，對一般讀者的影響則較間接。
