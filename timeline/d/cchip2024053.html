Arm（ARM） CSS for Client：把 3 奈米實作一起賣給晶片廠

Arm（ARM） 不只提供 CPU 與 GPU 的設計，也把可直接量產的 3 奈米實體實作一併提供。

這是什麼

CSS（運算子系統）是 Arm（ARM） 把多個 CPU、GPU 與互連電路預先整合並驗證的方案，讓手機與 PC 晶片廠縮短開發時間。這次是客戶端（手機、PC）版本，首度提供 3 奈米的實體實作。

三點帶走

  1. Arm（ARM） CSS for Client 首度提供 3 奈米實體實作。
  2. Cortex-X925 單執行緒效能提升 36%，Immortalis-G925 圖形效能提升 37%。
  3. 所有數字是 Arm（ARM） 在參考平台上的比較，需待量產晶片驗證。

重點與分析

官方表示，CSS for Client 含可直接量產的 3 奈米實體實作。

Arm（ARM） 過去多半只授權設計，這次把實體實作也納入，等於替晶片廠做掉一部分後段工作，縮短上市時間。原文強調這是 Arm 首次在 3 奈米提供實體實作，但沒有說明與哪家代工廠配合。

官方表示，Cortex-X925 單執行緒效能提升 36%。

這個數字有三個前提：3 奈米、假設 3.8GHz 時脈與最大快取，實際手機未必採用。官方的比較對象是 2023 年旗艦 4 奈米手機晶片，所以 36% 同時包含製程進步的貢獻，不全是微架構改進。換句話說，讀者看到的 36% 是『製程加架構』的合計，而非單看 Cortex-X925 設計本身的功勞，評估時要避免把它全算在微架構上。

官方表示，Cortex-A725 效能效率提升 35%，Immortalis-G925 圖形效能提升 37%。

G925 是旗艦手機用的 GPU，原文也提到 Mali-G725 與 Mali-G625 屬同一系列、針對中階市場。官方另稱 G925 在多種 AI 與 ML 網路上快 34%。這些都是 Arm（ARM） 在參考平台上對上一代的比較，不是特定手機的實測。

官方表示，平台對 Android 工作負載的運算與圖形效能提升超過 30%，AI 推論快 59%。

59% 是平台層級的 AI 推論加速，與 X925 的 36%、G925 的 34% 不是同一個基準，彼此不能相加或平均。原文也沒有說明 59% 來自哪些模型，因此只能當作 Arm（ARM） 的整體說法。三個百分比各自對應不同的比較基準，閱讀時最好分開記錄，才不會誤以為整體平台有 36%、37% 與 59% 的累積效果。

官方表示，推出 KleidiAI 與 KleidiCV 軟體函式庫。

KleidiAI 針對 AI 工作負載、KleidiCV 針對電腦視覺，整合熱門 AI 框架並利用 NEON、SVE2 與 SME2 等加速技術。對開發者而言，是否不改程式就吃到這些加速才是實際價值，這點要待日後使用回饋驗證。

通鑑怎麼看

通鑑認為，這次發表的新意是 Arm（ARM） 往下游走一步，連 3 奈米實體實作都提供，晶片廠的差異化空間可能因此縮小。各項百分比都來自 Arm 自家參考設計，要等量產手機晶片出現才能看到真實表現。
