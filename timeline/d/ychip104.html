RISE 建成低於環境壓力的晶片直冷實驗系統｜RISE｜9 月 15 日 事件推薦

RISE 的低壓直冷實驗，把焦點轉向水泵耗能

RISE 發表一套資料中心伺服器的晶片直冷實驗系統，測試迴路壓力如何影響冷卻與耗電。

這是什麼

RISE 建造低於環境壓力的實驗迴路，想釐清壓力變化會不會影響 CPU 溫度、耗電及水泵運作。

三點帶走

  1. RISE 研究低於環境壓力的晶片直冷，核心關切是液冷迴路的漏液風險與運作表現。
  2. 在此次測試條件下，研究者未觀察到壓力對 CPU 溫度或耗電的明顯影響。
  3. 較低負壓伴隨較小的水泵流動阻力；同等冷卻效果下的水泵用電，是下一個值得量測的數字。

重點與分析

RISE 指出，過去阻礙液冷的一大因素，是導電液體漏到電子零件、損壞伺服器的風險；官方認為低於環境壓力的晶片直冷技術能有效排除這項風險。

通鑑判斷，這項研究先處理的是資料中心敢不敢把液體送到處理器旁，而非單純追求更低溫。這讓壓力成（6239）為值得單獨研究的設計變數：即使降壓有助於處理漏液顧慮，系統仍須維持冷卻能力。RISE 因此建造可調整壓力與溫度的迴路，檢查兩者能否兼顧。

官方表示，原型只連接一台伺服器。研究者調整運算負載、冷卻液供應溫度、CPU 目標溫度與迴路壓力；系統大致能維持設定值，但在部分溫度條件下無法達標。

通鑑認為，這套原型的價值在於把幾個容易互相干擾的條件拆開觀察。伺服器忙起來會更熱，冷卻液入口溫度也會影響處理器溫度；如果兩者跟著壓力一起變，就難以辨認結果究竟由誰造成。研究者能固定平均 CPU 溫度、冷卻液供應溫度及伺服器入口壓力，才有基礎比較壓力的影響。達不到目標溫度的情況也指出，控制能力會受冷卻液與 CPU 之間的溫差限制。

在這次測試的壓力範圍內，官方表示沒有觀察到壓力對 CPU 溫度或耗電的明顯影響；實驗期間，冷卻液壓力也未進入可能發生相變的區域。

通鑑判斷，這個結果讓低壓設計的取捨更清楚：在研究者測過的負載、供液溫度與壓力條件下，調整壓力沒有帶來可察覺的 CPU 溫度或耗電變化。對設計冷卻迴路的人，這表示壓力不必被當成降低 CPU 耗電的主要旋鈕，注意力可以轉向漏液風險與輸送冷卻液所需的能量。原文也交代壓力範圍未使液體相變，因此這項判斷適用於此次測過的範圍。

官方表示，負壓較低時，循環水泵遇到的流動阻力較小；研究者據此推論，以較低負壓運作，抽送冷卻液所需的能量可能較少。

通鑑認為，下一個關鍵問題是水泵耗能，而非再比較 CPU 本身的耗電。冷卻系統要持續把液體送過伺服器；即使處理器溫度相近，推動液體所花的電仍會影響整套設備的效率。這次觀察到的是水泵面對的阻力差異，節能則是研究者由此提出的推論。接下來若要判斷這條路是否值得採用，最有用的數字會是：在相同負載與冷卻效果下，不同壓力設定各讓水泵消耗多少電。

通鑑怎麼看

通鑑認為，RISE 這項實驗把低壓直冷的討論從「能不能讓 CPU 更冷」推向「能否兼顧漏液風險與水泵耗能」。測試中 CPU 溫度與耗電沒有明顯隨壓力改變，水泵阻力卻有差異；後續應直接量測同等冷卻效果下的水泵用電。
