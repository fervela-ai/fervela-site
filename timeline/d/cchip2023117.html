AWS 與 NVIDIA（NVDA） 擴大合作，GH200 NVL32 將首度採液冷

官方表示，雙方將推出 GH200 NVL32 雲端執行個體、H200 執行個體 P5e，以及供 NVIDIA（NVDA） 自用的 Project Ceiba 超級電腦。

這是什麼

這是 NVIDIA（NVDA） 在 AWS re:Invent 大會與 AWS 一起發布的合作公告，涵蓋新的運算執行個體、DGX Cloud 上雲，以及一台由 AWS 代管、給 NVIDIA 自家研發使用的超級電腦。

三點帶走

  1. GH200 NVL32 將 32 顆超級晶片連成一個執行個體，為 AWS 上首個液冷 AI 基礎設施
  2. Project Ceiba 擁有 16,384 顆 GH200，供 NVIDIA（NVDA） 自家研發使用
  3. P5e、G6、G6e 三種新執行個體預告明年提供

重點與分析

官方表示，AWS 將是第一家提供多節點 NVLink 的 GH200 的雲端業者；GH200 NVL32 把 32 顆 Grace Hopper 超級晶片連成一個執行個體，可提供最高 20TB 共享記憶體。

NVL32 的意義在於『一個執行個體』：32 顆晶片的記憶體對程式來說像一個大池子，適合超大模型。官方另說，這類執行個體有 4.5TB 的 HBM3e，是目前 P5d（H100）的 7.2 倍，並以第三代 EFA 提供每顆超級晶片最高 400Gbps 網路。這些都是預告規格，原文寫的是『將會』提供。

官方表示，GH200 NVL32 執行個體將是 AWS 上第一個採用液冷的 AI 基礎設施，以支援高密度機櫃全效能運作。

這一句很短但分量重：官方說這是 AWS 上第一個採用液冷的 AI 基礎設施，與同月 Microsoft（MSFT） 為 Maia 做液冷機櫃、德國 JUPITER 用液冷節點彼此呼應。原文沒有說明液冷形式（冷板或浸沒）與散熱容量。

官方表示，雙方合作的 Project Ceiba 將配備 16,384 顆 GH200、可處理 65 exaflops 的 AI 運算，由 AWS 代管，供 NVIDIA（NVDA） 自家研發使用。

Ceiba 是 NVIDIA（NVDA） 自己當客戶的系統，這點跟其他超級電腦由第三方擁有不同。65 exaflops 與同月 AWS 自研 Trainium2 叢集的 65 exaflops 數字相同，但兩者是不同晶片、不同規模，數字相同只是巧合，勿混為一談。

官方表示，P5e 搭載 H200（141GB HBM3e），官方稱比 H100 大 1.8 倍、快 1.4 倍，EFA 最高 3,200Gbps；G6、G6e 用 L4、L40S，皆明年提供。

這裡可與 H200 的發表稿對照：同一款 H200 在這裡是 AWS 的執行個體商品，時程為 2024 年。官方同時預告 NeMo、BioNeMo 等軟體上 AWS，並說 AWS 自己用 NeMo 訓練部分 Amazon（AMZN） Titan 模型。要注意這裡的 1.8 倍與 1.4 倍是對 H100 的容量與速度比較，和 H200 發表稿用 A100 做基準的 2.4 倍並不相同，同一款晶片在不同稿件裡的比較基準不同。

通鑑怎麼看

通鑑認為，這則新聞展示 GPU 雲端的新單位已不是單卡而是『32 顆一體的機櫃級系統』，液冷與記憶體池成為標配。它與同日 AWS 自家晶片公告並讀，更能看出 AWS 『既賣 NVIDIA（NVDA） 也賣自研』的雙軌策略。
