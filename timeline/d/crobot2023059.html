Instruct2Act：讓語言模型寫出機械臂的感知到行動程式

這篇論文把現成的基礎模型接起來，讓機械臂依文字或圖像指令完成桌面操作。

這是什麼

Instruct2Act 是一個框架：語言模型負責產生程式碼，程式碼透過預先定義的 API 呼叫其他基礎模型（foundation models，大規模預訓練的通用模型）。

三點帶走

  1. LLM 產生 Python 程式，串起感知、規劃、行動
  2. SAM 定位物體、CLIP 分類，不另外訓練
  3. 結果限於桌面操作，比較細節需看全文

重點與分析

論文表示，框架用 LLM 產生構成完整感知、規劃、行動迴圈的 Python 程式，把多模態指令對應成機械臂操作的連續動作。

與直接輸出動作不同，這裡輸出的是可讀的程式碼。好處是流程可檢查；代價是依賴預先定義的 API，能做的事受限於那些介面。摘要沒有說明 API 涵蓋哪些動作。

論文表示，感知經由 API 取用基礎模型：Segment Anything Model（SAM）定位候選物體，CLIP 負責分類。

也就是把『找到物體』與『認出是什麼』分給不同的現成模型，再由程式碼組合。摘要沒有提到重新訓練視覺模型，這代表視覺能力主要沿用現成模型。

論文表示，方法在桌面操作的不同情境驗證，零樣本方法在多項任務優於許多學習型策略，並公開程式碼。

『優於』的對象與任務數，摘要沒有列出，結果僅限於桌面操作，且需看全文才能判斷比較設定是否公平。零樣本的意思是不為這些任務額外訓練。

通鑑怎麼看

通鑑認為，這類『語言模型寫程式、呼叫現成模型』的做法降低了機器人任務的訓練成本，但上限取決於 API 的設計與基礎模型的準確度，摘要尚未回答這些問題。
