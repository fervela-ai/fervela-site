ChatGPT Ads Manager｜OpenAI｜5 月 5 日 產品進階

ChatGPT 廣告開始讓企業自己買、自己管理

OpenAI 在擴大 ChatGPT 廣告試行計畫時，推出測試版 ChatGPT Ads Manager，並加入按點擊付費與成效衡量工具。

這是什麼

ChatGPT Ads Manager 是企業購買與管理 ChatGPT 內廣告的自助工具。它把原本主要透過 OpenAI 或合作夥伴處理的投放流程，帶進企業可自行操作的入口。

三點帶走

  1. 測試版 Ads Manager 讓企業可自行購買、管理並查看 ChatGPT 廣告成效，但仍在逐步開放。
  2. 新增按點擊付費；點擊能反映興趣，不能直接當成成交。
  3. 廣告主可看彙整成效，無法查看個別對話；實際投放決策由 OpenAI 系統控制。

重點與分析

官方表示，企業可在測試版 Ads Manager 註冊、加入付款資料、設定預算與出價、上傳廣告，並在同一入口管理活動和查看成效；工具正逐步開放。

通鑑判斷，變化不只是多了一個管理畫面，而是企業有機會從申請到查看結果都自行操作。這可能降低小公司嘗試 ChatGPT 廣告的門檻，但目前仍是逐步開放的測試版。能否順利使用、操作是否省時，以及成效資料夠不夠清楚，都需要等更多企業實際使用後才能判斷。

官方表示，廣告主除了按曝光付費，也可選擇按點擊付費；採後者時，只有出現點擊才會收費。官方表示將繼續支援按曝光與按點擊兩種購買方式。

通鑑判斷，按點擊付費讓企業較容易把支出連到使用者的下一步動作，適合先測試哪些廣告能引起興趣。不過，點擊不等於購買或詢問，也不能單靠點擊數判定廣告划算。企業仍需對照自己的目標與後續結果，才能知道這種計費方式是否合適。

官方表示，已推出 Conversions API 與像素衡量工具，協助廣告主了解使用者與廣告互動後是否購買、留下潛在客戶資料或註冊；廣告主取得的是彙整成效資料，無法查看個別對話。

通鑑判斷，投放入口與計費方式齊備後，能否看見點擊後的結果，才更接近企業評估廣告的需求。彙整資料也劃出隱私界線：廣告主可觀察活動整體表現，不能藉此讀取個別使用者的對話。值得觀察的是，這些衡量結果是否足以幫助企業決定要不要持續投入。

官方表示，企業也能透過既有代理商與技術合作夥伴購買 ChatGPT 廣告；合作夥伴可協助處理預算、出價與廣告內容，廣告的投放決策仍由 OpenAI 系統控制。

通鑑判斷，這讓已有廣告作業流程的企業可以沿用熟悉的工具，同時讓想直接操作的企業選擇 Ads Manager。兩條購買路徑都指向同一個關鍵限制：合作夥伴能協助準備與管理活動，實際投放由 OpenAI 系統決定。企業評估合作方式時，應先弄清楚自己能調整哪些設定、能看到哪些成效。

通鑑怎麼看

ChatGPT Ads Manager 讓 ChatGPT 廣告從少數企業參與的試行方式，往可自行購買與衡量的方向走。通鑑判斷，企業現在較容易規劃小規模測試；是否值得持續投放，仍取決於實際成效、可取得的衡量資料，以及廣告是否能在不干擾對話體驗的情況下被看見。
