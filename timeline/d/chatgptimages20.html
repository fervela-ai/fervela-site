ChatGPT Images 2.0｜OpenAI｜4 月 21 日 產品入門

OpenAI 要生圖先想完，再寫對中文

OpenAI 在發表會上推出 ChatGPT Images 2.0，並表示已在 ChatGPT 與 API 開放。開場稱 Imagen 2.0，後段又說成 GPT Images 2、Images 2 與 GPT Image 2，名稱沒有統一。

▶ 到 YouTube 看官方影片OpenAI｜Introducing ChatGPT Images 2.0｜22 分鐘

這是什麼

這是放進 ChatGPT 與 API 的新一代生圖。它被做成先想再畫、還能搜尋網路的流程，用來處理多國文字的海報、食譜、漫畫、裝修與標誌，而不是只多一張供觀賞的圖。

三點帶走

  1. 中文、日文、韓文、印地語被講者說能整頁生成，但不出錯仍是自我評價，要印的字必須人眼再對。
  2. 思考模式可先想、搜尋，並做出多張連貫的圖；圖裡的引言與資料要對回出處。
  3. 講者表示功能已在 ChatGPT 與 API 開放，標誌一次有 16 到 20 個方向，可再反覆改。應用程式要更新到出現歡迎畫面才算能用。

重點與分析

講者表示，中文、日文、韓文、印地語現在可整頁生成且不出錯；這些文字有成千上萬個字，不像英文只有 26 個字母，以前很難記住。現場海報有中文你好、英文 hello、法文 bonjour，日文海報的漢字與平假名拉近仍在。

對台灣上班族，錯字才是海報能不能用的關鍵。海報、菜單與簡報封面，以前多半只能當草稿。若中文整頁真站得住，生圖才有機會變成可交差的底稿。但不出錯是發表會上的自我評價。印地語食譜那段，工程師只說第一眼沒看到錯誤，不是逐字校對。公司名、地址、價格、日期仍要人看過才能送印。文字又密時才看得出差距，雙語海報要用真正要印的句子去試。

Kenji 說明思考模式會先想再出圖，適合複雜提示、搜尋網路、多圖連貫或先自我檢查。他表示漫畫能維持人物、畫風與劇情，同一張圖還放進搜尋引言，以及現場掃得過、通往 chat.openai.com 的 QR code。

思考模式把生圖從一次一張，改成可以來回改的作業。整本雜誌、全屋翻新、角色連續出現的漫畫，比單張海報更接近企劃與教材。可搜尋再把結果畫進圖裡，圖就開始帶資料。風險是畫面同時有搜尋結果、整理過的答案與 QR code，看起來像查證過的懶人包。發表會只證明做得出這種版面，沒有證明引用無誤。幾週前即時版本放上模型對戰網站 LM Arena 內測，代號 Duct Tape，現場才證實是 OpenAI。

Nithanth 說所有使用者現在就能用，應用程式需更新到出現歡迎畫面。講者表示，麵包店標誌一次回傳 16 到 20 個構想；以模型能力這仍算簡單提示，它很會遵守細指示，可用 ChatGPT 按品牌用語與設計美學反覆改。

一次給出十多個標誌，改變的是提案速度，不是品味已經決定。若講者表示的 16 到 20 個裡有幾個能用，會議可以改成挑選與修改。講者說這仍算簡單提示，賣點是更細的品牌規範。細指示好不好，要看指定顏色、留白、不能出現的字有沒有被吃掉。對話改到滿意，適合內部試探，不適合跳過設計直接定稿。人人可用是功能已開，手機要更新到歡迎畫面。講者所示實驗性 4K 屬 API，不是應用程式預設畫質。

Alex 表示，提示寫 photorealistic，或用 iPhone、拋棄式相機拍攝，就會往自然照片走。講者表示可以 2K 生成，長寬比最高到 1:3 與 3:1。講者請模型做登月 360 度圖，在自寫檢視器中太陽與影子方向一致。

寫實關鍵字適合做活動紀錄風、產品放在桌上、簡報用的情境圖，但不代表場景與比例已被核對。極端長寬比適合橫幅，也容易把人拉變形；現場把脖子拉到極長，講者說不宜當頭像或分享。講者表示最高到 1:3 與 3:1，那是版面能力。講者表示能以 2K 生成、細節清楚，解決的是放大後糊掉的問題，但不能代替人眼核對商標與人臉。登月全景的光影一致，只說明空間開始顧全張；檢視器是現場自寫的，不是內建產品。

通鑑怎麼看

對工作有差的不是文藝復興，也不是講者把進步比成從 GPT-3 走到 GPT-5，而是圖開始被拿去交付：中文要讀得懂、一連串圖要一致、標誌要改得動。同一場名稱從 Imagen 2.0 說到 GPT Image 2，官方頁寫 ChatGPT Images 2.0，找的時候認歡迎畫面。會搜尋又會排版，圖會很像已完成的報告；越像，越只能當草稿。美一眼可見，智能深不深，要用自己的句子與品牌規範試出來。
