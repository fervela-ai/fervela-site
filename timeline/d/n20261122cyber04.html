Microsoft Agent Framework 的兩個 PyPI 版本遭植入竊密程式

Aikido Security 發現，11 月 17 日發布的 agent-framework 1.26.1 與 1.26.2 都含有竊取憑證的程式。兩版相隔 33 分鐘發布，後來均已從 PyPI 移除。

這是什麼

agent-framework 是 Microsoft Agent Framework 的 Python 套件。受影響版本安裝後，竊密程式會在每次啟動 Python 時執行，即使程式沒有使用 agent-framework，也可能將可取得的憑證傳送出去。

三點帶走

  1. 若曾安裝 agent-framework，值得確認實際版本及環境中是否有文中列出的 .pth 檔。
  2. 若裝過受影響版本，可能需要依該環境能存取的憑證範圍，重建環境並更換相關秘密資訊。

重點與分析

1.26.1 於 11 月 17 日 20:35 UTC 上架；1.26.2 於 21:08 UTC 上架。到 21:20 UTC，兩版都已從 PyPI 移除。

若安裝時允許自動取得較新版本，是否受影響可能取決於安裝發生的時間與實際取得的版本。

惡意版本透過 Python 啟動時會讀取的 .pth 檔執行程式；執行 pytest 或 pip 也足以觸發，無須匯入 agent-framework。

值得注意的是，風險可能出現在使用同一個 Python 環境的其他工作中，不能只看專案程式碼有沒有呼叫這個套件。

竊密程式蒐集環境變數與憑證檔案，並嘗試取得 Azure 相關權杖；1.26.2 另加入針對 GitHub Actions OIDC 權杖的程式碼。Aikido 建議檢查安裝版本、將套件固定為 1.26.0、重建受影響環境，並更換該機器可取得的秘密資訊。

實際影響可能取決於受影響環境當時能存取哪些憑證。移除套件只能停止後續執行，已傳出的憑證仍需處理。

通鑑怎麼看

這起事件值得看的是執行時機：套件安裝後，惡意程式可能在每次啟動 Python 時運作。因此，排查範圍可能需要涵蓋開發電腦、建置流程與容器映像，而不只是直接使用該套件的程式。
