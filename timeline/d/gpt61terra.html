GPT-6.1 Terra 把電腦操作放在主打位置

官方原文介紹 GPT-6.1 Terra，主打快速且有能力的電腦操作。

這是什麼

GPT-6.1 Terra 是 OpenAI 推出的模型，主打電腦操作。官方希望讓更多人用得上這項能力；OpenAI 列出提案撰寫、技術圖面判讀、填表與影片剪輯等用途，並提供多項評測、供應範圍及定價。

三點帶走

  1. GPT-6.1 Terra 的主打能力是電腦操作。
  2. 快速且有能力是官方說法；提供的文字沒有測試數據。
  3. 讓每個人用得上是官方目標，實際使用條件仍待確認。

重點與分析

官方將電腦操作列為 GPT-6.1 Terra 的主打能力。

通鑑判斷，讀這項發表時，最該留意的是模型實際能完成哪些電腦操作。不過，官方提供的文字沒有具體操作示範，因此現在還無法從中判斷它能完成哪些工作、做到哪一步。

官方以快速且有能力形容 GPT-6.1 Terra 的電腦操作。

通鑑判斷，快速與有能力應分開看：速度快，未必代表每一步都做對；能完成工作，也還要看需要花多少時間。OpenAI 在 Agents’ Last Exam 中稱，GPT-6.1 Terra 以中等推理強度比 GPT-5.6 Terra 高 15 個百分點，成本約三分之一，並列出其他能力與速度比較；這些是官方評測結果。值得觀察後續是否有可供檢視的操作案例，讓使用者判斷它在自己的工作上是否可靠。

OpenAI 表示，GPT-6.1 Terra 以較低 API 價格讓開發者較容易用於大量電腦操作工作。

通鑑判斷，這句話指出官方想把電腦操作帶給更廣泛的使用者，但不能據此推定所有人現在都能使用。對上班族來說，能否取得、是否容易上手，以及操作時需要多少人工確認，都會影響它有沒有實際用途。OpenAI 表示，Plus、Pro、Enterprise 與 Edu 使用者已可在 ChatGPT Work 和 Codex 使用，開發者也可透過 API 使用 gpt-6.1-terra；API 定價已公布。

通鑑怎麼看

通鑑判斷，GPT-6.1 Terra 值得關注的方向是讓 AI 參與電腦操作。官方提供工作範例與多項評測數據，包括 Terminal-Bench 4.0 最大推理強度下完成 50.3% 任務；這些數字仍須放回實際工作情境評估。等到使用條件與實際示範更清楚，才能判斷它能替上班族省下多少操作工作。
