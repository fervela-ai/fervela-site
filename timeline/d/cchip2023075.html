Synopsys 介面 IP 在台積電 N3E 製程首次投片成功｜Synopsys｜7 月 20 日 事件進階

Synopsys 宣布 3 奈米介面 IP 矽驗證成功，已有數十家公司採用

7 月 20 日，Synopsys 宣布其台積電（2330） N3E 製程介面 IP 在多條產品線上取得矽驗證成功，鎖定 AI、高效能運算與手機晶片設計。

這是什麼

IP（矽智財）是晶片設計公司可以直接授權使用的現成電路模組，例如記憶體介面、高速傳輸介面。「首次投片成功」指晶片第一次送去製造就能正常運作，不必改版重來，對 3 奈米這種昂貴製程尤其重要。

三點帶走

  1. Synopsys 台積電（2330） N3E 介面 IP 多條產品線矽驗證成功。
  2. 涵蓋 112G 乙太網路、DDR5、LPDDR5X、PCIe 等 AI 晶片必備介面。
  3. IP 可快速移轉到 N3P，官方稱已有數十家公司採用。

重點與分析

官方表示，Synopsys 為台積電（2330） N3E 製程提供業界最廣的介面 IP 組合，多條產品線（包括最常用的協定）已取得矽驗證成功，在功耗、效能、面積（PPA）與延遲上表現領先。

PPA 是晶片設計的三大指標。原文所謂「領先」是 Synopsys 自己的描述，稿中沒有給出具體數字或和其他 IP 供應商的比較。這則公告真正的資訊量在於：3 奈米介面 IP 已有實際晶片驗證，晶片設計公司可以少冒一些整合風險。

官方表示，符合標準的 Synopsys 介面 IP 包括 112G 乙太網路、LPDDR5X、DDR5、PCIe、USB／DisplayPort 與 MIPI C/D-PHY，可廣泛互通。

這份清單幾乎涵蓋了 AI 加速器與伺服器晶片需要的對外通道：112G 乙太網路用於機櫃內外連線，DDR5、LPDDR5X 是記憶體介面，PCIe 連接加速卡與儲存。對想做 3 奈米 AI 晶片的公司來說，這些模組若能直接買到，就不必自行開發高速類比電路，這是先進製程上最耗時的工作之一。

官方表示，Synopsys 為 N3E 提供的 IP 可快速轉移到台積電（2330） N3P，協助設計者加速 AI、高效能運算與行動晶片開發；Synopsys 稱其 3 奈米 IP 已被數十家領先公司採用。

N3P 是 N3E 的效能強化版本。IP 能沿用到下一個版本，可以縮短客戶從 N3E 換到 N3P 的時間。「數十家公司採用」沒有列出名單。台積電（2330）設計基礎架構管理處負責人 Dan Kochpatcharin 在稿中為此背書，顯示晶圓廠也需要 IP 生態系來吸引客戶投片。
