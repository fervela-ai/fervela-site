Supermicro 發表直接液冷最佳化的 NVIDIA Blackwell SuperCluster｜Supermicro｜11 月 18 日 事件進階

Supermicro 以垂直冷卻液歧管提高液冷機架內的 B200 系統密度

Supermicro 在 Supercomputing 會議上公布 B200、GB200 NVL4 與 NVL72 的液冷與空冷系統。

這是什麼

Supermicro 是伺服器系統廠商，這份新聞稿說明如何把 NVIDIA（NVDA） 的 Blackwell 加速器放進液冷機架。重點是機架內的冷卻設計與單機散熱能力。

三點帶走

  1. 新 SuperCluster 以垂直冷卻液歧管與排內 CDU 提高液冷機架內 B200 系統密度。
  2. 空冷 10U 機箱可容納八顆 1000W TDP 的 Blackwell GPU。
  3. GB200 NVL72 以 72 顆 GPU 組成單一 NVLink 域，總頻寬 130TB/s。

重點與分析

官方表示，新的 SuperCluster 可擴展單元採機架級設計，使用垂直冷卻液分配歧管（CDM），讓單一機架容納更多運算節點；新開發的冷板與軟管設計進一步改善液冷效率，並新增排內 CDU 選項。

官方表示垂直歧管可讓單一機架容納更多運算節點。新聞稿沒有提供每機架具體的節點數或功率，只拿『較 H100/H200 為基礎的 SuperCluster 大幅提高 GPU 密度』作比較，所以密度提升幅度無從量化。

官方表示，新的空冷 10U HGX B200 系統重新設計機箱，有更大的散熱餘裕，可容納八顆 1000W TDP 的 Blackwell GPU；系統採 1:1 的 GPU 對網卡比例，並可搭配雙 500W 的 Intel（INTC） Xeon 6 或 AMD EPYC 9005。

TDP（熱設計功耗）是晶片設計時預期要散掉的熱量。新聞稿把空冷 10U 機箱的『擴大散熱餘裕』與八顆 1000W TDP 的 GPU 放在同一句，說明空冷版本是靠放大機箱來容納這個熱量；稿中沒有提供空冷機架的整體功率或適用機房條件。

官方表示，GB200 NVL72 SuperCluster 在單一機架內由 72 顆 Blackwell GPU 與 36 顆 Grace CPU 透過第五代 NVLink 連接，共享大量 HBM3e 記憶體，GPU 間總通訊頻寬 130TB/s。

130TB/s 是 NVLink 域內 GPU 之間的總通訊頻寬，新聞稿沒有說明測量方式。新聞稿把 HBM3e 描述為『大量記憶體池』，但沒有給出總容量。這個數字的價值在於說明機架內 72 顆 GPU 可被視為單一 GPU 使用。

官方表示，5U PCIe 系統現可搭載 NVIDIA（NVDA） H200 NVL，四顆 GPU 的 NVLink 域合計 564GB 的 HBM3e，推論最高比前代快 1.7 倍；Supermicro 並稱其已部署含 100,000 顆 GPU 的液冷 AI 資料中心。

564GB 是四顆 GPU 的 HBM3e 加總，1.7 倍在稿中沒有註明測試模型與條件。『100,000 顆 GPU』是新聞稿中執行長 Charles Liang 的說法，指的是 Supermicro 與 NVIDIA（NVDA） 共同貢獻的專案，沒有說明客戶與位置。

通鑑怎麼看

通鑑認為，這則新聞顯示 Blackwell 時代的系統廠商正同時推液冷機架與更大的空冷機箱，單顆 GPU 功耗已到 1000W 等級。具體的機架密度與節能幅度新聞稿都沒有量化。
