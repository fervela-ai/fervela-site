AWS 與 NVIDIA：Project Ceiba 以 20,736 顆 GB200 達 414 exaflops｜NVIDIA｜3 月 18 日 事件進階

AWS 與 NVIDIA（NVDA） 擴大合作：Blackwell 上雲與 Project Ceiba

AWS 與 NVIDIA（NVDA） 宣布 Blackwell 平台將上 AWS，並公布 Project Ceiba 的規格。

這是什麼

這是一則雲端上架與超級電腦規模的公告。與晶片最相關的是 GB200 NVL72 的系統規模與網路頻寬數字。

三點帶走

  1. AWS 將提供 GB200 NVL72 與 B100 執行個體。
  2. Project Ceiba：20,736 顆 B200 GPU、414 exaflops。
  3. 官方稱整合 Nitro 與 KMS 提供端到端加密控制。

重點與分析

官方表示，AWS 將提供 NVIDIA（NVDA） Blackwell 平台，包含 GB200 NVL72（72 顆 Blackwell GPU 與 36 顆 Grace CPU，以第五代 NVLink 互連），並以 EFA 網路、Nitro 系統與 EC2 UltraClusters 擴展到數千顆 GB200 超級晶片；也計畫提供搭載 B100 GPU 的 EC2 執行個體。

這則稿中的 GB200 與 B100 兩種產品並列，時程只說「即將」。稿中沒有價格與供貨日期。

官方表示，Project Ceiba 是 NVIDIA（NVDA） 與 AWS 合作、僅在 AWS 上運行的 AI 超級電腦，使用 GB200 NVL72 建造，擁有 20,736 顆 B200 GPU 連接 10,368 顆 Grace CPU，每顆超級晶片提供最高 800 Gbps 網路頻寬，AI 運算能力達 414 exaflops，是先前以 Hopper 架構規劃的 6 倍。

414 exaflops 是低精度下的理論峰值，稿中沒有說明精度，所以不能與傳統高效能運算榜單比較。稿首摘要寫 20,736 顆 GB200 超級晶片，內文寫 20,736 顆 B200 GPU，兩處計數單位不同，閱讀時要注意。

官方表示，AWS Nitro 系統、EFA 加密與 AWS Key Management Service 將與 Blackwell 的加密整合，使客戶對訓練資料與模型權重擁有端到端控制，並防止 AWS 營運人員取得金鑰或解密資料。

這是資安設計宣稱，稿中沒有第三方稽核。其重點是「營運人員無法存取」，需靠硬體與流程驗證。

通鑑怎麼看

Ceiba 的規模數字顯示 GPU 叢集仍在擴大，但 414 exaflops 的精度與可用性沒有說明。
