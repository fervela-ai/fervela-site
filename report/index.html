📝 會心

by Fervela.ai
拍下投影片、錄下聲音，拿回一份完整研討會報告。
聽完一整天的研討會，手機裡是幾百張歪斜的投影片照片和幾小時的錄音。 會心把它們整理成一份完整的 PPTX 報告——依議程分場、合併重複畫面、把投影片拉正， 再重建每位講者的論證順序、案例、數據與結論，套上你指定的母片。
錄音在你自己的電腦上轉成文字，原始錄音不會交給任何 AI 服務，也不會傳給 Fervela（資料到哪裡去 ↓）。

怎麼用

現場只管拍和錄，整理的事回來再說
1
把素材放進去

錄音、現場照片、主辦方的議程、你要套用的 PowerPoint 母片。照片不必先挑，全部丟進來。

2
會心在本機整理

錄音轉成帶時間碼的逐字稿；照片依時間與議程自動分場、去掉重複、拉正畫面。

3
你複核一次

看場次分得對不對，以及準備交給 AI 的文字和圖片有哪些。不想送出去的，這時候排除。

4
拿到 PPTX

Claude CLI 或 Codex CLI 整理內容，固定的排版程式套上母片，輸出前逐頁檢查過。

你的資料到哪裡去

哪些留在電腦裡、哪些會送出去，分開講
原始錄音
留在本機用 whisper.cpp 在你的電腦上執行 Whisper large-v3-turbo 轉成文字。音檔不會交給 Claude、OpenAI 或 Fervela。
現場照片
留在本機分場、去重、透視校正都在你的電腦上做。
逐字稿、議程、
你確認過的投影片圖片
送到你選的 AI交給你自己登入的 Claude CLI 或 Codex CLI（用的是你的 Anthropic／ChatGPT 帳戶）。送出前看得到清單，可以排除。
排版與成品
留在本機PPTX 在你的電腦上產生，存在你指定的資料夾。
Fervela 不接收你的原始錄音。送到 AI 服務的文字與圖片怎麼保存、怎麼使用，依你的帳戶方案與該服務的條款而定。
會心唯一會連回 Fervela 的事：看有沒有新版。一天最多一次，只是讀取官網上一個公開的版本檔，不附帶任何識別碼或使用紀錄；有新版只會提醒你，不會自動安裝。連不上也照常能用。
錄之前、拍之前，先確認主辦單位允許。投影片的著作權屬於講者；做出來的報告適合自己和團隊內部使用。

跟「語音轉文字」差在哪

逐字稿不是報告
幾百張照片，自動分場、去重

依時間、議程與畫面內容找出同一張投影片的重複照片，合併處理；不同的操作步驟和結果畫面則完整保留。

被擋住的，先找別張照片補

同一頁拍了好幾張時，先對齊，再用各張沒被擋到的部分互補，然後拉正。每一張都沒拍到的文字，不會猜。

逐字稿、議程、投影片三方對齊

每張圖旁邊的說明，對得回是錄音的哪一段、議程的哪一場。AI 寫錯的時候，你查得到。

你的母片，每次都一樣的版面

AI 只負責整理內容，排版由固定的程式處理。輸出前把每一頁實際渲染出來，檢查重疊、越界、漏頁和重複圖片。

做不到的事

先講清楚，免得你白裝
  • 投影片被完全擋住、或拍出畫面外的部分，不會猜補，報告裡就是沒有。
  • 語音辨識會有錯字，尤其是人名、公司名和專有名詞。AI 整理時會修掉常見的，但不保證全對。
  • 測試版還沒有付費簽章，第一次打開時 macOS 和 Windows 會跳安全警告。
