Android 安裝教學

  1. 下載：用 Chrome 開這一頁，點上面的「Android 安裝檔」。
  2. 點開：下載完成後，點開 huixin-0.7.0-70.apk。
  3. 允許安裝：手機問「是否允許安裝未知來源」時，選「允許」（只針對 Chrome，裝完可以關回去）。
  4. 開啟並允許麥克風與相機：第一次錄音前，會先出現錄音提醒，請照提醒做。

常見問題

研討會可以錄音嗎？

要看主辦單位的規定。主辦單位禁止錄音或拍照時，請不要使用會心的錄音與拍照功能；休息和私下談話也請暫停。整理出的內容只供你個人筆記，要分享前請先取得講者同意。

換手機怎麼搬資料？

會心不使用系統備份。換手機前，請用「整場打包」把場次存成檔案，傳到電腦或新手機。

要付費嗎？

目前是朋友試用版，免費使用。
